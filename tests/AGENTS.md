# tests

Тесты идут на реальной PostgreSQL из compose-контура: проект опирается на JSONB и специфичные
индексы, на SQLite они не воспроизводятся. Запуск — `docker compose run --rm test`.

## Файлы
- `conftest.py` — общие фикстуры: тестовая база с миграциями, сессия с откатом, клиенты, фабрика задач
- `test_actors_api.py` — эндпоинты акторов: доступ по токену, оболочка ответа, цикл жизни токена
- `test_actors_service.py` — сценарии акторов и токенов: успех и основные отказы
- `test_auth.py` — аутентификация: валидный, неизвестный, отозванный токен, отключённый актор
- `test_automation_api.py` — эндпоинты автоматики: обе половины правила, отказ на мусорных параметрах, журнал
- `test_automation_engine.py` — движок: три формы, взаимные правила гаснут, изоляция ошибки, лимит на волну, одновременная синхронизация реестра
- `test_automation_notify.py` — действие `notify` правила: сообщение доходит, видно в журнале, системному актору отказ
- `test_automation_rules.py` — поставочные правила: закрытие подзадач, напоминание о зависших, релизный макрос
- `test_boards_api.py` — эндпоинты досок: сборка по колонкам, ранжирование, перенос карточки
- `test_boards_service.py` — сценарии досок: состав колонок, порядок карточек, перенос переходом воркфлоу
- `test_catalogs_api.py` — эндпоинты справочников: адресация ссылками, области, отказы удаления
- `test_catalogs_service.py` — сценарии справочников: области действия, защита статусов, перенос задач
- `test_changelog_api.py` — эндпоинт истории задачи: оболочка ответа, пагинация, ссылки строками
- `test_checklists_api.py` — эндпоинты чеклиста: отметка, перестановка соседом, отказы домена
- `test_checklists_service.py` — сценарии чеклиста: одна строка на перемещение, перенумерация, события
- `test_comments_api.py` — эндпоинты обсуждения: упоминания, плашка удалённого, пагинация ленты
- `test_comments_service.py` — сценарии обсуждения: упоминания, правка, мягкое удаление, события
- `test_domain_actors.py` — домен без базы: ключи акторов, генерация и хеширование токенов
- `test_domain_checklists.py` — домен без базы: текст пункта, арифметика разреженных позиций
- `test_domain_boards.py` — домен без базы: границы полей доски, виртуальная шкала порядка
- `test_domain_comments.py` — домен без базы: текст комментария и границы разбора упоминаний
- `test_domain_events.py` — домен без базы: один словарь на действия и события, выбор типа события
- `test_domain_fields.py` — домен без базы: формат хранения по каждому типу, все ошибки валидатора сразу
- `test_domain_issues.py` — домен без базы: название, описание, дедлайн, теги, имена полей журнала
- `test_domain_links.py` — домен без базы: обратные стороны, канонизация направления, границы дерева
- `test_domain_notifications.py` — домен без базы: адресация по нагрузке события, текст, ключ склейки
- `test_domain_projects.py` — домен без базы: ключи, период, формула прогресса портфеля по задачам
- `test_domain_queues.py` — домен без базы: ключи очередей и задач, ссылки на записи справочников
- `test_domain_search.py` — домен без базы: грамматика языка, приоритет связок, позиция в каждой ошибке
- `test_domain_workflows.py` — домен без базы: целостность графа, тупики, достижимость и шаблоны
- `test_events_service.py` — журнал и outbox: запись в одной транзакции, откат не оставляет следов
- `test_events_worker.py` — шина: доставка, изоляция подписчиков, повторы, переживание перезапуска
- `test_fields_api.py` — эндпоинты полей: адресация ссылками, применимость, скрытие вместо удаления
- `test_fields_service.py` — сценарии полей: области, запрет смены типа, проверка значений против базы
- `test_issue_usage.py` — счётчики использования: справочники, значения полей в JSONB, перенос статусов
- `test_issues_api.py` — эндпоинты задач: оболочка ответа, `null` очищает поле, конфликт версий
- `test_issues_service.py` — сценарии задач: ключи, единая точка изменений, версии, наблюдатели
- `test_links_api.py` — эндпоинты связей: обе стороны, отказы иерархии, дерево с глубиной
- `test_links_service.py` — сценарии связей: дубликаты, единственный родитель, циклы, события
- `test_notifications_api.py` — эндпоинты инбокса и подписок: оболочка ответа, отказы, чужое недоступно
- `test_notifications_service.py` — сценарии уведомлений: маршрутизация, схлопывание, ожидание, инбокс
- `test_openapi.py` — пригодность схемы к генерации клиента: идентификаторы, модели ответов
- `test_portfolios_api.py` — эндпоинты портфелей: вложенность, циклы, состав одним списком, агрегация
- `test_projects_api.py` — эндпоинты проектов: карточка с прогрессом, состав, список задач как поиск
- `test_projects_service.py` — сценарии проектов: состав через единую точку правки задачи, прогресс, циклы
- `test_tags_api.py` — словарь тегов: алфавитный курсор, поиск подстрокой, точечные операции
- `test_queue_numbering.py` — нумерация задач под конкуренцией: свои сессии и честные коммиты
- `test_saved_filters_api.py` — сохранённые фильтры: единственный источник, проверка при сохранении, запуск
- `test_search_api.py` — эндпоинты поиска: выбор полей, сортировка, устойчивая пагинация
- `test_search_service.py` — сценарии поиска: равенство двух входов, каждый тип поля, отказы
- `test_queues_api.py` — эндпоинты очередей: цикл жизни, конфигурация одним запросом
- `test_queues_service.py` — сценарии очередей: значения по умолчанию, архивация, удаление
- `test_errors.py` — единый формат ошибки: доменное исключение, ошибка схемы, несуществующий маршрут
- `test_response_envelope.py` — форма ответа: одиночный ресурс в `data`, коллекция с `meta`
- `test_health.py` — smoke-тест `/health` и проверка того, что фикстура доходит до настоящей БД
- `test_transactions.py` — граница транзакции: коммит, откат и падение самого коммита
- `test_workflow_service.py` — редактор и движок: назначения, требования, резолюции и влияние правок
- `test_workflows_api.py` — REST workflow: граф целиком и точечно, клонирование и переходы задач
