# tests

Тесты идут на реальной PostgreSQL из compose-контура: проект опирается на JSONB и специфичные
индексы, на SQLite они не воспроизводятся. Запуск — `docker compose run --rm test`.

## Файлы
- `conftest.py` — общие фикстуры: тестовая база с миграциями, сессия с откатом транзакции, HTTP-клиент
- `test_errors.py` — единый формат ошибки: доменное исключение, ошибка схемы, несуществующий маршрут
- `test_response_envelope.py` — форма ответа: одиночный ресурс в `data`, коллекция с `meta`
- `test_health.py` — smoke-тест `/health` и проверка того, что фикстура доходит до настоящей БД
- `test_transactions.py` — граница транзакции: успешный запрос коммитит, упавший откатывает
