# site

Публичные страницы Casefile для полей листингов каталогов, по-английски: статический HTML без скриптов.
Публикует `.github/workflows/pages.yml` на GitHub Pages, адрес `https://azimov777.github.io/casefile/`.

## Папки
- `privacy/` — политика конфиденциальности: что хранит установка и что уходит наружу
- `support/` — куда писать (GitHub Issues) и что приложить
- `terms/` — условия: лицензия MIT, нет хостимого сервиса, нет гарантий

## Файлы
- `.nojekyll` — пустой файл: Pages отдаёт папку как есть, без обработки Jekyll
- `index.html` — главная: что такое Casefile и ссылки на остальные страницы
- `style.css` — общий стиль страниц, светлая и тёмная тема
