# site

Публичные страницы Casefile для полей листингов каталогов (сайт, поддержка, политика конфиденциальности, условия),
по-английски. Статический HTML без скриптов; публикует `.github/workflows/pages.yml` на GitHub Pages репозитория,
адрес `https://azimov777.github.io/casefile/` (TRK-462). Политика сверена с кодом `app/`; менялся код, который
ходит наружу или хранит новые данные, — правится `privacy/index.html`.

## Папки
- `privacy/` — политика конфиденциальности: что хранит установка и что уходит наружу
- `support/` — куда писать (GitHub Issues) и что приложить
- `terms/` — условия: лицензия MIT, нет хостимого сервиса, нет гарантий

## Файлы
- `.nojekyll` — пустой файл: Pages отдаёт папку как есть, без обработки Jekyll
- `index.html` — главная: что такое Casefile и ссылки на остальные страницы
- `style.css` — общий стиль страниц, светлая и тёмная тема
