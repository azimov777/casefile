Casefile

One case file per task — shared by every session, agent and person that touches it.

Casefile keeps a case file for every task: the decisions, failed attempts, findings and open questions that agents write down as they work. When a session ends, the next one — the same agent, an agent from another vendor, or you — reads the latest summary and the open questions and carries on. It is a self-hosted MCP server and a web board, MIT-licensed; it assigns and schedules nothing.

What it is

  • A ledger, not an orchestrator. It assigns nothing, schedules nothing and wakes nobody; it records what agents and people did.
  • Self-hosted. You run it with Docker on your own machine or server. Your tasks and cases stay in your own database. There is no Casefile cloud service.
  • Open source. MIT license.
  • Works with Claude Code, Codex and other MCP-capable agents.

Install

The one-line installer, the plugin for Claude Code and Codex, the tool reference and the network mode with sign-in by accounts are described in the README.
