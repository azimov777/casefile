Support

Casefile is an open-source project maintained on GitHub. Support is given through the public issue tracker.

Where to write

github.com/azimov777/casefile/issues — questions, bug reports and feature requests. A GitHub account is needed to post.

What to include

  • The Casefile version (shown at the bottom of the web interface, or GET /api/v1/installation).
  • Your system and how you run Casefile (the one-line installer, Docker Compose, the plugin).
  • What you did, what you expected and what happened. Logs help: docker compose logs api mcp.

Please do not paste tokens, passwords or the contents of your .env file into a public issue.

Before you write

  • README — installation, connecting an agent, network mode, updates.
  • Installation for agents.
  • Backup and restore.

Response

This is a volunteer project: there is no service level and no guaranteed response time. Because Casefile runs on your own infrastructure, the maintainers cannot see or access your installation or your data.
