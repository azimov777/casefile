# 10. Проекты и портфели

- **Блок:** Проекты
- **Зависимости:** 05, 06
- **Результат:** задачи из разных очередей собираются в проект, проекты — в портфели

## Зачем

Очередь отражает процесс команды, а проект — результат, ради которого работают несколько команд.
Это разные оси, и смешивать их нельзя: задача принадлежит одной очереди, но может входить в проект.

## Объём

- Модель `Project`: название, описание, ответственный, участники, статус, даты начала и
  окончания, теги, ссылка на родительский портфель.
- Модель `Portfolio`: те же базовые поля, состав из проектов и вложенных портфелей.
- Связь задач с проектом (задача входит не более чем в один проект).
- Расчёт прогресса проекта: доля задач в статусах категории `done`; агрегация прогресса портфеля
  по вложенным проектам и портфелям.
- Сценарии: создать, изменить, получить с составом, добавить и убрать задачи, перенести проект
  в другой портфель, архивировать.
- Проверка отсутствия циклов во вложенности портфелей.
- Эндпоинты проектов и портфелей, включая список задач проекта.

## Что учесть

- Прогресс не хранить как поле, которое кто-то обязан обновлять — он разъедется с реальностью
  в первую же неделю. Считать по запросу, при необходимости кешировать с инвалидацией по
  событиям изменения задач.
- Портфель может содержать портфели — проверка циклов обязательна, как в задаче 08.
- Статус проекта — самостоятельный справочник (не запущен, идёт, приостановлен, завершён),
  он не выводится из статусов задач: проект может быть приостановлен при полностью закрытых задачах.
- Список задач проекта должен уметь фильтроваться и постранично отдаваться: в проекте могут
  быть тысячи задач из разных очередей.
- Цели (goals) в объём первой версии не входят, но структура «портфель → проект» не должна
  мешать добавить их сверху позже.
- Имя `project` уже зарезервировано (`SYSTEM_FIELD_KEYS` в `app/domain/fields.py`) и лежит в
  списке «занято системой, но искать нечем»: сейчас фильтр по нему отвечает отказом с причиной
  `not_searchable`. Появившийся проект обязан стать полем поиска — описание добавляется в
  `SEARCHABLE_SYSTEM_FIELDS` (`app/domain/search.py`), после чего имя автоматически уходит из
  списка недоступных. Без этого структурный фильтр останется без параметра, который перечислен
  в его объёме, а запрос `project: alpha` продолжит отвечать «ещё нет»
  (выявлено в задаче 12).

## Готово, когда

- Проект собирает задачи из разных очередей, прогресс считается корректно.
- Портфель агрегирует вложенные проекты и портфели, циклы запрещены.
- Тесты на состав, прогресс, циклы.

## Не входит

Цели и ключевые результаты, диаграммы Гантта.
