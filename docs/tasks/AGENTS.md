# docs/tasks

Задания для агентов-исполнителей: один файл — одна задача, выполняемая за один заход.
Порядок запуска и зависимости — в `docs/ROADMAP.md`, общие правила и формат задания —
в `docs/CONVENTIONS.md`. Выполненная задача удаляется вместе со своей строкой в этом списке.

## Файлы
Задачи переписывания (20–29), надёжности (30), области вердиктов (31), признаков в
списке (32) и документационного долга (33) выполнены и удалены. Новая работа начинается
с файла здесь — по формату задания из `docs/CONVENTIONS.md` — и строки в
`docs/ROADMAP.md`.
- `34-prod-env.md` — прод-контур не читает `.env`: настройки установки правятся только в compose-файле
