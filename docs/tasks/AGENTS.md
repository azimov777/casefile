# docs/tasks

Задания для агентов-исполнителей: один файл — одна задача, выполняемая за один заход.
Порядок запуска и зависимости — в `docs/ROADMAP.md`, общие правила — в `docs/CONVENTIONS.md`.

## Файлы
- `04-field-registry.md` — реестр полей задачи и валидация значений; хранение в JSONB
- `05-issues-core.md` — сама задача: ключи, поля, частичное обновление, единая точка мутаций
- `06-changelog-events.md` — история изменений и outbox-шина; фундамент автоматики и уведомлений
- `07-workflow.md` — статусы и переходы, конструирование собственного процесса
- `08-issue-links.md` — типы связей, иерархия подзадач, защита от циклов
- `09-comments-checklists.md` — комментарии с упоминаниями, чеклисты, теги
- `10-projects-portfolios.md` — надочередной слой планирования и расчёт прогресса
- `11-boards-sprints.md` — доски, колонки, спринты, ранжирование карточек
- `12-search-query-language.md` — фильтры, текстовый язык запросов, сохранённые фильтры
- `13-automation-engine.md` — триггеры, автодействия, макросы; правила пишутся кодом
- `14-notifications.md` — подписки, инбокс актора, ожидание новых событий
- `15-webhooks-sse.md` — доставка наружу вебхуками и поток событий для фронтенда
- `16-mcp-server.md` — MCP-сервер: работа с задачами, настройка процесса, уведомления агентам
- `17-public-api.md` — ревизия контракта, агрегаты под экраны, сквозные тесты, демо-данные
