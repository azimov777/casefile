# docs/tasks

Задания для агентов-исполнителей: один файл — одна задача, выполняемая за один заход.
Порядок запуска и зависимости — в `docs/ROADMAP.md`, общие правила — в `docs/CONVENTIONS.md`.

## Файлы
- `14a-remove-sprints.md` — убрать сущность «спринт» из кода, схемы, API и документации
- `14b-rules-sync-race.md` — синхронизация реестра правил должна переживать одновременный старт процессов
- `15-webhooks-sse.md` — доставка наружу вебхуками и поток событий для фронтенда
- `16-mcp-server.md` — MCP-сервер: работа с задачами, настройка процесса, уведомления агентам
- `17-public-api.md` — ревизия контракта, агрегаты под экраны, сквозные тесты, демо-данные
