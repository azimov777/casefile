# docs/tasks

Задания для агентов-исполнителей: один файл — одна задача, выполняемая за один заход.
Порядок запуска и зависимости — в `docs/ROADMAP.md`, общие правила — в `docs/CONVENTIONS.md`.

## Файлы

Очередь пуста: невыполненных заданий нет. Новая задача заводится файлом по общему
формату (зачем, объём, что учесть, готово когда, не входит) и строкой в этом списке,
в `docs/ROADMAP.md` и в графе зависимостей.
