# docs/tasks

Задания для агентов-исполнителей: один файл — одна задача, выполняемая за один заход.
Порядок запуска и зависимости — в `docs/ROADMAP.md`, общие правила и формат задания —
в `docs/CONVENTIONS.md`. Выполненная задача удаляется вместе со своей строкой в этом списке.
