# docs/tasks

Задания для агентов-исполнителей: один файл — одна задача, выполняемая за один заход.
Порядок запуска и зависимости — в `docs/ROADMAP.md`, общие правила — в `docs/CONVENTIONS.md`.
Выполненная задача удаляется вместе со своей строкой в этом списке.

## Файлы
- `20-remove-sprints.md` — удалить спринты, сохранив доски и ранжирование карточек
- `21-remove-portfolios.md` — удалить портфели, сохранив проекты и их прогресс
- `22-remove-checklists-macros.md` — удалить чеклисты и ручной запуск правил-макросов
- `23-remove-watchers.md` — удалить наблюдателей, оставив доставку через подписки
- `24-drop-resolutions.md` — заменить справочник резолюций необязательной причиной закрытия
