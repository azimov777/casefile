# 15. Вебхуки и стрим событий

- **Блок:** Каналы
- **Зависимости:** 06, 14
- **Результат:** события уходят наружу и в браузер

## Зачем

Инбокс — канал для агентов. Наружу нужны вебхуки (дёрнуть внешний скрипт, бота, CI), а
фронтенду — живой поток, чтобы интерфейс не опрашивал сервер.

## Объём

**Вебхуки:**

- Модель `WebhookSubscription`: адрес, набор типов событий, область (очередь, проект, все),
  секрет для подписи, включённость.
- Доставка с повторами и нарастающей задержкой, ограничение числа попыток.
- Подпись полезной нагрузки секретом, идентификатор доставки для защиты от повторной обработки.
- Журнал доставок: событие, адрес, код ответа, попытки, ошибка.
- Эндпоинты управления подписками, просмотр журнала, ручная переотправка.

**Стрим для фронтенда:**

- SSE-эндпоинт: поток событий, доступных текущему актору, с фильтром по очереди/проекту/задаче.
- Переподключение с указанием последнего полученного события.

## Что учесть

- Вебхук — сетевой вызов, он будет падать и висеть. Обязательны таймаут, ограничение попыток и
  отключение подписки после серии неудач: без этого мёртвый адрес будет вечно занимать воркер.
- Доставка минимум один раз, а не ровно один: получатель должен уметь распознать повтор по
  идентификатору доставки, и это надо описать в документации подписки.
- SSE-соединение живёт долго и держит ресурсы: нужны heartbeat, ограничение числа соединений и
  корректное закрытие при отключении клиента.
- Переподключение с «последнего события» требует хранения недавних событий — определить окно
  хранения и не обещать больше, чем система может отдать.
- Не отправлять во внешний вебхук лишнего: полезная нагрузка — событие и ключевые поля, а не
  дамп задачи целиком.

## Готово, когда

- Событие доходит до внешнего адреса, подпись проверяется, повторы работают.
- Мёртвый адрес отключается после серии неудач и виден в журнале.
- SSE отдаёт события в реальном времени и переживает переподключение.
- Тесты: доставка, повторы, подпись, поток SSE.

## Не входит

Очередь сообщений как внешняя инфраструктура.
