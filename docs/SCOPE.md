# Объём: что было и что становится

Инвентарь возможностей, реализованных по задачам 01–19 (состояние на коммит `49e2e49`),
и судьба каждой в переписывании под трекер для агентов. Новая модель описана
в `CONCEPT.md`; этот файл отвечает на вопрос «что из старого можно взять, а что уходит».

Подход: доменный слой переписывается заново. Из старого остаётся только то, что подходит
под новую концепцию без переделки; остальное удаляется целиком (задача 20), а не вырезается
по кусочку. Старый код доступен в git по коммиту `49e2e49`: оттуда берутся куски, которые
стоит перенести.

Статусы: **остаётся** — переносится как есть; **переделывается** — идея остаётся, код
пишется под новую модель; **уходит** — удаляется без замены.
