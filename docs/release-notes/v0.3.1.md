# Casefile v0.3.1

A small release of board fixes. The contract (REST and MCP) and the database are
unchanged since v0.3.0.

## Install

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/azimov777/casefile/main/install.sh | sh
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/azimov777/casefile/main/install.ps1 | iex
```

All you need is Docker. An installation from v0.2.0 on updates itself to this release
within about an hour, or at the next Docker start.

## What's new

- **The Links panel says how each group relates to the open task.** Group headings now
  read from the open task's point of view — **Parent**, **Child tasks**, **Blocking this
  task**, **Blocked by this task**, **Related** — instead of pairing a contract
  identifier such as `parent` with a label that seemed to say the opposite. The link
  kind is still on the element (`data-kind`) and in the case entries. The heading, its
  icon and the count sit on one baseline and on one line, on a phone too.
- **The bottom of a board column fades out cleanly.** A column with more cards than fit
  no longer ends in a grey strip over the last card's text, which looked blurred in
  Safari: the last 32 px of the column fade into the column's own background, and the fade
  stops cleanly at the column's scrollbar.
- **The board no longer rubber-bands.** With every column collapsed, scrolling past the
  edge on a Mac trackpad dragged the page and the column headings along with it. On
  screens 704 px and wider the board page now stays put (`overscroll-behavior-y: none`);
  the task list and narrow screens behave as before.

## Upgrade notes

No migration and no configuration change. The v0.3.0 updater installs this release, so
this is the first update covered by automatic rollback and the database snapshot (see
the v0.3.0 notes).

## Not verified yet

The board changes were measured in Chromium and Playwright's WebKit, not in Safari
itself; trackpad rubber-banding in particular is not reproduced by any automated test.
