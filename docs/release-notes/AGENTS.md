# release-notes

Черновики заметок к выпускам GitHub, по-английски — как и сама страница выпуска, на
которую они переносятся руками после «да» владельца на конкретный текст (TRK-81).

## Файлы
- `v0.1.0.md` — заметки к первому выпуску: что такое Casefile, установка для macOS/Linux
  и Windows, что входит в выпуск, как подключить агента
- `v0.2.0.md` — заметки ко второму выпуску: канал автообновления `stable`, учётные записи и перенос установки,
  токены агентов, история вопросов, MCP по stdio, заметки об обновлении (TRK-123 — исполнитель до `in_progress`)
- `v0.3.0.md` — заметки к третьему выпуску: один родитель и поля `parent`/`children` (ломающее, TRK-135), автооткат
  со снимком базы, публикация в реестр MCP, аннотации инструментов, заметки об обновлении и что не проверено
- `v0.3.1.md` — заметки к выпуску с правками доски: заголовки групп связей глазами открытой задачи, затухание
  низа столбца, доска без оттяжки (UI-168/169/170)
- `v0.4.0.md` — заметки к выпуску «проект вместо очереди»: пути REST, инструменты MCP, поле `project:`, коды ошибок
  и записи проекта в ленте (ломающее, TRK-152/144/146), дело проекта, атрибуты, архив, импорт архивов v0.3,
  заметки об обновлении и что не проверено (TRK-161)
- `v0.5.0.md` — заметки к выпуску переноса задачи между проектами: `POST /tasks/{key}/move`, MCP `move_task`,
  `previous_keys`, запись `moved`, прежний ключ работает везде, включая адрес интерфейса (не ломающее, TRK-172/173)
- `v0.5.1.md` — заметки к патч-выпуску: пакетный `move_task` списком ключей до 100, итог `moved`/`already`/`error`
  по каждому (не ломающее, TRK-309), установщики печатают порт доски из окружения раньше `.env` (TRK-169)
- `v0.6.0.md` — заметки к выпуску «первый вход»: экран «Начало», учебный проект START, пояснения и проход по экранам,
  состояние знакомства на сервере, `refs` только ссылки и URL (ломающее для агентов, TRK-375), поведение при обновлении:
  миграция с `skipped`, START не на установке с проектами, замена контейнера обновлятора (TRK-360/373)
- `v0.7.0.md` — заметки к выпуску «без учебного проекта»: START, фраза знакомства и настройки языка убраны (ломающее для
  агентов, TRK-387), «Пропустить» скрывает и пояснения (TRK-385), доска не даёт 502 после пересоздания api (TRK-388),
  автообновление убирает сирот и ждёт конца проверки обновлятора (TRK-390/391); поведение при обновлении (TRK-392)
- `v0.8.0.md` — заметки к выпуску «скил Casefile»: установщик ставит скил в найденные харнессы, маркетплейс плагина и канал `stable`, скил по SEP-2640, плашка нового выпуска и `TRACKER_RELEASE_CHECK`, тексты без разработки, указатель на скил в `instructions` (TRK-424)
- `v0.8.1.md` — заметки к патч-выпуску: проверка «стоит ли скил» в instructions и гайде (установке до v0.8.0 однажды `CASEFILE_SKILL_ONLY=1` или повтор строки установки, TRK-431), `tool_timeout_sec = 90` в блоке Codex (TRK-438), `title` у инструментов (TRK-443), сверка SEP-2640 (TRK-439), `wait_journal` на 2026-07-28 (TRK-440), `plugin validate --strict` (TRK-441), черновик поля отбора (TRK-423) (TRK-444)
- `v0.9.0.md` — заметки к выпуску «вход OAuth и плагин с коннектором»: при обновлении отзываются ключи людей, повтор строки установки ставит плагин и входит, ключ — харнессам без OAuth; наборов task/main нет, init без токена, экраны «Доступы» и «Подключить агента», сетевой режим со своими агентами `<клиент>_<человек>`, шесть миграций, что не проверено (TRK-482)
- `v0.9.1.md` — заметки к патч-выпуску: вход через плагин с адресом по умолчанию 127.0.0.1 (Claude Code и Codex отказывали: resource mismatch) — служба на петле называет себя узлом запроса, после обновления службы войти снова (`/mcp` → Authenticate, `codex mcp login casefile`); сверка resource (RFC 8707), `scopes_supported` и `scope` в 401, что не проверено (TRK-489, TRK-488, TRK-485, TRK-484)
- `v0.9.2.md` — заметки к патч-выпуску: маркетплейс плагина ставится с ветки `plugin`, прежняя установка переводится повторным запуском установщика (TRK-494); порты и имя проекта попадают в `.env` новой установки, старый `.env` не меняется (TRK-493); Hermes по `auth: oauth`, device-вход не поддержан (TRK-495); публичные страницы на azimov777.github.io/casefile (TRK-462); что не проверено (TRK-501)
- `v0.9.3.md` — заметки к патч-выпуску: повтор refresh в окне 30 с не отзывает цепочку, refresh чужим клиентом отзывает (TRK-504); установщик сохраняет адрес плагина, смена адреса просит войти снова (TRK-502); Cursor, Gemini CLI и OpenCode (TRK-496, TRK-497, TRK-498); скил — руководство по работе через MCP, установка в docs/agent-install.md (TRK-508, TRK-509); шрифты без Google (TRK-499); что не проверено (TRK-510)
