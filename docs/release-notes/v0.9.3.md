# Casefile v0.9.3

A patch release around sign-in and the agent plugin. A repeated refresh no longer drops a
sign-in, the installer keeps the plugin's address, Cursor, Gemini CLI and OpenCode join the
supported agents, and the skill is now a guide to working through the Casefile MCP server.

## Install

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/azimov777/casefile/main/install.sh | sh
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/azimov777/casefile/main/install.ps1 | iex
```

An installation on v0.9.2 updates its service to this release by itself within about an
hour, or at the next Docker start. The service has no migrations and no new settings.

## What's changed

- **A retried refresh is no longer treated as theft.** A client that repeats a refresh with the
  same token within 30 seconds (a lost response, a double click) gets the same result and its
  chain stays alive. Beyond the window, a refresh by another client revokes the whole chain
  (TRK-504).
- **The installer keeps the plugin's address.** Without `CASEFILE_URL` it reads the address of
  the plugin that is already installed and leaves it, so a sign-in stored under that address
  survives a re-run (`CASEFILE_SKILL_ONLY=1` used to rewrite `localhost` into `127.0.0.1` and
  drop the sign-in). If the address does change, the installer says "the address changed" and
  that you must sign in again, and prints the sign-in command after the marketplace moves
  (TRK-502).
- **New agents: Cursor, Gemini CLI and OpenCode.** Cursor gets a `.cursor-plugin` manifest,
  Gemini CLI a `gemini-extension.json` extension, and the installer prints an OpenCode block
  with OAuth sign-in and the skill from `~/.agents/skills`. The `plugin` branch carries the new
  manifests (TRK-496, TRK-497, TRK-498).
- **The skill is a guide to working through MCP.** It walks a task step by step: entering,
  keeping the case, handing the move over, splitting, closing with verdicts and `unmeasured`.
  It no longer installs Casefile and has no download-and-run commands; connecting, 401, the
  journal watcher and installing the skill itself are described in `docs/agent-install.md`
  (TRK-508, TRK-509).
- **Fonts without Google.** Fira Sans and Fira Code are served from the installation itself; the
  interface makes no request to Google Fonts (TRK-499).
- **Listing material.** A PNG icon and a privacy policy URL for the Anthropic portal (TRK-505),
  `interface.capabilities` and a support URL in the Codex manifest (TRK-506), a ZIP for the
  OpenAI catalog without the MCP connector (TRK-503).
- **Smaller fixes.** "Skip" and "I figured it out" in the first-run tour are disabled until
  the first frame is shown (TRK-490); a test compares the plugin command in the interface
  with the installer (TRK-507).

## Upgrade notes

- No migrations and no new settings.
- **Sign in again only if the plugin address changes.** Keeping the address keeps the
  sign-in; after a different `CASEFILE_URL`, run `/mcp` in Claude Code and choose
  Authenticate.
- **`CASEFILE_VERSION=0.9.3`** in `.env`, if you pin a release, is the line to change to move
  to this one by hand.

## Not verified yet

- **Cursor, Gemini CLI and OpenCode** were not checked against the real programs.
- The 30-second refresh window was checked by tests, not by a long-lived real client.
- The items of v0.9.0's, v0.9.1's and v0.9.2's "Not verified yet" (a full sign-in in Claude
  Code, long-lived sessions, desktop apps, a real TLS proxy, `install.ps1` end to end, Hermes
  with `auth: oauth`, the Pages address) are still open.
