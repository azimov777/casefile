# Casefile v0.1.0

Casefile is the task tracker your AI agents keep for each other: every task carries a
case file — decisions, failed attempts, findings, open questions — so the next agent,
with a fresh context and zero memory, picks up exactly where the last one stopped. You
watch it all on a live board.

## Install

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/azimov777/casefile/main/install.sh | sh
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/azimov777/casefile/main/install.ps1 | iex
```

All you need is Docker. The board opens at `http://localhost:8080`, and the installer
prints the one command that connects your agent. Casefile updates itself every time
Docker starts (`CASEFILE_AUTO_UPDATE=false` in `~/casefile/.env` turns that off).

## What's in this release

- **MCP server** over streamable HTTP: agents create and split tasks, record decisions
  and dead ends, ask the human questions, and close tasks with a verdict on every check.
- **REST API** (`/api/v1`) behind the web board, with its OpenAPI schema shipped as
  `openapi.json`.
- **Web board** (React + Vite): tasks by status and queue with direct parents shown on
  the card and in list rows, a task page with its full case file, a live journal, and
  screens to connect an agent and manage access tokens.
- **Guardrails, not bureaucracy**: no closing a task without a summary and a passed
  verdict per check, no starting a blocked task — and nothing else. A closing summary
  also names what the checks didn't measure. No sprints, no estimates, no automation.
- **Network mode**: local by default — Casefile listens on localhost only. Lock it with
  an owner password and set `CASEFILE_BIND` to reach it from other machines; sign-in is
  rate-limited per client address and by an install-wide ceiling. Casefile does not do
  TLS itself — put a reverse proxy in front beyond a network you trust.
- **Backup and restore**: a documented `pg_dump`/`pg_restore` procedure moves an
  installation's data into a clean one, on the same machine or a different one
  (`docs/backup-restore.md`).
- **[A skill for Claude Code](../../skill/tracker-agent/SKILL.md)** that teaches the
  case-file discipline.
- MIT-licensed; contributions are sign-off (DCO) verified in CI.

## Connect your agent

The installer prints a ready-made command with your token and its actual MCP address
filled in — by default:

```bash
claude mcp add --transport http --scope user casefile http://localhost:8100/mcp \
  --header "Authorization: Bearer <token>"
```

Any other MCP client works the same way: streamable HTTP at the MCP address the
installer printed (`http://localhost:8100/mcp` by default) with that header. Or let your
agent install and connect itself by following
[`docs/agent-install.md`](../agent-install.md).
