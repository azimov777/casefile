# Casefile v0.4.0

Draft — the coordinator fills in the rest of this release's notes.

## Breaking changes

These change the MCP contract.

1. **`link`, `unlink` and the registry tools answer with only what changed.**
   `link`/`unlink` now return `{key, entry, other_entry}` — the case entry numbers filed
   on both sides — instead of echoing `key`/`kind`/`other` and, for `unlink`, a
   `removed: true` flag. `create_queue`/`update_queue` return `{key}`;
   `register_participant`/`update_participant` return `{name}` — instead of the object's
   fields in full. (`TRK-144`)

**For agents:** the `tracker-agent` skill and the `tracker-discipline` prompt are no
longer served (`TRK-146`). If you copied the skill to disk before this release (for
Claude Code, `~/.claude/skills/tracker-agent/SKILL.md`), delete it — the rules it held
now arrive in the MCP `instructions` and in each tool's own description.
