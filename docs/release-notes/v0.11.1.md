# Casefile v0.11.1

A fixing release: dependency updates and one flaky end-to-end test made stable. No change
in behaviour, no migrations, no change in the API or the MCP tools.

## Install

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/azimov777/casefile/main/install.sh | sh
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/azimov777/casefile/main/install.ps1 | iex
```

An installation on v0.11.0 updates its service to this release by itself within about an
hour, or at the next Docker start. This release has no migrations.

## What's changed

- **uv in the images: 0.12.19 → 0.12.22** (Dependabot PR #7,
  https://github.com/azimov777/casefile/pull/7). The changelog has nothing breaking
  (TRK-587).
- **ruff 0.16.8 → 0.16.9 and uvicorn 0.53.0 → 0.54.0 in `uv.lock`** (Dependabot PR #8,
  https://github.com/azimov777/casefile/pull/8). The changelogs have nothing breaking
  (TRK-588).
- **The end-to-end test `reason-line.spec.ts` waits for the paragraph of the entry**, not
  for the "Now" block. This removes a flickering failure; the interface itself is not
  changed (TRK-586).

## Upgrade notes

- **Nothing to do for the clients:** the tool schemas are the same as in v0.11.0.
- **No migrations.** The REST schema in `openapi.json` changed only in its version.
- **`CASEFILE_VERSION=0.11.0`** in `.env`, if you pin a release, is the line to change to
  move to this one by hand.

## Not verified yet

- The items of v0.11.0's "Not verified yet" are still open; this release adds nothing to
  them and does not close any.
