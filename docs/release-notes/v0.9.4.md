# Casefile v0.9.4

A patch release for the interface: tables in case entries keep short words whole.

## Install

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/azimov777/casefile/main/install.sh | sh
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/azimov777/casefile/main/install.ps1 | iex
```

An installation on v0.9.3 updates its service to this release by itself within about an
hour, or at the next Docker start. The service has no migrations and no new settings.

## What's changed

- **Markdown tables no longer break words letter by letter.** A short column next to a long
  one used to shrink to a single letter ("S/i/l/a" stacked down the cell): the cells
  inherited `overflow-wrap: anywhere`, which lets the table squeeze a column below its
  longest word. Cells now wrap only between words, and a table wider than the screen scrolls
  sideways inside its own box instead of widening the page (TRK-532).

## Upgrade notes

- No migrations and no new settings.
- **`CASEFILE_VERSION=0.9.3`** in `.env`, if you pin a release, is the line to change to move
  to this one by hand.
