# docs/assets

Картинки страницы проекта на GitHub: скриншоты интерфейса для `README.md` и карточка
предпросмотра ссылки.

## Файлы
- `demo-dark.gif` — запись для README (TRK-82), тёмная тема (пара с `demo-light.gif`,
  переключаются `<picture>` по `prefers-color-scheme` — как раньше `board-dark.png`):
  агент заводит задачу и ведёт её через REST/MCP, доска подхватывает карточку и статусы
  сама, на странице задачи видно, что записи оставил агент. Заменяет прежний статичный
  `board-light.png`/`board-dark.png` — тот дублировал бы первый и последний кадр записи.
  Снята `ui/e2e-demo/demo-recording.spec.ts` на отдельном изолированном контуре (не тот,
  что поднимает `pnpm e2e`), исходное видео в GIF сведено `ffmpeg` в контейнере — команды
  в `ui/e2e-demo/README.md`
- `demo-light.gif` — та же запись, светлая тема
- `question-dark.png` — скриншот задачи с блокирующим вопросом владельцу для README, тёмная тема (пара с `question-light.png`)
- `question-light.png` — тот же скриншот задачи с вопросом, светлая тема
- `social-preview.png` — карточка предпросмотра ссылки 1280×640; в README не ссылается, загружается вручную в настройках репозитория на GitHub
