# docs

Справочник ошибок и публичные руководства. Что строим и как строим — не здесь:
решения проекта `TRK` и областей в трекере.

## Папки
- `assets/` — картинки страницы на GitHub: записи и скриншоты для `README.md`, карточка превью ссылок

## Файлы
- `agent-install.md` — установка Casefile для агента, по-английски: на него ведёт фраза из `README.md`
- `backup-restore.md` — снятие `pg_dump` и подъём чистой установки из него, по-английски: что делать
  с токенами дампа, чего процедура не делает
- `ERRORS.md` — справочник кодов ошибок с описанием, когда какой возникает; собирается командой
- `moving.md` — перенос своей установки на другую машину или сервер без shell, по-английски: выгрузка
  и приём архива через REST, версии, что становится с людьми и токенами
