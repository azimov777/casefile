# docs

Проектная документация бэкенда трекера для агентов: что строим и по каким правилам.
Точка входа для нового агента — `CONCEPT.md`, затем `CONVENTIONS.md`, затем своя задача
в очереди `TRK` трекера.

## Папки
- `assets/` — картинки страницы на GitHub: скриншоты для `README.md` (светлая и тёмная тема) и карточка
  `social-preview.png` 1280×640 для превью ссылок — её загружают руками в настройках репозитория
- `notes/` — находки и грабли от предыдущих агентов; читается до начала работы; заметки живут,
  пока жив описанный ими код, и уходят вместе с ним
- `release-notes/` — черновики заметок к выпускам GitHub, по-английски

## Файлы
- `agent-install.md` — установка Casefile для агента, по-английски: на него ведёт фраза из `README.md`
- `CONCEPT.md` — доменная модель трекера для агентов: принципы, задача, дело, связи, лента, интерфейсы,
  отвергнутые варианты; единый источник по «что и почему»
- `CONVENTIONS.md` — обязательные правила: стек, слои, контракт API, журнал, тесты, коммиты,
  протокол выполнения задачи
- `DEVELOPMENT.md` — руководство разработчика бэкенда: контуры в Docker, миграции, демо-данные, доступ к API,
  MCP, тесты, слияние веток, продакшен-контур, переменные окружения
- `ERRORS.md` — справочник кодов ошибок с описанием, когда какой возникает; собирается командой
