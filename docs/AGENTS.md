# docs

Проектная документация бэкенда трекера для агентов: что строим, по каким правилам и в каком порядке.
Точка входа для нового агента — `CONCEPT.md`, затем `CONVENTIONS.md`, затем свой файл задачи.

## Папки
- `notes/` — находки и грабли от предыдущих агентов; читается до начала работы; заметки живут,
  пока жив описанный ими код, и уходят вместе с ним
- `tasks/` — задания для агентов-исполнителей, по одному файлу на задачу; выполненные удаляются

## Файлы
- `CONCEPT.md` — доменная модель трекера для агентов: принципы, задача, дело, связи, лента, интерфейсы,
  отвергнутые варианты; единый источник по «что и почему»
- `ERRORS.md` — справочник кодов ошибок с описанием, когда какой возникает; собирается командой
- `FRONTEND.md` — документ для разработчика интерфейса: четыре экрана человека, первый экран, контракт, поток;
  пути и коды ошибок в нём сверяются с кодом тестом
- `CONVENTIONS.md` — обязательные правила: стек, слои, контракт API, журнал, тесты, коммиты,
  формат задания, протокол выполнения задачи
- `ROADMAP.md` — история задач 01–35 одним абзацем и решения, отложенные до наблюдений;
  очередь `tasks/` пуста
