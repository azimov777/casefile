# docs

Документация бэкенда: справочник ошибок, заметки и публичные
руководства. Что строим и как строим — не здесь: точка входа для нового агента — действующие
решения проекта `TRK` и области своей задачи в трекере (протокол выполнения задачи — TRK#233),
затем своя задача.

## Папки
- `assets/` — картинки страницы на GitHub: скриншоты для `README.md` (светлая и тёмная тема) и карточка
  `social-preview.png` 1280×640 для превью ссылок — её загружают руками в настройках репозитория
- `notes/` — находки и грабли от предыдущих агентов; читается до начала работы; заметки живут,
  пока жив описанный ими код, и уходят вместе с ним
- `release-notes/` — черновики заметок к выпускам GitHub, по-английски

## Файлы
- `agent-install.md` — установка Casefile для агента, по-английски: на него ведёт фраза из `README.md`
- `backup-restore.md` — снятие `pg_dump` и подъём чистой установки из него, по-английски: что делать
  с токенами дампа, чего процедура не делает; проверено на TRK-96
- `ERRORS.md` — справочник кодов ошибок с описанием, когда какой возникает; собирается командой
- `moving.md` — перенос своей установки на другую машину или сервер без shell, по-английски: выгрузка
  и приём архива через REST, версии, что становится с людьми и токенами; TRK-100
