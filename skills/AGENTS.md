# skills

Скилы Casefile для агентов в формате agentskills.io; их отдают и плагин (ветка `plugin`), и MCP-сервер
(ресурсы `skill://…`). У каталогов скилов своих карт нет: всё, что в них лежит, уезжает агенту.
Формат файлов сверяют `tests/test_skill_file.py` и `tests/test_skill_setup_file.py`.

## Папки
- `casefile-setup/` — скил `casefile-setup`: как подключить Casefile там, где агент работает; срабатывает сам, только когда инструментов Casefile нет или они отвечают 401; в ZIP для каталога OpenAI его нет
- `casefile/` — скил `casefile`: как вести задачу через MCP Casefile — шаги цикла, проверки между ними, передача хода, примеры вызовов
