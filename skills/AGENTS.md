# skills

Скилы Casefile для агентов в формате agentskills.io, их два (TRK-566). Скил `casefile` учит работе с задачей через
MCP Casefile: шаги цикла по порядку, проверки между ними, условия передачи хода и примеры
вызовов (слово владельца, TRK-509). Сами правила живут в `app/mcp/instructions.md` и
метадате инструментов и в скил не переписываются (TRK-140#8): скил на них ссылается.
Подключение, 401, сторож журнала и установка скила — в `docs/agent-install.md`; скил
ссылается на него одной фразой и не несёт команд установки, ключей и внешних скриптов.

Скил `casefile-setup` ведёт агента и человека к подключению там, где они работают, и срабатывает
сам только когда инструментов Casefile нет или они отвечают 401: отключить один скил плагина в
Claude Code нельзя, условие держит его `description`. Он тоже без команд установки и ключей;
в ZIP для каталога OpenAI его нет, а MCP-сервер, читающий весь каталог, отдаёт и его.

Файл `casefile/SKILL.md` один на оба канала доставки: плагин маркетплейса по узкой ветке `plugin` (TRK-494)
и MCP-сервер по SEP-2640 (ресурс `skill://casefile/SKILL.md`). Своей карты у
каталогов скилов нет: всё, что в нём лежит, уезжает агенту. Формат держат
`tests/test_skill_file.py` и `tests/test_skill_setup_file.py`.

## Папки
- `casefile-setup/` — скил `casefile-setup`: единственный файл `SKILL.md`, как подключить Casefile в Claude Code, Codex, Cursor, чате Claude Desktop и claude.ai; `description` начинается с условия «нет инструментов Casefile или 401», текст по-английски
- `casefile/` — скил `casefile`: единственный файл `SKILL.md`, фронтматтер `name` и `description`, текст для модели по-английски
