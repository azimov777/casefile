# app/services

Сценарии приложения: оркестрация домена, работа с репозиториями, служебные записи дела.
Один сценарий — одна функция, вызываемая и из REST, и из MCP, и из командной строки;
дублировать логику в интерфейсах нельзя.

Транзакцию сценарии не фиксируют: границу держит вход в приложение (`get_session` для
запроса, `session_scope` для MCP-сервера и команды). `flush` внутри сценария допустим и нужен.

Здесь фундамент, ядро задачи, дело, связи между задачами, отбор задач, лента журнала,
идемпотентность создающих вызовов, первый экран и демо-данные — один механизм на REST
и на MCP.
Ожидание ленты — единственный сценарий, который коммитит сам: он висит десятки секунд и
обязан отпустить соединение из пула на время сна.

## Файлы
- `__init__.py` — маркер пакета
- `auth.py` — аутентификация по секрету токена и метке; отдаёт структуру автора с набором
- `bootstrap.py` — первый экран одним вызовом: участник за токеном, очереди, число открытых вопросов к нему
- `case.py` — дело: записи агента и служебные, чтение с фильтрами, опись, признаки, вопросы поперёк задач
- `demo.py` — демонстрационные данные настоящими сценариями: очередь `DEMO`, все статусы, все типы записей, три вида связей
- `idempotency.py` — выполнить один раз на ключ: занять пару «токен и ключ», сделать работу, сохранить ответ для повтора
- `journal.py` — лента журнала: хвост по `seq` с фильтрами, долгое ожидание на оповещениях, поток и счётчик его соединений
- `links.py` — связи: поставить и снять с записью в делах обеих задач, проверка циклов, признак `blocked`
- `participants.py` — участники: зарегистрировать, изменить описание, прочитать, перечислить
- `permissions.py` — единая точка проверки прав: проверяет набор токена и ничего больше
- `queues.py` — очереди: создать, изменить, прочитать, перечислить, выдать номер задачи
- `search.py` — отбор задач: склейка строки запроса со структурным фильтром, разрешение имён и значений, страница
- `setup.py` — первичная инициализация: владелец и его первый токен на пустой установке
- `tasks.py` — задачи: создать, пакет преемника, единая точка мутаций с версией, переход по таблице с фактами из дела, закрытие одной транзакцией
- `tokens.py` — токены: выпустить (с участником или общий агентский), перечислить, отозвать
