# app/core

Инфраструктура, нужная всем слоям и ни от одного из них не зависящая: конфигурация,
логирование, базовые типы исключений. Импортировать отсюда можно откуда угодно.

## Файлы
- `__init__.py` — маркер пакета
- `config.py` — настройки из переменных окружения с валидацией; `get_settings()` кеширует их на процесс
- `errors.py` — `AppError` и базовые семейства ошибок; наследники несут стабильный код ошибки
- `logging.py` — единый формат логов для сервера, воркеров и тестов
