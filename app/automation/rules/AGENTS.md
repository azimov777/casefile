# app/automation/rules

Правила автоматики, поставляемые с проектом: по одному на каждую форму. Новое правило —
новый файл здесь плюс строка в `RULE_MODULES` (`app/automation/registry.py`); движок,
воркер и планировщик при этом не трогаются.

Правило приезжает с выкладкой **выключенным** и включается через API. Параметры описываются
моделью Pydantic рядом с телом правила: по ней их проверяют при сохранении и по ней же
интерфейс строит форму настройки.

## Файлы
- `__init__.py` — маркер пакета; список правил живёт в реестре, а не здесь
- `close_children_with_parent.py` — триггер: родителя закрыли — закрыть подзадачи или назвать их вслух
- `nudge_stale_issues.py` — автодействие: напомнить о задачах без движения, с собственным сроком молчания
- `prepare_release.py` — макрос: оформить задачу как релизную одним вызовом
