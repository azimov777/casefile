# app/mcp

MCP-сервер для агентов. Вызывает те же сценарии из `services`, что и HTTP-слой, и ничего не
знает про `api`. Запуск — `python -m app.mcp`, сервис Compose `mcp`.

Через сервер агент проходит весь цикл задачи, не касаясь REST: двадцать один инструмент
(семнадцать открывает набор `task`, четыре добавляет `main`), промпт `tracker-discipline`
с текстом скила и выжимка из него в `instructions` при подключении. Состав `tools/list`
зависит от набора токена; отказ на вызове приходит из той же единой точки прав, что и в
REST. Прежние инструменты доступны в git по коммиту `49e2e49`.

## Папки
- `tools/` — сами инструменты по областям: задачи, дело, связи, реестры, лента

## Файлы
- `__init__.py` — назначение пакета и границы слоя
- `__main__.py` — точка входа: streamable HTTP своим процессом, слушатель оповещений журнала
- `server.py` — сборка сервера: инструменты, промпт дисциплины, инструкции, проверка здоровья
- `toolset.py` — регистрация инструмента с набором токена и фильтр `tools/list` по набору
- `runtime.py` — контекст вызова: сессия БД, автор запроса за токеном и меткой, заголовки сообщения
- `arguments.py` — аннотации аргументов и вложенные модели: описания-контракты, которые читает модель
- `views.py` — данные наружу: задача, короткие ответы изменения, подшивки и закрытия, запись дела, связь, очередь, участник, страница
- `idempotency.py` — ключ повтора у создающего инструмента: имя операции берётся у функции
- `errors.py` — доменная ошибка в ошибку инструмента или ресурса, с кодом и подробностями
- `skill.py` — текст скила: промпт целиком и раздел «Кратко» для `instructions`
