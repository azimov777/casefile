# app/mcp

MCP-сервер для агентов. Вызывает те же сценарии из `services`, что и HTTP-слой, и ничего не
знает про `api`. Запуск — `python -m app.mcp`, сервис Compose `mcp`.

Через сервер агент проходит весь цикл задачи, не касаясь REST: инструменты
и свой текст `instructions` при подключении — как пользоваться сервером. Наборов доступа
нет: любой действующий доступ видит весь `tools/list`. Точный список — `tools/list`
самого сервера, а не пересказ здесь
(`docs/CONVENTIONS.md`, «Документация»). Прежние инструменты доступны в git по коммиту
`49e2e49`.

## Папки
- `tools/` — инструменты: папка на группу (задачи, дело, связи, реестры, лента), файл на инструмент

## Файлы
- `__init__.py` — назначение пакета и границы слоя
- `__main__.py` — точка входа: streamable HTTP своим процессом или stdio по `--stdio` с токеном процесса, слушатель оповещений журнала
- `server.py` — сборка сервера: инструменты, инструкции, проверка здоровья, вход OAuth и слой причин `401` поверх приложения
- `skills.py` — скил Casefile по SEP-2640: расширение `io.modelcontextprotocol/skills`, ресурсы `skill://casefile/…`, объявление на рукопожатии старой эпохи
- `toolset.py` — регистрация инструмента: аннотации, ключ повтора у создающего, запрет лишнего аргумента, отказ неизвестному токену на `tools/list`
- `consent.py` — страница входа OAuth в сетевом режиме `/oauth/consent`: почта и пароль, выбор участника, согласие или отказ; повторные проверки запроса `/authorize`, CSRF, свой узел
- `oauth.py` — служба как защищённый ресурс и сервер авторизации OAuth 2.1: провайдер SDK поверх `services/oauth.py`, проверка любого bearer на транспорте, причина отказа в `401`, сервер авторизации только на https или петле; проверка узла `/mcp` в сети; клиент SDK со сравнением адреса на петле без порта, метаданные с CIMD и методом `none`
- `runtime.py` — контекст вызова: сессия БД, автор запроса за токеном и меткой, заголовки сообщения
- `arguments.py` — аргументы, общие для разных групп (ключи, страница, ключ повтора), и правила текста метадаты
- `enums.py` — перечисления домена в схеме `tools/list`: значения из домена, английское описание вместо русской докстроки
- `views.py` — формы ответа, общие для разных групп (автор, проект строкой, страница), и почему ответы короткие
- `idempotency.py` — ключ повтора у создающего инструмента: имя операции берётся у функции
- `errors.py` — доменная ошибка в ошибку инструмента или ресурса, с кодом и подробностями
- `instructions.md` — текст `instructions` сервера: как пользоваться трекером, не длиннее 2048 символов
