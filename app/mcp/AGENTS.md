# app/mcp

MCP-сервер для агентов: инструменты, ресурсы, нотификации. Вызывает те же сценарии из `services`,
что и HTTP-слой, и ничего не знает про `api`. Запуск — `python -m app.mcp`, сервис Compose `mcp`.

## Папки
- `tools/` — инструменты по областям работы: задачи, обсуждение, связи, очереди, проекты,
  доски, автоматика, инбокс, настройка процесса

## Файлы
- `__init__.py` — назначение пакета и границы слоя
- `__main__.py` — точка входа: streamable HTTP на своём порту, отдельным процессом
- `server.py` — сборка сервера: инструкции для модели, регистрация инструментов и ресурсов,
  жизненный цикл, маршрут проверки здоровья
- `runtime.py` — контекст вызова: сессия БД, актор за токеном, заголовки сообщения
- `refs.py` — разрешение ссылок: строка от агента в объект, который ждёт сценарий
- `views.py` — компактные представления объектов: выбор полей, усечение текстов, страницы
- `resources.py` — ресурсы: список очередей, словарь статусов, «кто я», инбокс актора
- `push.py` — MCP-нотификации: сигнал «инбокс обновился» поверх оповещений PostgreSQL
- `errors.py` — доменная ошибка в ошибку инструмента или ресурса, с кодом и подробностями
