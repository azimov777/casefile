# app/mcp/tools/files

Инструменты файлов: байты не идут через инструмент, только ссылка (`app/mcp/file_links.py`) и карточка.
Прикладывает файл к записи аргумент `files` инструментов дела. Реестр группы — `TOOLS` в `__init__.py`:
он же задаёт порядок в `tools/list`.

## Файлы
- `__init__.py` — реестр группы: модули инструментов по порядку `tools/list`
- `arguments.py` — идентификатор файла, имя, тип; разбор идентификатора с отказом `file_not_found`
- `views.py` — карточка файла и выданная ссылка с командой `curl`
- `request_file_upload.py` — `request_file_upload`: ссылка и команда `curl -T` для нового файла в проект
- `request_file_replace.py` — `request_file_replace`: ссылка и команда `curl -T` для замены содержимого под тем же идентификатором
- `read_file.py` — `read_file`: изображение содержимым `image` после карточки; документ — карточка и ссылка `curl -o`; удалённый — надгробие
- `list_files.py` — `list_files`: карточки файлов страницами, поиск по имени, отбор по проекту и типу, сортировка
- `delete_file.py` — `delete_file`: стереть байты и оставить надгробие
