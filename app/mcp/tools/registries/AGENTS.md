# app/mcp/tools/registries

Инструменты по реестрам проектов, их направлений и участников: файл на инструмент. У направления (`CONCEPT.md`, 3.7) своих инструментов нет: его заводят, читают, правят, архивируют и ведут атрибуты и дело инструменты проекта по адресу `ПРОЕКТ/ключ` (`CaseOwnerKeyArg`); почему — замер в деле TRK-555. Реестр группы — `TOOLS` в `__init__.py`: он же задаёт порядок в `tools/list`.

## Файлы
- `__init__.py` — реестр группы: модули инструментов по порядку `tools/list`
- `arguments.py` — описание участника, общее для регистрации и правки; имя атрибута, общее для задания и снятия; причина архива проекта или направления
- `views.py` — короткие ответы записи: ключ проекта или адрес направления, имя участника, итог архива
- `get_project.py` — `get_project`: проект с описанием, атрибутами, действующими решениями, направлениями и описью его дела; по адресу — направление в той же форме
- `list_projects.py` — `list_projects`: проекты строкой с временем архива, страницами; архивные — с `include_archived`
- `list_participants.py` — `list_participants`: реестр участников, страницами
- `create_project.py` — `create_project`: ключ, название и описание нового проекта; по адресу `ПРОЕКТ/ключ` — нового направления
- `update_project.py` — `update_project`: новое название и описание проекта или направления, прежние — в `field_changed` его дела
- `archive_project.py` — `archive_project`: заморозить проект и его задачи или направление с причиной, запись `archived`
- `restore_project.py` — `restore_project`: вернуть проект или направление из архива с причиной, запись `restored`
- `set_attribute.py` — `set_attribute`: завести атрибут проекта или направления или изменить значение; тип записи выбирает трекер
- `remove_attribute.py` — `remove_attribute`: снять атрибут с причиной, последнее значение — в `attribute_removed`
- `register_participant.py` — `register_participant`: род и имя нового участника
- `update_participant.py` — `update_participant`: новое описание участника
