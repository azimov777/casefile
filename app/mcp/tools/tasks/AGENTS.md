# app/mcp/tools/tasks

Инструменты по задачам: файл на инструмент, в нём описание, аргументы, форма ответа и вызов
сценария. Реестр группы — `TOOLS` в `__init__.py`: он же задаёт порядок в `tools/list`.

## Файлы
- `__init__.py` — реестр группы: модули инструментов по порядку `tools/list`
- `views.py` — формы ответа нескольких инструментов группы: карточка, признаки, короткий ответ изменения
- `get_task.py` — `get_task`: пакет преемника, связи со стороны задачи
- `search_tasks.py` — `search_tasks`: аргументы отбора, строка выдачи, обрезка длинного текста
- `create_task.py` — `create_task`: поля и пять разделов новой задачи, ребёнок родителя
- `update_task.py` — `update_task`: частичная правка вложенной моделью `changes`
- `transition.py` — `transition`: целевой статус и причина перехода
- `close_task.py` — `close_task`: финальная сводка, вердикты и записи закрытия, ответ закрытия
- `move_task.py` — `move_task`: перенос в другой проект с причиной, набор `main`; ключ строкой — ответ с новым и прежними ключами, списком — итог по каждому ключу
