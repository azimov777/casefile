# app/mcp/tools/discussions

Инструменты обсуждения, которых нет у инструментов дела, проекта и связей: итог и закрытие
с итогом. Вопрос, ответ, заметка, чтение дела и привязка задачи — `ask`, `answer`,
`add_project_entry`, `read_project_entries`, `link`/`unlink` по адресу `TRK~7`. Реестр
группы — `TOOLS` в `__init__.py`: он же задаёт порядок в `tools/list`.

## Файлы
- `__init__.py` — реестр группы: модули инструментов по порядку `tools/list`
- `arguments.py` — части итога «решено», «заменено», «открыто», общие для обоих инструментов
- `add_conclusion.py` — `add_conclusion`: итог без закрытия
- `close_discussion.py` — `close_discussion`: итог и закрытие одной транзакцией, ответ — адрес, статус и номера записей
