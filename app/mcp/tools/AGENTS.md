# app/mcp/tools

Инструменты MCP, разложенные по областям работы агента. Каждый модуль объявляет функцию
`register(server, runtime)` и ничего больше; список модулей — в `__init__.py`, там же
задан порядок, в котором инструменты видит модель.

## Файлы
- `__init__.py` — реестр модулей и `register_all`
- `issues.py` — поиск, чтение с уровнями детализации, создание, частичное обновление,
  назначение исполнителя, переходы воркфлоу
- `discussion.py` — лента комментариев и чеклист задачи
- `links.py` — связи задач и дерево подзадач
- `queues.py` — список очередей и конфигурация очереди целиком
- `projects.py` — проекты, портфели и состав проекта
- `boards.py` — доски, карточки колонок, перенос и ранжирование карточек
- `automation.py` — правила автоматики: список, настройка, запуск макроса
- `notifications.py` — инбокс: чтение, отметка прочитанным, ожидание новых
- `setup.py` — настройка процесса: очередь, справочники, воркфлоу, поля; `dry_run`
