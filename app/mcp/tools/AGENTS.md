# app/mcp/tools

Инструменты MCP — тонкий слой над сценариями `services`: папка на группу, файл на инструмент
(`<группа>/<имя>.py` — описание, аргументы, форма ответа и вызов сценария). Инструмент подключается
строкой в `TOOLS` своей группы, группа — строкой в `REGISTRARS` из `__init__.py`.

## Папки
- `tasks/` — задачи: пакет преемника, отбор, создание с родителем, частичная правка, переход, закрытие
- `case/` — дело: чтение записей, сводка, запись без нагрузки, вопрос (в обсуждении), ответ, резолюция, вердикт; чтение и запись дела проекта
- `discussions/` — обсуждения: итог и закрытие с итогом; вопрос, ответ, заметка, чтение и привязка — инструментами дела, проекта и связей по адресу
- `links/` — связи: поставить и снять; вид называет роль задачи из `key`; вид `attached` — привязка задачи к обсуждению
- `registries/` — реестры: проекты и участники: чтение и запись
- `journal/` — лента: хвост журнала с долгим ожиданием на оповещениях

## Файлы
- `__init__.py` — сборка: реестр групп `REGISTRARS` и общие границы инструментов
