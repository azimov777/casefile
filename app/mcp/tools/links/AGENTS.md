# app/mcp/tools/links

Инструменты по связям: файл на инструмент, общие для пары аргументы и ответ — рядом. Реестр
группы — `TOOLS` в `__init__.py`: он же задаёт порядок в `tools/list`.

## Файлы
- `__init__.py` — реестр группы: модули инструментов по порядку `tools/list`
- `arguments.py` — сторона `key` (задача или адрес области), вид связи ролью `key` (`attached` — привязка к обсуждению, `see_also` — связь областей), другая сторона и причина связи областей, общие для `link` и `unlink`
- `views.py` — ответ обоих: номера записей, подшитых в оба дела
- `link.py` — `link`: поставить связь, отказы по видам и закрытой задаче; с `attached` — привязать задачу к обсуждению; по адресам областей — связь `see_also` с причиной
- `unlink.py` — `unlink`: снять связь с любой стороны; с `attached` — отвязать задачу от обсуждения; по адресам областей — снять `see_also`
