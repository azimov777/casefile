# app/mcp/tools/links

Инструменты по связям: файл на инструмент, общие для пары аргументы и ответ — рядом. Реестр
группы — `TOOLS` в `__init__.py`: он же задаёт порядок в `tools/list`.

## Файлы
- `__init__.py` — реестр группы: модули инструментов по порядку `tools/list`
- `arguments.py` — вид связи ролью `key` (и `attached` — привязка к обсуждению) и задача или обсуждение на другой стороне, общие для `link` и `unlink`
- `views.py` — ответ обоих: номера записей, подшитых в оба дела
- `link.py` — `link`: поставить связь, отказы по видам и закрытой задаче; с `attached` — привязать задачу к обсуждению
- `unlink.py` — `unlink`: снять связь с любой стороны; с `attached` — отвязать задачу от обсуждения
