# app/mcp/tools/journal

Инструмент ленты журнала. Реестр группы — `TOOLS` в `__init__.py`: он же задаёт порядок в
`tools/list`.

## Файлы
- `__init__.py` — реестр группы; почему фильтр ленты разрешает домен, а не инструмент
- `wait_journal.py` — `wait_journal`: курсор `after`, фильтры задач и проекта, ожидание `timeout`
