# app

Код бэкенда по слоям: входы `api` (REST) и `mcp` (MCP-сервер), сценарии `services`, домен `domain`,
база `db`, общая инфраструктура `core`; границы слоёв — решение TRK#215.

## Папки
- `api/` — HTTP-слой: роутеры, схемы запросов и ответов, превращение исключений в ответы
- `core/` — конфигурация, логирование, базовые исключения, общие всем слоям
- `db/` — подключение к PostgreSQL, модели SQLAlchemy, миграции Alembic
- `domain/` — доменные модели и бизнес-правила в чистом Python
- `mcp/` — MCP-сервер для агентов: инструменты рабочего цикла, промпт дисциплины; запуск `python -m app.mcp`
- `services/` — сценарии: оркестрация домена, транзакции, служебные записи дела

## Файлы
- `__init__.py` — версия приложения (`__version__`), читается из `pyproject.toml`, больше ничего
- `cli.py` — командная строка: первичная настройка установки, выпуск токенов, ключ локального интерфейса в файл, хеш пароля владельца, выгрузка артефактов
- `main.py` — фабрика `create_app` и объект `app` для uvicorn: сборка приложения из слоёв
