# app/db/migrations

Окружение Alembic. Миграции применяются явной командой (`docker compose run --rm migrate`),
а не при старте приложения: параллельный накат из нескольких реплик портит схему.

## Папки
- `versions/` — сами миграции, применяются по цепочке `down_revision`

## Файлы
- `env.py` — подключение асинхронным движком и адрес БД: `-x database_url`, затем ini, затем настройки; либо готовое соединение и схема таблицы версии из `config.attributes` — так миграции гоняет приём архива
- `script.py.mako` — шаблон новой ревизии: типизированные заголовки и пустые `upgrade`/`downgrade`
