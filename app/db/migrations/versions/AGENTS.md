# app/db/migrations/versions

Версии схемы. Имя файла начинается с даты и времени создания, порядок применения задаётся полем
`down_revision` внутри файла, а не именем. Правка уже применённой ревизии запрещена — нужна новая.

## Файлы
- `20*_*.py` — ревизии Alembic; первая (`initial empty schema`) пустая и держит начало цепочки
