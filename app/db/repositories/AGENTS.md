# app/db/repositories

Доступ к данным: сборка запросов и выдача ORM-объектов. Бизнес-правил здесь нет —
они в `app/services`. Транзакцией репозиторий не управляет никогда: `flush` вызывать
можно, `commit` и `rollback` — нельзя, границу держит вход в приложение.

## Файлы
- `__init__.py` — реэкспорт репозиториев, чтобы сценарии импортировали их из одного места
- `actors.py` — акторы: поиск по ключу и идентификатору, страница списка с фильтрами
- `api_tokens.py` — токены: поиск по хешу при аутентификации, токены актора, отзыв
- `automation.py` — состояние правил и журнал срабатываний: заведение строк атомарной вставкой, захват созревших правил, счёт для защиты от циклов
- `boards.py` — доски и порядок карточек: соседние позиции и перенумерация одним запросом
- `catalogs.py` — один репозиторий на три справочника; выборка по области действия
- `checklists.py` — пункты чеклиста задачи по порядку; списком целиком, без пагинации
- `comments.py` — лента обсуждения задачи страницами; удалённые остаются в выдаче плашкой
- `events.py` — история задачи страницами, захват события воркером и чтение потока с позиции
- `fields.py` — реестр полей: выборка по области и по применимости к типу задачи
- `issues.py` — задачи: выборка, словарь тегов, счётчики использования и атомарный перенос статуса
- `links.py` — связи задач: обе стороны одним запросом, дети уровнями, рекурсивный подъём к предкам
- `notifications.py` — подписки и инбокс: подбор подписок под одно событие, поиск записи для склейки
- `projects.py` — проекты и портфели: счётчики задач пачкой, рекурсивный обход вложенности, состав одним списком
- `queues.py` — очереди, привязки типов задач и атомарная выдача номеров задач
- `saved_filters.py` — сохранённые фильтры: поиск по имени владельца и страница списка
- `search.py` — компиляция внутреннего представления фильтра в запрос и страница выдачи
- `webhooks.py` — подписки вебхуков и очередь доставок: подбор адресов под событие, захват задания
- `workflows.py` — графы процессов, назначения типам задач и счётчики влияния правок
