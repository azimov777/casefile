# app/db/repositories

Доступ к данным: сборка запросов и выдача ORM-объектов, файл на сущность; сценарии берут
репозитории отсюда.

## Файлы
- `__init__.py` — реэкспорт репозиториев, чтобы сценарии импортировали их из одного места
- `accounts.py` — учётные записи: поиск по идентификатору, почте и участнику, самая ранняя действующая учётная запись администратора, число действующих администраторов, страница списка
- `areas.py` — области: поиск по проекту и ключу или по адресу, список и страница проекта (архивные по просьбе), первая архивная среди названных — для заморозки
- `attributes.py` — атрибуты проекта и области: поиск по имени без учёта регистра, все атрибуты владельца по имени, вставка, снятие строки
- `discussions.py` — обсуждения: поиск по проекту и номеру или адресу, номер `max + 1` под блокировкой проекта, первое закрытое для заморозки, привязки задач, страница с отбором и признаками; выражения «чей ход» и числа открытых вопросов, вопросы обсуждений задачи для её признаков
- `entries.py` — записи дела: очередь на подшивку, выдача `no` под блокировкой задачи, проекта, области или обсуждения, вставка, страница с фильтрами, опись, решения проектов и областей (все записи `decision` их дел), номера, заголовки и нагрузка решений и заметок проекта или области для статуса, вердикты, вопросы и их счётчик, хвост журнала по `seq`; правки нет
- `idempotency.py` — ключи идемпотентности: найти пару «токен и ключ», занять её вставкой, снять устаревшие
- `links.py` — связи: поиск канонической тройки, связи задачи с обеих сторон, блокеры и дети, родители строки выдачи, обход графа при проверке цикла
- `oauth.py` — вход через OAuth: клиент по `client_id` и запись клиента CIMD одним `INSERT … ON CONFLICT`, код и refresh по хешу, атомарное погашение одним `UPDATE`, цепочка ротаций, уборка истёкших кодов
- `participants.py` — участники: поиск по имени и идентификатору, проверка набора имён, страница реестра
- `projects.py` — проекты: поиск по ключу и по набору ключей, есть ли хоть один (включая архивные), страница реестра, выдача номера задачи без гонок
- `search.py` — отбор задач: компиляция разрешённого фильтра в условия, порядок с `NULLS LAST`, страница по курсору с признаками и родителями строк
- `tasks.py` — задачи: поиск по ключу — текущему или прежнему (`named_by`), по набору ключей и идентификатору, вставка, число задач по каждому решению проекта, часы базы и условие «момент `not_before` впереди» (`deferred_now`) для признака, отбора и входа в работу
- `tokens.py` — токены: поиск по хешу при аутентификации, страница списка, наличие хоть одного, неотозванные токены участника по имени, все или только сеансы
