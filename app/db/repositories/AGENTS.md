# app/db/repositories

Доступ к данным: сборка запросов и выдача ORM-объектов. Бизнес-правил здесь нет —
они в `app/services`. Транзакцией репозиторий не управляет никогда: `flush` вызывать
можно, `commit` и `rollback` — нельзя, границу держит вход в приложение.

## Файлы
- `__init__.py` — реэкспорт репозиториев, чтобы сценарии импортировали их из одного места
- `actors.py` — акторы: поиск по ключу и идентификатору, страница списка с фильтрами
- `api_tokens.py` — токены: поиск по хешу при аутентификации, токены актора, отзыв
- `catalogs.py` — один репозиторий на три справочника; выборка по области действия
- `queues.py` — очереди, привязки типов задач и атомарная выдача номеров задач
