# app/db/repositories

Доступ к данным: сборка запросов и выдача ORM-объектов. Бизнес-правил здесь нет —
они в `app/services`. Транзакцией репозиторий не управляет никогда: `flush` вызывать
можно, `commit` и `rollback` — нельзя, границу держит вход в приложение.

## Файлы
- `__init__.py` — реэкспорт репозиториев, чтобы сценарии импортировали их из одного места
- `entries.py` — записи дела: очередь на подшивку, выдача `no` под блокировкой задачи, вставка, страница с фильтрами, опись, вердикты, вопросы и их счётчик, хвост журнала по `seq`; правки нет
- `idempotency.py` — ключи идемпотентности: найти пару «токен и ключ», занять её вставкой, снять устаревшие
- `links.py` — связи: поиск канонической тройки, связи задачи с обеих сторон, блокеры и дети, обход графа при проверке цикла
- `participants.py` — участники: поиск по имени и идентификатору, проверка набора имён, страница реестра
- `queues.py` — очереди: поиск по ключу, страница реестра, выдача номера задачи без гонок
- `search.py` — отбор задач: компиляция разрешённого фильтра в условия, порядок с `NULLS LAST`, страница по курсору
- `tasks.py` — задачи: поиск по ключу, по набору ключей и идентификатору, вставка
- `tokens.py` — токены: поиск по хешу при аутентификации, страница списка, наличие хоть одного
