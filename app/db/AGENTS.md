# app/db

Всё, что знает про PostgreSQL: подключение, модели, миграции. Транзакцию открывает сценарий
в `services`, поэтому здесь её границ нет — только выдача сессии и описание схемы.

## Папки
- `migrations/` — окружение Alembic и версии миграций
- `models/` — ORM-модели проекта; модель, не импортированная в его `__init__.py`, невидима для автогенерации

## Файлы
- `__init__.py` — маркер пакета
- `base.py` — декларативный `Base`, соглашения об именах ограничений, общие колонки `id`/`created_at`/`updated_at`
- `session.py` — движок, фабрика сессий, зависимость `get_session` для запросов и `session_scope` для воркеров
