# app/db

Всё, что знает про PostgreSQL: подключение, модели, миграции. Транзакцию открывает сценарий
в `services`, поэтому здесь её границ нет — только выдача сессии и описание схемы.

## Папки
- `migrations/` — окружение Alembic и версии миграций
- `models/` — ORM-модели проекта; модель, не импортированная в его `__init__.py`, невидима для автогенерации
- `repositories/` — сборка запросов и выдача объектов; транзакцией не управляют

## Файлы
- `__init__.py` — маркер пакета
- `archive.py` — архив установки на стороне базы: строки таблиц в текст `col::text` и обратно через `COPY`, порядок по внешним ключам, временная схема приёма на ревизии архива миграциями Alembic, замена строк `public`, счётчики идентичности
- `base.py` — декларативный `Base`, имена ограничений, общие колонки, `string_enum` для перечислений
- `locks.py` — очередь изменений: консультативная блокировка мутирующих сценариев и перечитывание задач под ней
- `pagination.py` — курсорная пагинация: по `(created_at, id)` и по произвольному порядку
- `sql.py` — общие куски SQL: экранирование шаблона `LIKE` и вхождение подстроки одной формой на проект
- `session.py` — движок, фабрика сессий, граница транзакции `transaction`, `get_session` для запросов, `session_scope` для MCP и командной строки, перевод ошибок целостности
- `wakeup.py` — слушатель `LISTEN/NOTIFY` для ленты: оповещение из транзакции подшивки, регистрация ждущих, подъём жизненным циклом процесса
