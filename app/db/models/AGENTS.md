# app/db/models

ORM-модели предметной области. Каждая наследует `BaseModel` из `app/db/base.py` и импортируется
в `__init__.py`: Alembic видит таблицы только через `Base.metadata`, а он наполняется импортами.

Здесь фундамент (участники, учётные записи, токены, проекты), задача, записи дела, связи между задачами
и ключи идемпотентности создающих вызовов.

## Файлы
- `__init__.py` — реестр моделей для автогенерации миграций; сюда добавляется каждая новая модель
- `account.py` — учётная запись: почта, хеш пароля, флаг администратора, отключение, состояние знакомства; одна на участника-человека
- `area.py` — область проекта: неизменяемые проект и ключ (адрес `ПРОЕКТ/ключ`), название, описание до 320 знаков, время архива; без родителя
- `attribute.py` — атрибуты проекта и области (две таблицы одной формы): имя как прислано, уникальное без учёта регистра, нынешнее значение; история — в деле владельца
- `author.py` — примесь «кем заведена строка»: род и подпись автора одной парой колонок
- `entry.py` — запись дела: владелец — задача, проект или область, сквозной `seq` от базы, `no` внутри владельца, тип, нагрузка; неизменяема
- `idempotency.py` — ключ идемпотентности: пара с токеном под уникальностью, отпечаток запроса и сохранённый ответ
- `link.py` — связь двух задач: одна строка на связь, канонический вид, обратная сторона считается при чтении
- `oauth.py` — вход через OAuth: клиент DCR или по документу CIMD (со сроком документа) с метаданными, одноразовый код и refresh-токен с цепочкой ротаций — хешами; сам доступ — строка `tokens`
- `participant.py` — участник: род, уникальное имя, описание, хозяин агента (`owner_id`); удаления нет
- `project.py` — проект: неизменяемый ключ, название, описание, счётчик номеров задач
- `task.py` — задача: пять разделов, зашитый статус, исполнитель строкой, версия под `version_id_col`, прежние ключи и решения проекта (`decisions`, ссылки `TRK#15`) JSONB-списками, момент «не раньше» `not_before`
- `token.py` — токен доступа: набор, хеш секрета, отметка использования, отзыв, срок у токена сеанса; участник необязателен
