# app/api/routes

Роутеры по предметным областям: один файл — одна область, каждый подключается к `api_router`
из `app/api/router.py`. Исключение — `health.py`: он висит вне версионированного префикса.

## Файлы
- `__init__.py` — маркер пакета
- `actors.py` — акторы и их токены: список, создание, изменение, выпуск и отзыв токена
- `catalogs.py` — справочники: адресация ссылками и workflow-безопасный массовый перенос статусов
- `checklists.py` — чеклист задачи: пункты, отметка о выполнении, перестановка соседом
- `comments.py` — обсуждение задачи: лента, новая реплика, правка, мягкое удаление
- `fields.py` — реестр полей: заведение атрибутов задачи без миграции, скрытие вместо удаления
- `filters.py` — сохранённые фильтры: цикл жизни именованных запросов
- `health.py` — проверка здоровья `/health`: подтверждает живое соединение с БД для мониторинга
- `issues.py` — задачи: цикл жизни, частичное обновление с версией, исполнитель, наблюдатели, история изменений
- `links.py` — связи задачи и дерево подзадач: обе стороны одной строки, глубина выдачи
- `portfolios.py` — портфели: вложенность без циклов, состав одним списком, агрегированный прогресс
- `projects.py` — проекты: карточка с прогрессом, состав из разных очередей, перенос между портфелями
- `queues.py` — очереди: цикл жизни, набор типов задач, конфигурация одним запросом
- `search.py` — поиск задач: строка на языке запросов и структурный фильтр
- `tags.py` — словарь существующих тегов и точечные добавление и снятие тегов задачи
- `workflows.py` — редактор графов, шаблоны, назначения и переходы конкретной задачи
