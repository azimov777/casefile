# app/api/routes

Роутеры REST по предметным областям, файл на область; подключаются к `api_router` из
`app/api/router.py`, вход по паролю — к `session_router`, `/health` — вне `/api/v1`. Маршруты вне
оболочки ответа и без токена объявлены в `app/api/contract.py`.

## Файлы
- `__init__.py` — маркер пакета
- `accounts.py` — учётные записи: список, заведение с паролем один раз, чтение, правка почты, флага и отключения, сброс пароля администратором, смена своего пароля, правка своего состояния знакомства
- `bootstrap.py` — первый экран интерфейса одним запросом: участник, его учётная запись, токен, проекты, число вопросов к нему
- `areas.py` — области проекта (`/projects/{key}/areas`): список, заведение, чтение с атрибутами, правка, архив и восстановление; атрибуты и дело области — те же сценарии, что у проекта
- `discussions.py` — обсуждения (`/discussions`, адрес `TRK~7`): список с отбором, «Новое обсуждение» запиской с привязкой задач, экран с итогом и привязками, дело — страница, заметка и ответ, привязать и отвязать задачу
- `installation.py` — сведения установки, одинаковые для любого токена: публичный адрес MCP; версия и последний выпуск Casefile с кэшем приложения; архив установки — выгрузка и приём, только администратору
- `health.py` — проверка здоровья `/health`: подтверждает живое соединение с БД для мониторинга
- `journal.py` — лента журнала: хвост по `seq` с ожиданием и тот же хвост потоком SSE
- `links.py` — связи между задачами: поставить и снять; чтения нет, связи приезжают в карточке
- `participants.py` — реестр участников: список, регистрация, чтение, правка описания
- `projects.py` — реестр проектов: список, создание, чтение с атрибутами, решениями (статус, преемник, число ссылающихся задач) и неархивными областями, правка названия и описания; дело проекта — подшивка, страница и запись по номеру; атрибуты — задать значение и снять с причиной
- `questions.py` — вопросы поперёк задач: «входящая» участника, представление над делом
- `remarks.py` — замечания поперёк задач: что ещё не разобрали, представление над делом
- `session.py` — вход по почте и паролю: токен сеанса в куке `HttpOnly` и в ответе, чтение сеанса по куке, выход с отзывом токена
- `tasks.py` — задачи: список с языком запросов и структурным фильтром, создание, пакет преемника, обновление, переход, закрытие, перенос в другой проект, записи дела
- `tokens.py` — токены доступа: список, выпуск с секретом в ответе, отзыв
