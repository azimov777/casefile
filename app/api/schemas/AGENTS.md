# app/api/schemas

Схемы Pydantic для HTTP-слоя: что приходит в запросе и что уходит в ответе. Из них же
собирается OpenAPI, поэтому примеры и описания полей пишутся здесь, а не в роутерах.

## Файлы
- `__init__.py` — маркер пакета
- `actors.py` — акторы и токены: чтение, создание, частичное обновление, ответ с секретом токена
- `automation.py` — правило: объявление из кода и состояние из базы, настройка, запись журнала, запуск макроса
- `boards.py` — доска и колонка: чтение, создание, правка, перестановка и перенос карточки
- `catalogs.py` — справочники: общая форма записи, ссылки, перенос статусов с резолюцией
- `checklists.py` — пункт чеклиста: чтение без позиции, правка, отметка, перемещение соседом
- `comments.py` — комментарий: чтение с упоминаниями и плашкой удалённого, создание, правка
- `common.py` — оболочки `data`/`meta`, формат ошибки, `unset_field()` для схем `PATCH`
- `events.py` — история изменений задачи и внешний вид события для вебхука и потока
- `fields.py` — реестр полей: описание поля, варианты перечисления, значение по умолчанию
- `filters.py` — сохранённый фильтр: чтение, создание, частичное обновление
- `health.py` — ответ проверки здоровья
- `issues.py` — задача: чтение, создание, частичное обновление, назначение, наблюдатель
- `links.py` — связь глазами запросившей задачи и рекурсивный узел дерева
- `notifications.py` — инбокс и подписки: запись ленты, итог ожидания, отметка прочитанным
- `projects.py` — проект и портфель: карточка с прогрессом, создание, частичное обновление, состав
- `queues.py` — очередь и её конфигурация целиком, включая назначенные полные графы процессов
- `search.py` — запрос поиска, структурный фильтр и задача в выдаче с выбором полей
- `tags.py` — тег словаря с числом задач и добавление тегов к задаче
- `webhooks.py` — подписка вебхука: секрет только при создании, маска в остальных ответах, журнал
- `workflows.py` — входные и выходные представления графов, переходов, шаблонов и влияния правок
