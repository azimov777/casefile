# app/api/schemas

Схемы Pydantic для HTTP-слоя: что приходит в запросе и что уходит в ответе. Из них же
собирается OpenAPI, поэтому примеры и описания полей пишутся здесь, а не в роутерах.

## Файлы
- `__init__.py` — маркер пакета
- `actors.py` — акторы и токены: чтение, создание, частичное обновление, ответ с секретом токена
- `common.py` — оболочки `data`/`meta` и формат ошибки; форма ответа задаётся здесь один раз
- `health.py` — ответ проверки здоровья
