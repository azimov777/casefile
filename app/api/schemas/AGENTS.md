# app/api/schemas

Схемы Pydantic для HTTP-слоя: что приходит в запросе и что уходит в ответе. Из них же
собирается OpenAPI, поэтому примеры и описания полей пишутся здесь, а не в роутерах.

## Файлы
- `__init__.py` — маркер пакета
- `actors.py` — акторы и токены: чтение, создание, частичное обновление, ответ с секретом токена
- `catalogs.py` — справочники: общая форма записи, ссылки, перенос задач между статусами
- `common.py` — оболочки `data`/`meta`, формат ошибки и признак `UNSET` для схем `PATCH`
- `fields.py` — реестр полей: описание поля, варианты перечисления, значение по умолчанию
- `health.py` — ответ проверки здоровья
- `queues.py` — очередь и её конфигурация целиком; заглушка воркфлоу для задачи 07
