# app/api

HTTP-слой: принимает запрос, вызывает сценарий из `services`, отдаёт ответ. Своей бизнес-логики
не содержит и в БД напрямую не пишет — иначе та же операция из MCP пойдёт мимо событий.

## Папки
- `routes/` — роутеры по предметным областям, по файлу на область
- `schemas/` — модели Pydantic для запросов и ответов; они же формируют OpenAPI

## Файлы
- `__init__.py` — маркер пакета
- `client_address.py` — адрес клиента запроса для окна попыток входа: собеседник TCP или `X-Real-IP` от собеседника из `TRACKER_REAL_IP_FROM` (адреса, сети, имена служб, разрешаемые при входе)
- `contract.py` — контракт кодом: исключения из оболочки ответа, маршруты без токена и справочник кодов ошибок
- `deps.py` — зависимости FastAPI: сессия на запрос, фабрика сессий для потока, автор по токену и метке, настройки собравшего приложения, общие параметры запроса и пути
- `idempotency.py` — HTTP-сторона идемпотентности: заголовок `Idempotency-Key`, отпечаток запроса, повтор сохранённого ответа
- `errors.py` — обработчики исключений: единственное место, где код ошибки встречается с HTTP
- `router.py` — корневой роутер `/api/v1`: токен, формы ошибок, генератор `operation_id`; отдельный роутер входа по паролю без токена
