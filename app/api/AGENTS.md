# app/api

HTTP-слой: принимает запрос, вызывает сценарий из `services`, отдаёт ответ. Своей бизнес-логики
не содержит и в БД напрямую не пишет — иначе та же операция из MCP пойдёт мимо событий.

## Папки
- `routes/` — роутеры по предметным областям, по файлу на область
- `schemas/` — модели Pydantic для запросов и ответов; они же формируют OpenAPI

## Файлы
- `__init__.py` — маркер пакета
- `contract.py` — контракт кодом: исключения из оболочки ответа и справочник кодов ошибок
- `deps.py` — зависимости FastAPI: сессия на запрос, фабрика сессий для потока, автор по токену и метке, общие параметры запроса и пути
- `errors.py` — обработчики исключений: единственное место, где код ошибки встречается с HTTP
- `router.py` — корневой роутер `/api/v1`: токен, формы ошибок, генератор `operation_id`
