# skill

Скилы, которые трекер раздаёт агентам. Исходные тексты дисциплины: приложение читает их
при запуске и отдаёт через MCP как промпт и инструкции сервера, харнесс устанавливает
как скил.

## Папки
- `tracker-agent/` — дисциплина работы агента с делом задачи: вход, сводки, вопросы, декомпозиция, проверка
