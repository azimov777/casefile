# tracker

Бэкенд таск-трекера: REST API для фронтенда (делается отдельным проектом) и MCP-сервер для
агентов. Код приложения появится в `app/` по задаче `docs/tasks/01-project-skeleton.md`.

## Папки
- `docs/` — концепция, соглашения и задания для агентов; читается до начала любой работы

## Файлы
- `main.py` — заглушка FastAPI из шаблона PyCharm; заменяется точкой входа в задаче 01
- `test_main.http` — HTTP-запросы к заглушке для ручной проверки из IDE
