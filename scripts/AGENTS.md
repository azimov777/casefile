# scripts

Команды, которым нужен хост: git и docker живут снаружи контейнера, и обёртка над ними
тоже. Прогон, который такая команда запускает, идёт в контейнере — установка Python на
хост по-прежнему не поддерживается (`docs/CONVENTIONS.md`, раздел «Запуск: всё работает
в Docker»). `watch-journal.sh` — другой случай той же идеи «нужен хост»: он ходит по сети
на опубликованный порт установки голым `curl` и внутрь контейнера не идёт вовсе.

## Файлы
- `check-dco.sh` — подпись вклада: каждый коммит диапазона несёт `Signed-off-by` своего автора, кроме коммитов Dependabot в PR, которые GitHub сам числит за ним; тем же файлом проверяет конвейер и человек до отправки PR
- `merge-task-branch.sh` — слияние ветки задачи: слить без коммита, прогнать набор на результате, закоммитить только зелёное со строкой `Merge-verified:`; перед своим слиянием называет слияния без этой строки
- `watch-journal.sh` — ВРЕМЕННЫЙ образец сторожа журнала для `docs/agent-install.md`
  («Learn about news in your tasks»), не поддерживаемый инструмент: не входит ни в один
  `docker-compose*.yml`, ничего не пишет в трекер и не знает, жив ли агент; долгий опрос
  `GET /api/v1/journal` по отслеживаемым задачам, продолжение по `seq`, переживает отказ
  установки
