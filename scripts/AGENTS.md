# scripts

Команды, которым нужен хост: обёртки над git и docker, сборка поставляемых архивов и живые проверки
установки. Прогоны, которые они запускают, идут в контейнерах; на хосте — только `pnpm check` из
`merge-task-branch.sh` для веток, трогающих `ui/`, и `curl` сторожа `watch-journal.sh`.

## Файлы
- `build-mcpb.sh` — архив расширения Claude Desktop `casefile.mcpb` из `mcpb/` в контейнере `node`; падает до Docker,
  если версия манифеста не равна версии выпуска; его же зовёт `.github/workflows/mcpb.yml`
- `build-openai-plugin.sh` — ZIP плагина `casefile` (только скил) для каталога OpenAI: `.codex-plugin/`, `skills/` без
  своей карты, `LICENSE`; ничего не подаёт
- `build-plugin-branch.sh` — дерево узкой ветки `plugin` (только файлы плагинов, `skills/` без своей карты); с `--commit ТЕГ`
  строит коммит выпуска; ту же сборку зовёт конвейер выпуска
- `check-auto-update.sh` — живая проверка автообновления установки на своём `registry:2`: канал `stable`, замена
  обновлятора, откат выпуска, который не поднялся; всё своё гасит на выходе
- `check-dco.sh` — подпись вклада: каждый коммит диапазона несёт `Signed-off-by` своего автора (кроме коммитов
  Dependabot в PR); тем же файлом проверяет конвейер и человек до отправки PR
- `check-skill-install.sh` — живая проверка шага «скил» и плагина установщика на своём http-git стенде в изолированных
  домашних каталогах харнессов; сверяет, что настоящие `~/.claude`, `~/.codex`, `~/.agents` не тронуты
- `merge-task-branch.sh` — слияние ветки задачи: без коммита, линтер и набор бэкенда на результате, `pnpm check` — если
  ветка трогает `ui/`; коммит только на зелёном со строкой `Merge-verified:`
- `snapshot-release-archive.sh` — архив демо-данных выпуска по его тегу в `tests/data/` для `tests/test_release_archives.py`;
  свой проект compose, всё своё гасит на выходе
- `watch-journal.sh` — временный образец сторожа журнала для `docs/agent-install.md`, не поддерживаемый инструмент:
  долгий опрос `GET /api/v1/journal` по отслеживаемым задачам с продолжением по `seq`
