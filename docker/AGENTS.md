# docker

Образы приложения на одном базовом образе Python, зависимости — из `uv.lock` в `/opt/venv`.
Дев-образ собирает `docker-compose.yml`; прод-образ собирает конвейер (`.github/workflows/images.yml`)
и публикует в ghcr.io, откуда его берёт `docker-compose.prod.yml`.

## Файлы
- `Dockerfile.dev` — разработка: dev-зависимости, uv для сервиса `lock`, код монтируется томом, автоперезапуск uvicorn
- `Dockerfile.prod` — продакшен: многостадийная сборка, только рантайм-зависимости, непривилегированный пользователь
