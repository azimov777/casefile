# docker

Образы приложения. Оба построены на одном базовом образе Python — расхождение сред не должно
быть причиной «на дев работает, на проде нет». Какой образ каким контуром используется — в
`docker-compose.yml` и `docker-compose.prod.yml`.

## Файлы
- `Dockerfile.dev` — разработка: dev-зависимости, код монтируется томом, автоперезапуск uvicorn
- `Dockerfile.prod` — продакшен: многостадийная сборка, только рантайм-зависимости, непривилегированный пользователь
