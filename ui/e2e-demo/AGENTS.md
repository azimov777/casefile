# ui/e2e-demo

Запись `docs/assets/demo-light.gif` и `demo-dark.gif` — не сквозные тесты: свой конфиг
`../playwright.demo.config.ts` и свой изолированный контур бэкенда; `pnpm e2e` эту папку не подхватывает.

## Файлы
- `README.md` — как воспроизвести запись целиком: свой контур бэкенда со своим тегом
  образа и портами, участник `claude`, наполнение фона, запись (дважды, по теме),
  сведение в GIF `ffmpeg` в контейнере, гашение контура
- `demo-recording.spec.ts` — сценарий записи: агент заводит задачу REST-вызовом от лица `claude`, двигает её по
  статусам, подшивает записи и переходит в карточку
- `seed-background.py` — фон доски до записи: фоновые задачи во всех столбцах; только стандартная библиотека Python
