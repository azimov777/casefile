# docker

Образ интерфейса. Контур целиком описан в `docker-compose.yml` в корне репозитория.

## Файлы

- `Dockerfile` — сборка статики в Node и отдача её через nginx
- `nginx.conf` — одностраничное приложение и проксирование `/api` на бэкенд;
  буферизация для `/api` выключена ради живого потока (задача 07)
