# scripts

Команды, которыми установку поднимают и сливают ветки задач руками. Всё, что нужно
прогонам и сборке, живёт не здесь: контур сквозных тестов поднимает `e2e/global-setup.ts`,
образ собирает `docker/Dockerfile`.

## Файлы

- `up.sh` — подъём установки целиком одной командой (`pnpm start`): бэкенд из соседнего
  репозитория, миграции, владелец, ключ интерфейса, интерфейс — и адрес в конце. Ключ
  читает с хоста из файла, выпущенного командой `local-token` бэкенда, и передаёт контуру
  переменной `TRACKER_UI_TOKEN`; настройки берёт из `.env` в корне репозитория
- `merge-task-branch.sh` — слияние ветки задачи в `main`: без коммита, `pnpm check` затем
  `pnpm e2e` на результате, коммит только на двойном зелёном со строкой `Merge-verified:`
  (`docs/CONVENTIONS.md`, «Слияние ветки задачи в main»); проверяет согласие с прозой
  `testing/merge-script.test.ts`
