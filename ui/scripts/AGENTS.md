# scripts

Команды, которыми установку поднимают руками. Всё, что нужно прогонам и сборке, живёт
не здесь: контур сквозных тестов поднимает `e2e/global-setup.ts`, образ собирает
`docker/Dockerfile`.

## Файлы

- `up.sh` — подъём установки целиком одной командой (`pnpm start`): бэкенд из соседнего
  репозитория, миграции, владелец, ключ интерфейса, интерфейс — и адрес в конце. Ключ
  читает с хоста из файла, выпущенного командой `local-token` бэкенда, и передаёт контуру
  переменной `TRACKER_UI_TOKEN`; настройки берёт из `.env` в корне репозитория
