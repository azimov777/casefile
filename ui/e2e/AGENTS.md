# e2e

Сквозные сценарии Playwright против настоящего бэкенда с демо-данными. Контур
поднимает и гасит сам прогон: `pnpm e2e`.

Все сценарии, кроме `answer.spec.ts` и `live.spec.ts`, только читают и потому идут
параллельно в обеих темах. Пишущие вынесены в проект `запись` и запускаются после них
(`playwright.config.ts`).

## Файлы

- `login.spec.ts` — вход с токеном демо, отказ на неверном токене, прогон `axe`
- `tasks.spec.ts` — список: отбор по статусу, признаки строки, ошибка запроса, адрес, `axe`
- `board.spec.ts` — доска: столбцы из контракта, свёрнутые столбцы, переход в карточку, фильтр, `axe`
- `task.spec.ts` — карточка и лента дела: пакет одним запросом, раскрытие записи, отбор по типам, `axe`
- `questions.spec.ts` — входящая: адресованный вопрос, отбор в адресе, `axe`
- `answer.spec.ts` — ответ на вопрос демо: пишущий сценарий, проект «запись»
- `live.spec.ts` — живой поток: кадры доходят до списка, карточки и шапки; проект «запись»
- `resilience.spec.ts` — отказ запроса объясняется по коду и чинится кнопкой «Повторить»
- `global-setup.ts` — подъём контура, миграции, демо-данные, выпуск токена
- `global-teardown.ts` — гашение контура вместе с данными
- `contour.ts` — вызов `docker compose` и передача токена тестам через файл
