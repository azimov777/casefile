# ui

Интерфейс человека для трекера задач, которые ведут агенты. Бэкенд и контракт API —
в корне этого репозитория, на уровень выше (`..`).

**Перед любой работой в `ui/` — вход через трекер** (проект `TRK`, MCP-сервер плагина `casefile`):
`get_task` по ключу задачи (поле `area`), `get_project(key="TRK")` — общие решения проекта и
протокол выполнения задачи TRK#233, `get_project(key="TRK/<область>")` — знание области
интерфейса (`TRK/ui-api`, `ui-list`, `ui-screens`, `ui-shared`, `ui-testing`, `ui-tooling`),
как вести задачу — скил `casefile`. Задания приходят задачами трекера.

Команды запуска, проверок и сборки — `get_project(key="TRK/ui-tooling")` (записи с пометкой «перенос TRK-694»; сводка — атрибут проекта `ui_dev`).

## Папки

- `src/` — исходный код по слоям Feature-Sliced Design
- `testing/` — обвязка модульных и страничных тестов и проверки вне экранов: подмена API, рендер
- `e2e/` — сквозные сценарии Playwright и подъём контура для них
- `e2e-demo/` — запись `docs/assets/demo-light.gif`/`demo-dark.gif`: свой
  сценарий и свой контур, `pnpm e2e` их не подхватывает
- `docker/` — образ интерфейса и конфигурация nginx
- `scripts/` — команда подъёма установки целиком, команда слияния ветки задачи

## Файлы

- `package.json` — зависимости и скрипты; версия pnpm задана `packageManager`
- `pnpm-lock.yaml` — закреплённые версии зависимостей
- `pnpm-workspace.yaml` — какие зависимости вправе запускать сборочные скрипты
- `index.html` — страница-оболочка Vite
- `vite.config.ts` — сборка, Tailwind плагином, псевдонимы `@` и `@testing`, прокси `/api`,
  посредник `/config.json` по `TRACKER_UI_TOKEN`, Vitest
- `components.json` — псевдонимы shadcn/ui: компоненты в `src/shared/ui`, утилиты в `src/shared/lib`
- `tsconfig.json` — корневой конфиг: ссылки на два ниже
- `tsconfig.app.json` — типы приложения и тестов: `src` и `testing`
- `tsconfig.node.json` — типы оснастки: конфигурации сборки и сквозные тесты
- `eslint.config.js`, `.prettierrc.json`, `.prettierignore` — линт и формат; в `eslint.config.js` же сторож
  подписей мимо словаря
- `steiger.config.ts` — правила границ слоёв Feature-Sliced Design
- `playwright.config.ts` — сквозные тесты в светлой и тёмной теме и на английском; пишущие сценарии отдельным проектом после читающих
- `playwright.demo.config.ts` — конфиг записи `docs/assets/demo-light.gif`/`demo-dark.gif`
  (`e2e-demo/`, тема — `DEMO_COLOR_SCHEME`), в `pnpm e2e` (`playwright test` без `-c`) не попадает
- `docker-compose.yml` — контур сборки и сквозных тестов: интерфейс и бэкенд из корня репозитория,
  ключ интерфейса выпускает сервис `local-token`, бэкенд знает учебный пароль администратора
  `owner@localhost` для второго экземпляра интерфейса в режиме входа по учётным записям
- `.env.example` — образец настроек этой машины: порт контура сквозных тестов, адрес API и ключ
  установки для дев-сервера
- `.nvmrc` — версия Node
- `.gitignore` — что не попадает в репозиторий
- `.dockerignore` — что попадает в контекст сборки образа: перечень устроен наоборот,
  сначала отброшено всё
