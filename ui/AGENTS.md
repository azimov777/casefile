# tracker-ui

Интерфейс человека для трекера задач, которые ведут агенты. Отдельный проект; бэкенд
и контракт API живут в репозитории `tracker` рядом.

**Перед любой работой в репозитории:** прочитать `docs/CONCEPT.md` (что строим),
`docs/CONVENTIONS.md` (как строим и обязательный протокол выполнения задачи) и заметки
в `docs/notes/` по своей области. Задания в `docs/tasks/`.

## Папки
- `docs/` — концепция, соглашения, дорожная карта, задания для агентов, накопленные заметки

## Файлы
- `README.md` — что это и с чего начать; команды запуска появятся после задачи 01
- `.gitignore` — что не попадает в репозиторий
