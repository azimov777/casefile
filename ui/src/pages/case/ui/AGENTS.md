# src/pages/case/ui

## Файлы

- `case-page.tsx` — лента страницами по курсору и окном `after_no`, переход к свежей записи, ответы под вопросами, подсветка записи из адреса
- `case-page.test.tsx` — порядок записей, чипы типов без раскрытия панели, окно дела, ответ под вопросом, запись из адреса
- `case-filters.tsx` — строка инструментов («Фильтр» со счётом условий) и строка состояния
  (чипы типов, сброс) — тот же вид, что у отбора задач (UI-130, UI-137)
- `case-filter-menu.tsx` — содержимое панели «Фильтр»: типы двумя группами (записи агента /
  служебные), подпись группы — кнопка, ставящая или снимающая её целиком
- `case-filter-menu.test.tsx` — панель без всплывающего слоя: отбор нажатыми
  переключателями, применение по клику, подпись группы не трогает другую группу
- `section-edits-group.tsx` — правки разделов одного действия одной строкой ленты; раскрытие кликом и по `?entry=N`
