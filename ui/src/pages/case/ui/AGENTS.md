# src/pages/case/ui

## Файлы

- `case-page.tsx` — лента страницами по курсору и окном `after_no`, переход к свежей записи, ответы под вопросами, подсветка записи из адреса
- `case-page.module.css` — стили ленты
- `case-page.test.tsx` — порядок записей, свёрнутый отбор и чипы типов, окно дела, ответ под вопросом, запись из адреса
- `case-filters.tsx` — отбор по типам: чипы отобранного, группы «записи агента» и «служебные», раскрытие всех типов
- `case-filters.module.css` — стили отбора
