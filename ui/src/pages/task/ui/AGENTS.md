# src/pages/task/ui

## Файлы

- `task-page.tsx` — сборка экрана и его раскладка: слева сводка, вопросы, замечания и дело, справа задание и связи; проект читается ради `archived_at`, и у задачи архивного проекта нет ни ответа, ни замечания, вместо них — плашка со ссылкой на проект; шапка блока дела (заголовок, число записей, прыжки по описи, ссылка на ленту) — здесь, сама опись — `EntryIndex` из `entities/entry`; адрес по прежнему ключу перенесённой задачи (`task.key` пакета ≠ ключ из `useParams`) заменяется на текущий, номер записи сохраняется (TRK-173)
- `task-page.test.tsx` — один запрос пакета, раскрытие записи, ссылки, `task_not_found`, задача архивного проекта без ответа и замечания; адрес по прежнему ключу заменяется на текущий с тем же `entry`, прежние ключи в шапке (TRK-173)
- `task-header.tsx` — шапка карточки группами: проект, область ссылкой (TRK-557) и родитель (`parent` пакета) над ключом и названием, под ними полоса свойств с подписями — статус, приоритет, область адресом с «Изменить» (`ChangeTaskArea`; нет у закрытой задачи и у задачи архивного проекта), исполнитель, прежние ключи перенесённой задачи ссылками (TRK-173), признаки, в правом конце время (UI-143); строкой во всю ширину — решения проекта, на которые опирается задача, со статусом и преемником заменённого (TRK-554)
- `task-state.tsx` — блок «Сейчас» под шапкой (TRK-579): последний переход с причиной, сколько записей подшито после сводки, блокеры и дети со статусами, решения после правки задания; считает бэкенд при чтении (`state` пакета), человек его не правит; сводку, вопросы и строки записей не дублирует — они ниже
- `task-area.test.tsx` — область в карточке (TRK-557): название ссылкой рядом с проектом, адрес в полосе, правка окном уходит `PATCH` с одним `area`, у задачи с областью пункта «без области» нет (TRK-677), у старой без области он выбран и ей можно поставить область, неизменённый выбор без запроса, отказ словами, у закрытой задачи кнопки нет, нынешняя архивная с пометкой
- `task-state.test.tsx` — блок «Сейчас»: причина перехода и счёт записей после сводки; блокеры и дети ссылками, решения номерами; задача без вестей без пустых ячеек
- `task-decisions.test.tsx` — строка «Решения» в шапке: каждое решение ссылкой на запись проекта со статусом, у заменённого — преемник; без решений строки нет
- `task-sections.tsx` — пять разделов и обзорные проверки нумерованным списком
- `task-links.tsx` — связи с обеих сторон со статусом другой стороны; родитель и дети — из `parent`/`children` пакета теми же группами `child`/`parent`
