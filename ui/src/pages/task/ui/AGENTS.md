# src/pages/task/ui

## Файлы

- `task-page.tsx` — сборка экрана и его раскладка: слева сводка, вопросы, замечания и дело, справа задание и связи; проект читается ради `archived_at`, и у задачи архивного проекта нет ни ответа, ни замечания, вместо них — плашка со ссылкой на проект; шапка блока дела (заголовок, число записей, прыжки по описи, ссылка на ленту) — здесь, сама опись — `EntryIndex` из `entities/entry`
- `task-page.test.tsx` — один запрос пакета, раскрытие записи, ссылки, `task_not_found`, задача архивного проекта без ответа и замечания
- `task-header.tsx` — шапка карточки группами: проект и родитель (`parent` пакета) над ключом и названием, под ними полоса свойств с подписями — статус, приоритет, исполнитель, признаки, в правом конце время (UI-143)
- `task-sections.tsx` — пять разделов и обзорные проверки нумерованным списком
- `task-links.tsx` — связи с обеих сторон со статусом другой стороны; родитель и дети — из `parent`/`children` пакета теми же группами `child`/`parent`
