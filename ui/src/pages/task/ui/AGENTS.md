# src/pages/task/ui

## Файлы

- `task-page.tsx` — сборка экрана и его раскладка: слева сводка, вопросы, замечания и дело, справа задание и связи
- `task-page.test.tsx` — один запрос пакета, раскрытие записи, ссылки, `task_not_found`
- `task-header.tsx` — шапка карточки группами: очередь и родители над ключом и названием, под ними полоса свойств с подписями — статус, приоритет, исполнитель, признаки, в правом конце время (UI-143)
- `task-sections.tsx` — пять разделов и обзорные проверки нумерованным списком
- `task-links.tsx` — связи с обеих сторон со статусом другой стороны
- `task-index.tsx` — таблица описи дела (на узком месте, `@max-index:`, — строками-карточками) с раскрытием тела записи по клику и правками разделов одного действия одной строкой; шапку блока (заголовок, число записей, прыжки по описи, ссылку на ленту) держит `task-page.tsx`
