# src/pages/task/ui

## Файлы

- `task-page.tsx` — сборка экрана и его раскладка: слева сводка, вопросы, замечания и дело, справа задание и связи
- `task-page.test.tsx` — один запрос пакета, раскрытие записи, ссылки, `task_not_found`
- `task-header.tsx` — ключ, название, статус, приоритет, исполнитель, признаки, возможные переходы
- `task-sections.tsx` — пять разделов и обзорные проверки нумерованным списком
- `task-links.tsx` — связи с обеих сторон со статусом другой стороны
- `task-index.tsx` — опись дела с раскрытием тела записи по клику, прыжками к свежей записи и в начало, ссылкой на ленту
