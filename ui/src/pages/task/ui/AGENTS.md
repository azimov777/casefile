# src/pages/task/ui

## Файлы

- `task-page.tsx` — сборка экрана: шапка, сводка, вопросы, задание, связи, дело
- `task-page.module.css` — раскладка экрана
- `task-page.test.tsx` — один запрос пакета, раскрытие записи, ссылки, `task_not_found`
- `task-header.tsx` — ключ, название, статус, приоритет, исполнитель, теги, признаки, переходы
- `task-header.module.css` — стили шапки
- `task-sections.tsx` — пять разделов и обзорные проверки нумерованным списком
- `task-sections.module.css` — стили разделов
- `task-links.tsx` — связи с обеих сторон со статусом другой стороны
- `task-links.module.css` — стили связей
- `task-index.tsx` — опись дела с раскрытием тела записи по клику
- `task-index.module.css` — стили описи
