# src/pages/task/ui

## Файлы

- `task-page.tsx` — сборка экрана и его раскладка: слева сводка, вопросы, замечания и дело, справа задание и связи; проект читается ради `archived_at`, и у задачи архивного проекта нет ни ответа, ни замечания, вместо них — плашка со ссылкой на проект; шапка блока дела (заголовок, число записей, прыжки по описи, ссылка на ленту) — здесь, сама опись — `EntryIndex` из `entities/entry`; адрес по прежнему ключу перенесённой задачи (`task.key` пакета ≠ ключ из `useParams`) заменяется на текущий, номер записи сохраняется (TRK-173)
- `task-page.test.tsx` — один запрос пакета, раскрытие записи, ссылки, `task_not_found`, задача архивного проекта без ответа и замечания; адрес по прежнему ключу заменяется на текущий с тем же `entry`, прежние ключи в шапке (TRK-173)
- `task-header.tsx` — шапка карточки группами: проект и родитель (`parent` пакета) над ключом и названием, под ними полоса свойств с подписями — статус, приоритет, исполнитель, прежние ключи перенесённой задачи ссылками (TRK-173), признаки, в правом конце время (UI-143)
- `task-sections.tsx` — пять разделов и обзорные проверки нумерованным списком
- `task-links.tsx` — связи с обеих сторон со статусом другой стороны; родитель и дети — из `parent`/`children` пакета теми же группами `child`/`parent`
