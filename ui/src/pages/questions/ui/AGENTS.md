# src/pages/questions/ui

## Файлы

- `questions-page.tsx` — два вида экрана по адресу (`view=history`): входящая первым экраном и история вопросов с ответами от свежих, без формы ответа, флажок «только мне» (`to=anyone`); две половины входящей: вопросы ко мне и мои замечания без разбора; очередь отбирает обе, «только блокирующие» — вопросы; пустота различает «ничего нет» и «ничего не нашлось»; у блокирующего вопроса левая кромка тоном опасности (Д17); оформление утилитами, две колонки от точки `wide`
- `questions-page.test.tsx` — вид по умолчанию и история (запрос, ответы со ссылками `KEY#N`, снятие адресата, пустота), ответ с ключом повтора, повтор после обрыва, замечания у полей, черновик, пустые состояния под отбором, ссылки на записи
