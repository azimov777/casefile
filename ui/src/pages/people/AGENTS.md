# src/pages/people

Экран «Люди» (`/people`): учётные записи установки и управление ими администратором —
завести, сбросить пароль, отключить, включить. Только в режиме входа (страж
`app/routes/require-sign-in-mode.tsx`) и только администратору: остальным — объяснение без
запроса списка.

## Папки

- `ui/` — экран людей

## Файлы

- `index.ts` — публичный интерфейс среза
