# src/pages/files

Экран «Файлы» (`/files`): все файлы установки одним списком — поиск по имени, сортировка, отбор по типу и проекту в адресе,
листание по курсору; открыть изображение, скачать, загрузить, заменить, удалить один, выбранные или все отобранные.

## Папки

- `model/` — отбор из адреса и правка адреса: виды файлов, порядки, умолчания
- `ui/` — экран и панель поиска и отбора

## Файлы

- `index.ts` — публичный интерфейс среза
