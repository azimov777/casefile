# src/pages/access/ui

## Файлы

- `access-page.tsx` — экран в одной колонке по центру: у администратора дорожка «Все / Мои» в адресе; три раздела по виду строки — «Подключения» (OAuth, «Отключить»), «Ключи агентов» (колонка «кто выдал», заведение агента и выпуск ключа) и «Сеансы входа» (только живые); снятые подключения и ключи — свёрнутой историей; отзыв своей строки и чужой только администратору, выпуск закрыт с причиной без учётной записи, список дочитывается до конца сам, окна заведения, выпуска, секрета с фрагментами и подтверждения отзыва
- `access-page.test.tsx` — разделы по `kind`, «этот компьютер» и ключ сеанса отмечен, пустые «Подключения», «Отключить» с подтверждением, подключение с вышедшим сроком остаётся, действующие раньше снятых и история свёрнута, дочитывание второй страницы, ключ агента без учётной записи без запросов записи, секрет один раз и его исчезновение из состояния и кэшей, один ключ повтора на повтор и новый на исправленный выпуск, отказы по причине, подтверждение отзыва своего ключа; у человека без флага администратора свои доступы и в выпуске свои агенты без людей и чужих, у администратора все агенты с хозяином, дорожка и `mine=true`, сеансы отдельно и без закончившихся
