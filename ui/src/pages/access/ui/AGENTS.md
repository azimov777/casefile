# src/pages/access/ui

## Файлы

- `access-page.tsx` — экран: список доступов страницами, запрещённые действия с объяснением при ключе `task`, окна заведения, выпуска, секрета с фрагментами и подтверждения отзыва
- `access-page.test.tsx` — ключ `task` без запросов записи, ключ сеанса отмечен, секрет один раз и его исчезновение из состояния и кэшей, один ключ повтора на повтор и новый на исправленный выпуск, отказы по причине, подтверждение отзыва своего ключа
