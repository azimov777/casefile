# src/pages/access/ui

## Файлы

- `access-page.tsx` — экран в одной колонке по центру: у администратора дорожка «Все / Мои» в адресе, действующие ключи агентов сверху, живые сеансы входа своим разделом, отозванные ключи — свёрнутой историей, отзыв своей строки и чужой только администратору, выпуск закрыт с причиной без учётной записи, список дочитывается до конца сам, запрещённые действия с объяснением при ключе `task`, окна заведения, выпуска, секрета с фрагментами и подтверждения отзыва
- `access-page.test.tsx` — ключ `task` без запросов записи, ключ сеанса отмечен, действующие раньше отозванных и история свёрнута, дочитывание второй страницы, секрет один раз и его исчезновение из состояния и кэшей, один ключ повтора на повтор и новый на исправленный выпуск, отказы по причине, подтверждение отзыва своего ключа; свои токены у человека без флага администратора, дорожка и `mine=true` у администратора, сеансы отдельно и без закончившихся, выпуск закрыт ключу агента, отказы по причине `details.reason`
