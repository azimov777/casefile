# src/pages/access/ui

## Файлы

- `access-page.tsx` — экран в одной колонке по центру: действующие токены сверху, отозванные — свёрнутой историей, список дочитывается до конца сам, запрещённые действия с объяснением при ключе `task`, окна заведения, выпуска, секрета с фрагментами и подтверждения отзыва
- `access-page.test.tsx` — ключ `task` без запросов записи, ключ сеанса отмечен, действующие раньше отозванных и история свёрнута, дочитывание второй страницы, секрет один раз и его исчезновение из состояния и кэшей, один ключ повтора на повтор и новый на исправленный выпуск, отказы по причине, подтверждение отзыва своего ключа
