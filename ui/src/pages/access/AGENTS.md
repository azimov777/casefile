# src/pages/access

Экран «Доступы»: ключи агентов и сеансы входа — человеку свои, администратору все
токены установки с дорожкой «Все / Мои» (`?tokens=mine`, TRK-114), заведение
агента-участника, выпуск токена с показом секрета один раз и готовой строкой подключения,
отзыв своего (чужого — администратору). Список виден любым ключом, выпуск открыт ключу
набора `main` за человеком с учётной записью; ввода ключа на экране нет (`UI-104#7`).

- `ui/` — экран доступов
