# src/pages/access

Экран «Доступы»: подключения агентов (OAuth), ключи агентов и сеансы входа —
человеку свои, администратору все доступы установки с дорожкой «Все / Мои»
(`?tokens=mine`), заведение агента-участника, выпуск ключа агенту с показом
секрета один раз и готовой строкой подключения, отзыв своего и отключение подключения
(чужого — администратору). Список виден любым ключом, выпуск открыт человеку с учётной
записью; наборов токена нет, ввода ключа на экране нет.

- `ui/` — экран доступов
