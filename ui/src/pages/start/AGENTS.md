# src/pages/start

Экран «Начало»: шаги по порядку с отметкой по фактам установки (подключить агента, сказать ему фразу,
смотреть и отвечать), затем зачем нужен Casefile, откуда берутся задачи, что сказать агенту и что делает человек
сам. Первый экран, пока состояние знакомства учётной записи `pending`; открывается снова из панели.

## Папки

- `ui/` — экран «Начало»

## Файлы

- `index.ts` — публичный интерфейс среза
