# src/pages/start

Экран «Начало»: три шага по порядку с отметкой по фактам установки (подключить агента,
сказать ему фразу, смотреть и отвечать — `TRK-378`), затем зачем нужен Casefile, откуда
берутся задачи, что сказать агенту и что делает человек сам (`TRK-361`, `TRK-360#14`).
Первый экран, пока состояние знакомства учётной записи `pending`; открывается снова из
панели.
