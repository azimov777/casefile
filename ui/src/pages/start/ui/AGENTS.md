# src/pages/start/ui

## Файлы

- `start-page.tsx` — четыре раздела по порядку `TRK-360#14` (зачем это, откуда берутся задачи, что сказать агенту, что делает человек), в третьем — фразы «Знакомство» (только пока учебная задача `START-1` есть, не в архиве и не закрыта), «Завести задачи» и «Выполнить задачи» с объяснением новой сессии между ними; «Пропустить» и «Я разобрался» ставят состояние знакомства и уводят на список задач
- `start-page.test.tsx` — порядок разделов, фразы «Завести задачи»/«Выполнить задачи» всегда и текст о сессии между ними, блок «Знакомство» по фактам бэкенда (открыта, отсутствует, проект в архиве, закрыта), копирование каждой фразы дословно, «Пропустить»/«Я разобрался» отправляют статус и уходят на список задач, вход из панели
