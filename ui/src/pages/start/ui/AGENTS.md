# src/pages/start/ui

## Файлы

- `start-page.tsx` — экран: «Показать пояснения снова» и «Пройти по экранам» у заголовка, шаги с отметкой «сделано» по ответам бэкенда (без хранения в браузере), разделы с фразами «Завести задачи» и «Выполнить задачи»; «Пропустить» — `skipped` и скрытие пояснений, «Я разобрался» — `completed`, оба уводят на список задач
- `start-page.test.tsx` — «Показать пояснения снова», порядок разделов и фразы дословно, копирование, «Пропустить» и «Я разобрался», отметки шагов по фактам установки, тексты на обоих языках
