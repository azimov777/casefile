# src/pages/start/ui

## Файлы

- `start-page.tsx` — рядом с заголовком «Показать пояснения снова» (`RestoreHintsAction`, видно только когда есть что возвращать, `TRK-362`) и «Пройти по экранам» (`StartWalkAction`, `TRK-364`); сразу под заголовком три шага по порядку (`TRK-378`: подключить агента → `/connect`, сказать агенту, с чего начать → якорь на раздел «Что сказать агенту», смотреть и отвечать → `/questions`) с отметкой «сделано» по ответу бэкенда (`GET /api/v1/tokens`, `GET /api/v1/tasks`, `GET /api/v1/questions`), без хранения в браузере; затем четыре раздела по порядку `TRK-360#14` (зачем это, откуда берутся задачи, что сказать агенту, что делает человек), в третьем — фразы «Завести задачи» и «Выполнить задачи» с объяснением новой сессии между ними; «Пропустить» ставит `skipped` и `hints.hidden_all: true` одним запросом (`TRK-385`), «Я разобрался» — `completed` без пояснений; оба уводят на список задач
