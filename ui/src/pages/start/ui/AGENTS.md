# src/pages/start/ui

## Файлы

- `start-page.tsx` — сразу под заголовком три шага по порядку (`TRK-378`: подключить агента → `/connect`, сказать агенту, с чего начать → якорь на раздел «Что сказать агенту», смотреть и отвечать → `/questions`) с отметкой «сделано» по ответу бэкенда (`GET /api/v1/tokens`, `GET /api/v1/tasks`, `GET /api/v1/questions`), без хранения в браузере; затем четыре раздела по порядку `TRK-360#14` (зачем это, откуда берутся задачи, что сказать агенту, что делает человек), в третьем — фразы «Знакомство» (только пока учебная задача `START-1` есть, не в архиве и не закрыта), «Завести задачи» и «Выполнить задачи» с объяснением новой сессии между ними; «Пропустить» и «Я разобрался» ставят состояние знакомства и уводят на список задач
- `start-page.test.tsx` — порядок разделов, фразы «Завести задачи»/«Выполнить задачи» всегда и текст о сессии между ними, блок «Знакомство» по фактам бэкенда (открыта, отсутствует, проект в архиве, закрыта), копирование каждой фразы дословно, «Пропустить»/«Я разобрался» отправляют статус и уходят на список задач, вход из панели; блок трёх шагов (`TRK-378`) — порядок и ссылки, отметка «сделано» по фактам установки (свежая установка, агент подключён и работает, отозванный/человеческий токен не отмечают первый шаг, отказ запроса токенов), тексты «Зачем это»/«Откуда берутся задачи» дословно на обоих языках
