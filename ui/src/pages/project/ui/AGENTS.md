# src/pages/project/ui

## Файлы

- `project-page.tsx` — сборка экрана на каркасе `HolderScreen`: шапка с «Задачи проекта» и меню «⋯», вкладки «Обзор», «Решения», «Атрибуты», «Направления», «Дело» по `?tab=`; архивный — плашкой и без правок; `project_not_found` словами
- `project-overview.tsx` — вкладка «Обзор»: направления списком, три последних действующих решения и пять последних записей дела ссылками в «Дело», «Все N решений» и «Всё дело»
- `project-directions.tsx` — раздел «Направления» (TRK-557): список направлений проекта отдельным запросом (описание и признак архива), флажок «Показать архивные», «Новое направление»; у строки — название ссылкой на страницу направления, адрес, описание, задачи направления ссылкой в список с отбором, «Изменить» и «В архив»/«Восстановить»
- `project-directions.test.tsx` — список и пустота, архивные по флажку с пометкой, заведение уводит на страницу направления, правка и архив с причиной, ссылка на задачи направления с отбором, архивный проект — без действий
- `project-decisions.tsx` — решения проекта (TRK-554): действующие списком со статусом, автором, временем, «Заменило» и числом задач ссылкой в список задач с отбором `decision:` и архивом; заменённые свёрнуты кнопкой, у каждого — чем заменено; ссылка решения открывает его запись во вкладке «Дело» (`?entry=N`), тела здесь нет; список, а не таблица
- `project-decisions.test.tsx` — действующее сверху, заменённое свёрнуто и раскрывается с преемником, задачи по решению — ссылка с отбором и архивом, ссылка решения открывает «Дело» с раскрытой записью; оба пустых состояния
- `project-actions.test.tsx` — действия с проектом: видимость на вкладках и «⋯» в шапке вместо «Изменить» и «В архив», остаток описания и запрет отправки сверх него, изменение и снятие атрибута без причины не уходят, заметка записью `note`, отказы на обоих языках, фокус после отмены заметки; архивный только читается
- `project-page.test.tsx` — шапка и вкладки с числами, переход по вкладкам, опись и тело, история атрибута, адрес восстанавливает вкладку и раскрытое, неизвестный `tab`, «Обзор» (направления, последние решения и записи, хвост длинного дела, пустые состояния), `aria-current` в панели, `project_not_found`
