# src/pages/project/ui

## Файлы

- `project-page.tsx` — сборка экрана: ключ, название, описание, переход к задачам проекта, «Изменить» и «В архив»/«Восстановить» набору `main`; архивный — плашкой «в архиве с …» и без правок, атрибутов и заметки; слева атрибуты и решения проекта, справа дело; `project_not_found` словами; состояние `entry` и `attribute` в адресе
- `project-attributes.tsx` — атрибуты: имя кнопкой и нынешнее значение текстом как есть, «Добавить атрибут», «Изменить» и «Снять» у строки; история атрибута по клику — отбор `attribute` (TRK-166) на сервере, карточками `EntryCard`
- `project-case.tsx` — дело проекта описью `EntryIndex` (владелец — проект), «Написать заметку» с формой над описью и фокусом туда и обратно: строки из записей `GET /projects/{key}/entries`, тело по клику, следующая страница по кнопке
- `project-decisions.tsx` — решения проекта (TRK-554): действующие списком со статусом, автором, временем, «Заменило» и числом задач ссылкой в список задач с отбором `decision:` и архивом; заменённые свёрнуты кнопкой, у каждого — чем заменено; ссылка решения раскрывает его запись в деле ниже (`?entry=N`), тела здесь нет; список, а не таблица
- `project-decisions.test.tsx` — действующее сверху, заменённое свёрнуто и раскрывается с преемником, задачи по решению — ссылка с отбором и архивом, ссылка решения пишет `entry` в адрес, не трогая `attribute`; оба пустых состояния
- `project-actions.test.tsx` — действия с проектом: видимость по набору, остаток описания и запрет отправки сверх него, изменение и снятие атрибута без причины не уходят, заметка записью `note`, отказы на обоих языках, фокус после отмены заметки; архив и восстановление: не видны набору `task`, без причины не уходят, архивный без правок
- `project-page.test.tsx` — карточка, атрибуты, история по клику, опись и тело, адрес восстанавливает раскрытое, `aria-current` в панели, `project_not_found`
