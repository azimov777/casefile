# src/pages/project/ui

## Файлы

- `project-page.tsx` — сборка экрана на каркасе `HolderScreen`: шапка с «Задачи проекта» и меню «⋯», вкладки «Обзор», «Решения», «Атрибуты», «Области», «Дело» по `?tab=`; архивный — плашкой и без правок; `project_not_found` словами
- `project-overview.tsx` — вкладка «Обзор»: области списком, последние действующие решения и записи дела ссылками в «Дело», «Все N решений» и «Всё дело»
- `project-counters.test.tsx` — строка «Не подтверждено решений» проекта и области; счётчики шапки проекта и области: данные, ноль, `null`, отказ одного запроса, загрузка; ссылка каждого равна ожидаемому отбору, запрос на счётчик с `limit=1`
- `project-areas.tsx` — раздел «Области»: список областей проекта отдельным запросом (описание и признак архива), флажок «Показать архивные», «Новая область»; у строки — название ссылкой на страницу области, адрес, описание, задачи области ссылкой в список с отбором, «Изменить» и «В архив»/«Восстановить»
- `project-areas.test.tsx` — список и пустота, архивные по флажку с пометкой, заведение уводит на страницу области, правка и архив с причиной, ссылка на задачи области с отбором, архивный проект — без действий
- `project-decisions.tsx` — вкладка «Решения»: заголовок блока и список проверки решений проекта и его областей (`features/decisions/review`), ссылка на задачи решения с отбором `decision:` и архивом
- `project-decisions.test.tsx` — метки и действия по состоянию решения, отбор в адресе, «Подтвердить» без окна, окна «Отклонить» и «Удалить» с предупреждением о прежнем решении и числом задач, «Исправить» с `supersedes`, отказ рядом с действием, архивный проект без действий
- `project-actions.test.tsx` — действия с проектом: видимость на вкладках и «⋯» в шапке вместо «Изменить» и «В архив», остаток описания и запрет отправки сверх него, изменение и снятие атрибута без причины не уходят, заметка записью `note`, отказы на обоих языках, фокус после отмены заметки; архивный только читается
- `project-page.test.tsx` — шапка и вкладки с числами, переход по вкладкам, опись и тело, история атрибута, адрес восстанавливает вкладку и раскрытое, неизвестный `tab`, «Обзор» (области, последние решения и записи, хвост длинного дела, пустые состояния), `aria-current` в панели, `project_not_found`
