# src/pages/project

Экран проекта (`/projects/:key`): шапка с меню «⋯» и вкладки «Обзор», решения,
атрибуты с историей, области, дело проекта описью; каркас, меню и разделы
атрибутов и дела — из `features/manage-project` (общие со страницей области).
Состояние — в адресе: `?tab=`, `?entry=N`, `?attribute=имя`.

## Папки

- `ui/` — страница, «Обзор», раздел областей, раздел решений

## Файлы

- `index.ts` — публичный интерфейс среза
