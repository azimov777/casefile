# src/pages

По странице на экран из `docs/CONCEPT.md`, раздел 3. Страница собирает экран
из действий (`features`) и представлений сущностей (`entities`); собственной логики
работы с API у неё нет.

## Папки

- `account/` — своя учётная запись: почта, имя-подпись, смена пароля; только в режиме входа
- `access/` — доступы установки: токены списком, заведение агента, выпуск и отзыв
- `case/` — дело задачи лентой: все записи по типам, отбор, ссылки на записи
- `connect/` — подключить агента: откуда взять токен, фрагменты под клиенты
- `login/` — экран входа: поле токена или почта и пароль учётной записи, объяснение отказа
- `moving/` — перенос установки администратору: скачать архив всех данных, принять его в свежую установку
- `people/` — люди установки администратору: учётные записи, заведение, сброс пароля, отключение; только в режиме входа
- `project/` — экран проекта на чтение: карточка, атрибуты с историей по клику, дело проекта описью, состояние в адресе
- `questions/` — входящая: открытые вопросы участника и ответ на них
- `task/` — карточка задачи: пакет преемника одним запросом, опись дела с раскрытием тел
- `tasks/` — список задач: таблица с признаками, фильтры и язык запросов, листание по курсору
