# src/pages/tasks/ui

Экран списка задач в двух режимах: таблицей и доской.

## Файлы

- `tasks-page.tsx` — сборка экрана, выбор режима, состояния (загрузка, пусто, отказ, отказ разбора), листание
- `tasks-page.module.css` — стили экрана
- `tasks-table.tsx` — таблица: липкая шапка, заданные ширины колонок, строки одной высоты
- `tasks-board.tsx` — доска: столбец на каждое значение статуса из контракта, свёрнутые `done` и `cancelled`
- `tasks-board.module.css` — стили доски
- `view-switch.tsx` — переключатель «таблица / доска» радиогруппой
- `view-switch.module.css` — стили переключателя
- `tasks-page.test.tsx` — состояния экрана с MSW: данные, признаки, пусто, отказы, курсор
- `tasks-board.test.tsx` — столбцы из перечисления клиента, свёрнутость, отбор, дочитывание
