# src/pages/tasks/ui

Экран списка задач в двух режимах: таблицей и доской. Переключатель вида живёт
в верхней полосе оболочки (`features/task-filters/ui/view-switch.tsx`).

## Файлы

- `tasks-page.tsx` — сборка экрана, выбор режима, число выдачи, состояния (загрузка, пусто — со словами о скрытом архиве и кнопкой показать его, страница за концом выдачи, отказ, отказ разбора); полоса обновлений живого потока стоит только над таблицей — доска обновляется сама
- `tasks-table.tsx` — таблица: липкая шапка, заданные ширины колонок, строки одной высоты; рамка — контейнер запроса, и по её ширине выбирается прокрутка вбок или `clip`; областью с именем рамка объявляет себя только там, где прокручивается
- `tasks-pagination.tsx` — ряд страниц под таблицей: число страниц из `meta.total`, ссылки через `tasksHref`
- `tasks-board.tsx` — доска: столбец на каждое значение статуса из контракта, свёрнутые `done`
  и `cancelled`; столбец читает свой отбор сам и дочитывается по мере прокрутки, его
  заголовок липнет к верху столбца там, где у столбца есть своя прокрутка, а ниже точки
  остановки прижат к верху окна шкалой прокрутки доски; у нижнего края столбца стоит знак —
  полоска с тенью, видимая ровно тогда, когда за краем есть ещё карточки
- `tasks-page.test.tsx` — состояния экрана с MSW: данные, признаки, пусто, отказы, страницы; архив — флажок, адрес, ссылка, сброс, пустота, доска во всех запросах, позиция отказа в строке человека, порог не в ключе
- `tasks-board.test.tsx` — столбцы из перечисления клиента, свёрнутость, отбор, счёт запросов
  на отрисовку доски и состояния дочитывания (идёт, кончилось, отказ)
