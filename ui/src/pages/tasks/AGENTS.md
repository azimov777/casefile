# src/pages/tasks

Список задач. Отбор живёт в `features/task-filters`, строка — в `entities/task`;
страница собирает их и рисует состояния. Таблица читает страницу выдачи одним
запросом, доска — по запросу на столбец, и столбец дочитывается по мере прокрутки.

## Папки

- `model/` — сторож конца столбца: наблюдатель пересечения вместо кнопки «Ещё»
- `ui/` — экран, таблица и доска

## Файлы

- `index.ts` — публичный интерфейс среза: `TasksPage`
