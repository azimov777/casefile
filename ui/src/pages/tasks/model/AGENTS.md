# src/pages/tasks/model

Механика экрана списка, не рисующая ничего сама.

## Файлы

- `end-reach.ts` — сторож в конце содержимого: наблюдатель пересечения зовёт «дочитать»,
  корнем берёт саму область, когда та прокручивается сама, и окно, когда нет
- `end-reach.test.ts` — выбор корня по вычисленному стилю, снятый наблюдатель при запрете
  и пересадка сторожа на пришедшее содержимое
