# src/pages/tasks/model

Механика экрана списка, не рисующая ничего сама.

## Файлы

- `end-reach.ts` — сторож в конце содержимого и два вопроса к нему: `useEndReach` зовёт
  «дочитать», когда сторож показался, а `useBeyondEdge` говорит, есть ли за нижним краем
  ещё, — для знака края столбца. Корнем оба берут саму область, когда та прокручивается
  сама; дочитывание без неё берёт окно, знак края не показывается вовсе
- `end-reach.test.ts` — выбор корня по вычисленному стилю, снятый наблюдатель при запрете,
  пересадка сторожа на пришедшее содержимое и знак края по уходу сторожа за край
