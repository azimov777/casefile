# src/pages/discussion/ui

## Файлы

- `conclusion-box.tsx` — итог сверху тремя частями «решено / заменено / открыто» со строкой, чей он и когда
- `discussion-page.tsx` — страница: шапка с чьим ходом, плашка закрытого, итог, привязанные задачи с «Привязать» и «Отвязать», переписка и «Заметка»; закрытое без форм; нет обсуждения — словами
- `discussion-page.test.tsx` — экран обсуждения: шапка и итог, ответ и заметка, привязка и отвязка задачи, закрытое без форм, нет такого — словами
- `thread.tsx` — переписка: вопросы с раскрываемым телом и «Ответить на #N», ответы, заметки, итоги, служебные записи строками
