# src/pages/discussion

Экран обсуждения (TRK-672, решение проекта `TRK#51`, п. 8): итог сверху, привязанные
задачи, вся переписка по времени, ответ и заметка. Адрес — `/discussions/:address`,
например `/discussions/TRK~7`; `?entry=N` — запись, на которую пришли по ссылке.

## Папки

- `ui/` — сборка страницы и её тесты

## Файлы

- `index.ts` — публичный интерфейс среза: `DiscussionPage`
