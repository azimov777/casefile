# src/pages/login/ui

Экран входа целиком: обрамление вокруг формы из `features/auth`.

## Файлы

- `login-page.tsx` — заголовок, пояснение о просроченном сеансе, переключатель языка, форма токена или пароля установки, переход на `/tasks`;
  карточка прижата к верху, оформление утилитами
- `login-page.test.tsx` — состояния входа: годный токен, отказ, агентский токен, нет сети; экран на двух языках
- `password-login.test.tsx` — установка под паролем: форма пароля вместо токена, неверный пароль и окно попыток словами входа, ключ после входа, отказ «пароль принят, ключа нет», выход, закрывающий сеанс
