# src/pages/login/ui

Экран входа целиком: обрамление вокруг формы из `features/auth`.

## Файлы

- `login-page.tsx` — заголовок, пояснение о просроченном сеансе, переключатель языка, форма токена или почты и пароля учётной записи, переход на `/tasks`;
  карточка прижата к верху, оформление утилитами
- `login-page.test.tsx` — состояния входа: годный токен, отказ, агентский токен, нет сети; экран на двух языках
- `account-login.test.tsx` — режим входа: почта и пароль вместо токена, неверные данные, отключённая учётная запись и окна попыток словами входа, токен сеанса из ответа и после перезагрузки, почта в панели, выход, закрывающий сеанс, конец сеанса посреди работы
