# src

Исходный код интерфейса по слоям Feature-Sliced Design. Слой импортирует только слои
ниже, срезы одного слоя друг друга не импортируют, наружу срез отдаёт только `index.ts`.
Нарушения ловит `steiger` в `pnpm check`. Слоя `widgets` в проекте нет намеренно.

Порядок слоёв сверху вниз: `app` → `pages` → `features` → `entities` → `shared`.

## Папки

- `app/` — обвязка приложения: провайдеры, маршруты, оболочка с шапкой
- `pages/` — по странице на экран из `docs/CONCEPT.md`
- `features/` — действия и интерактив: вход и выход, отбор задач
- `entities/` — сущности контракта: сеанс, задача
- `shared/` — клиент API, словарь ошибок, тема, утилиты, кирпичи интерфейса

## Файлы

- `main.tsx` — точка входа: подключает глобальные стили и монтирует `App`
