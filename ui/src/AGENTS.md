# src

Исходный код интерфейса по слоям Feature-Sliced Design, сверху вниз: `app` → `pages` → `features` →
`entities` → `shared`. Правила импортов между слоями и срезами — решение TRK#249, их стережёт `steiger`.

## Папки

- `app/` — обвязка приложения: провайдеры, маршруты, оболочка с шапкой
- `pages/` — по странице на экран
- `features/` — действия и интерактив: вход и выход, отбор задач
- `entities/` — сущности контракта: сеанс, задача
- `shared/` — клиент API, словарь ошибок, тема, утилиты, кирпичи интерфейса

## Файлы

- `main.tsx` — точка входа: подключает глобальные стили, спрашивает установку про ключ
  и монтирует `App`
