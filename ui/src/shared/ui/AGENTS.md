# src/shared/ui

Кирпичи интерфейса. Библиотек компонентов в проекте нет намеренно: чужая библиотека
тянет свою тему и свой словарь.

## Файлы

- `button.tsx` — кнопка, основная и второстепенная
- `button.module.css` — стили кнопки
- `callout.tsx` — короткое сообщение о состоянии; отказ объявляется программе чтения с экрана
- `callout.module.css` — стили сообщения
- `index.ts` — публичный интерфейс сегмента
