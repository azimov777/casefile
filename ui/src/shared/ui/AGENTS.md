# src/shared/ui

Кирпичи интерфейса. Библиотек компонентов в проекте нет намеренно: чужая библиотека
тянет свою тему и свой словарь.

## Файлы

- `badge.tsx` — короткая метка в строке: статус, приоритет, тег, признак
- `badge.module.css` — стили метки
- `button.tsx` — кнопка, основная и второстепенная
- `button.module.css` — стили кнопки
- `callout.tsx` — короткое сообщение о состоянии; отказ объявляется программе чтения с экрана
- `callout.module.css` — стили сообщения
- `composer.tsx` — форма записи в дело: поле markdown, предпросмотр, черновик, упрёк за пустоту
- `composer.module.css` — стили формы; всё изменчивое ниже кнопок, кнопка не едет
- `markdown.tsx` — markdown без HTML; `TRK-42` и `TRK-42#12` в тексте становятся ссылками
- `markdown.module.css` — плотная типографика разметки
- `query-state.tsx` — состояние запроса вместо данных: загрузка, отказ с повтором, пустота
- `query-state.module.css` — стили состояния запроса
- `receipt.tsx` — подтверждение подшитой записи: что случилось, номер ссылкой и текст
- `receipt.module.css` — стили подтверждения
- `relative-time.tsx` — «3 мин. назад» с точным временем в подсказке
- `task-text.tsx` — строка обычного текста, в которой ссылки на задачи кликабельны
- `index.ts` — публичный интерфейс сегмента
