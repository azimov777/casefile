# src/shared/i18n

Механизм языка интерфейса: чем сказать человеку слово и как выбирается, на каком языке.
Наружу сегмент отдаёт `index.ts`; подписи берут не отсюда, а из `react-i18next`
(`useTranslation`, `Trans`) — типы ключей уже настроены.

## Папки

- `dictionaries/` — словари языков по пространствам имён и сверка их наборов ключей

## Файлы

- `languages.ts` — какие языки есть, как они называются на себе, ключ хранилища выбора, язык по умолчанию
- `i18n.ts` — единственный экземпляр `i18next`: определитель языка, порядок выбора, смена языка на месте
- `use-language.ts` — текущий язык и способ его сменить внутри компонента, с подпиской на смену
- `i18next.d.ts` — типизация ключей: опечатка в `t('…')` и ключ, забытый в английском словаре, роняют сборку
- `index.ts` — публичный интерфейс сегмента
