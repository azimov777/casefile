# src/shared/i18n/dictionaries/ru

Русский словарь: набор ключей обязан совпадать с английским. Один файл — одно пространство имён; имя пространства заменяет здесь
принадлежность срезу, потому что импортировать срезы `shared` не вправе.

## Файлы

- `login.ts` — экран входа: заголовок, поле токена, подсказка с командой, кнопка, просроченный сеанс
- `tasks.ts` — экран списка: заголовок и счётчики, таблица, доска, ряд страниц, отбор и его условия словами, архив (флажок, подсказка, пустота при скрытом)
- `task.ts` — карточка задачи: шапка, блоки задания, разделы, опись дела
- `case.ts` — лента дела: окно записей, отбор по типам, конец ленты
- `connect.ts` — экран «Подключить агента»: вступление, откуда взять токен, флажок общего токена, скил дисциплины
- `questions.ts` — входящая: обе половины, отбор по очереди и блокирующим, пустота по отбору
- `ui.ts` — подписи механизма, а не экрана: оболочка, кирпичи `shared/ui`, представление задачи и записи, живой поток, ответ и замечание, текст для копирования, фрагменты подключения агента
- `errors.ts` — тексты отказов по `error.code` бэкенда: справочник `../docs/ERRORS.md` целиком
- `index.ts` — словарь языка целиком: сюда вписывается новое пространство имён
