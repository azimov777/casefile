# src/shared/i18n/dictionaries

Словари языков, вшитые в сборку: по папке на язык, внутри — по файлу на пространство
имён. Языки добавляются папкой рядом и строкой в `languages.ts`, пространства — файлом
и двумя строками в `index.ts` языка.

## Папки

- `en/` — английский словарь; он же источник типов ключей, потому что английский — язык по умолчанию
- `ru/` — русский словарь

## Файлы

- `index.ts` — все языки одним объектом для `i18next`; здесь же названа причина, почему словари лежат в `shared`
- `dictionaries.test.ts` — наборы ключей всех языков совпадают, формы множественного числа не считаются расхождением
