# src/shared/i18n/dictionaries/en

Английский словарь: язык по умолчанию и источник типов ключей. Один файл — одно пространство имён; имя пространства заменяет здесь
принадлежность срезу, потому что импортировать срезы `shared` не вправе.

## Файлы

- `login.ts` — экран входа: заголовок, поле токена, подсказка с командой, кнопка, просроченный сеанс
- `ui.ts` — подписи механизма, а не экрана: переключатель языка и обёртки текста ошибки
- `errors.ts` — тексты отказов по `error.code` бэкенда: справочник `../tracker/docs/ERRORS.md` целиком
- `index.ts` — словарь языка целиком: сюда вписывается новое пространство имён
