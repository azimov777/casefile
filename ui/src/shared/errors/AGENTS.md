# src/shared/errors

Тексты ошибок для человека: выбор текста по `error.code` и по брошенному значению; сами тексты — в пространстве
`errors` словарей (`shared/i18n`). Причины у отдельных полей (`details.fields[].reason`) — рядом, своим пространством
`fieldReasons`: их полноту, в отличие от `errors`, никто не проверяет.

## Файлы

- `fields.ts` — поля, на которые жалуется отказ (`invalidFields`, `complainsAbout`): `details.fields` домена и `details.errors` разбора схемы запроса
- `text.ts` — выбор текста по коду и по брошенному значению (`errorMessage`) на языке интерфейса; неизвестный код показывает фразу бэкенда и сам код; `fieldReasonText` — то же для причины у поля, с запасным текстом по коду причины
- `text.test.ts` — сверка словаря каждого языка со справочником бэкенда и выбор текста на каждом языке
- `index.ts` — публичный интерфейс сегмента
