# src/shared/errors

Тексты ошибок для человека. Решения принимаются по `error.code`, а не по `message`
бэкенда: он техническая фраза для журнала. Сами тексты переезжают в словари языков
(`shared/i18n`), и здесь остаётся выбор текста плюс непереехавший остаток.

## Файлы

- `dictionary.ts` — временный остаток: коды на русском, ещё не переехавшие в пространство `errors` словарей языков
- `text.ts` — выбор текста по коду и по брошенному значению (`errorMessage`) на языке интерфейса; неизвестный код показывает фразу бэкенда и сам код
- `dictionary.test.ts` — сверка обоих источников со справочником бэкенда и выбор текста на каждом языке
- `index.ts` — публичный интерфейс сегмента
