# src/shared/errors

Тексты ошибок для человека. Решения принимаются по `error.code`, а не по `message`
бэкенда: он техническая фраза для журнала. Сами тексты живут в пространстве `errors`
словарей языков (`shared/i18n`), здесь — выбор текста по коду и по брошенному значению.

## Файлы

- `text.ts` — выбор текста по коду и по брошенному значению (`errorMessage`) на языке интерфейса; неизвестный код показывает фразу бэкенда и сам код
- `text.test.ts` — сверка словаря каждого языка со справочником бэкенда и выбор текста на каждом языке
- `index.ts` — публичный интерфейс сегмента
