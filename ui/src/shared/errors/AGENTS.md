# src/shared/errors

Тексты ошибок для человека. Решения принимаются по `error.code`, а не по `message`
бэкенда: он техническая фраза для журнала.

## Файлы

- `dictionary.ts` — коды из `../tracker/docs/ERRORS.md` на русском плюс коды самого клиента
- `text.ts` — выбор текста по коду и по брошенному значению (`errorMessage`); неизвестный код показывает фразу бэкенда и сам код
- `dictionary.test.ts` — сверка словаря со справочником бэкенда и выбор текста по коду
- `index.ts` — публичный интерфейс сегмента
