# src/shared

Нижний слой: код без знания о предметной области экранов. Слоёв ниже нет, поэтому
импортировать отсюда можно откуда угодно, а сам он не импортирует ничего сверху.

## Папки

- `api/` — сгенерированные типы контракта, клиент, разбор оболочки ответа, хранилище токена
- `errors/` — текст отказа для человека по коду ошибки бэкенда; сами тексты живут в словарях языков
- `i18n/` — механизм языка: словари, выбор языка, типизация ключей подписей
- `lib/` — чистые утилиты: время и числа для человека, склейка классов, адреса, черновики
- `styles/` — переменные темы и сброс
- `ui/` — кирпичи интерфейса: кнопка, сообщение о состоянии
