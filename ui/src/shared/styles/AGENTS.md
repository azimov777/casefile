# src/shared/styles

Тема и сброс. Цвета, отступы и шрифты берутся только отсюда — переменными.

## Файлы

- `tokens.css` — переменные светлой и тёмной темы, выбор по `prefers-color-scheme`
- `reset.css` — сброс и базовая типографика
- `index.css` — единственная точка подключения, её импортирует `src/main.tsx`
