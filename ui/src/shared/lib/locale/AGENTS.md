# src/shared/lib/locale

То, что зависит от выбранного языка: подпись времени и число для человека.

Язык сюда всегда приходит параметром и нигде не читается из глобального состояния —
как и «сейчас». Берёт его вызывающий: внутри компонента хуком `useLanguage`, снаружи —
`currentLanguage()` из `@/shared/i18n`. Наружу группа отдаёт `index.ts`, а дальше её
пересобирает `../index.ts` вместе с остальными утилитами.

## Файлы

- `intl.ts` — разбор форматтеров `Intl` по языку (`perLanguage`) и число с разделителем разрядов (`formatNumber`)
- `intl.test.ts` — по форматтеру на язык и ни одним больше; разряды разделены и у языков разные
- `time.ts` — относительная подпись времени и точная для подсказки; обе чистые, язык и «сейчас» параметром
- `time.test.ts` — границы ступеней на каждом языке, местный пояс, негодные значения, цена форматтера
- `index.ts` — публичный интерфейс группы
