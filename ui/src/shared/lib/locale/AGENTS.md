# src/shared/lib/locale

То, что зависит от выбранного языка: подпись времени и число для человека. Язык и «сейчас» приходят
параметром от вызывающего (`useLanguage` в компоненте, `currentLanguage()` из `@/shared/i18n` снаружи); наружу
группа отдаёт `index.ts`, его пересобирает `../index.ts`.

## Файлы

- `intl.ts` — разбор форматтеров `Intl` по языку (`perLanguage`) и число с разделителем разрядов (`formatNumber`)
- `intl.test.ts` — по форматтеру на язык и ни одним больше; разряды разделены и у языков разные
- `time.ts` — относительная подпись времени, точная для подсказки и момент «можно взять с …» (`momentLabel`); все чистые, язык и «сейчас» параметром
- `time.test.ts` — границы ступеней на каждом языке, местный пояс, негодные значения, цена форматтера
- `index.ts` — публичный интерфейс группы
