# src/shared/lib

Чистые утилиты без знания о предметной области экранов.

## Папки

- `locale/` — то, что зависит от выбранного языка: время и числа для человека

## Файлы

- `cn.ts` — склейка классов утилит: из конфликтующих остаётся последний; здесь же
  настройка `tailwind-merge` со шкалами `@theme` — без неё кегль проигрывал бы цвету
- `cn.test.ts` — сторож: имена шкал в настройке совпадают со шкалами `theme.css`,
  кегль рядом с цветом остаётся на месте
- `exit-hold.ts` — держит узел, пока идёт выход: `{open ? … : null}` убрал бы его в том же
  кадре, и анимировать было бы нечего. Одна на весь интерфейс; снимает узел, когда
  кончились движения его корня (ссылка `ref`), а срок из `--motion-fast` решает только,
  был ли кадр вовсе, — и потому гаснет вместе с движением
- `exit-hold.test.ts` — тот самый кадр «уже убран, ещё в разметке», снятие ожидания
  у вернувшегося узла, чтение токена в обеих единицах и его отсутствие; конец выхода
  по движениям узла на подменённом `getAnimations`, погашенное движение и вкладка без кадров
- `task-refs.ts` — разбор ссылок `TRK-42` и `TRK-42#12` в тексте, адрес, куда они ведут,
  и проект, читаемый из ключа задачи
- `task-refs.test.ts` — что считается ссылкой, а что остаётся текстом
- `draft.ts` — черновик записи в `sessionStorage` вместе с ключом повтора: общий для всех форм
- `list-return.ts` — адрес списка с отбором, с которого человек ушёл в задачу
- `paging.ts` — арифметика страниц: сколько их при таком общем числе и какие номера показать рядом с текущим
- `paging.test.ts` — округление вверх, пустая выдача без страниц, ряд у краёв и пропуск, который не прячет одну страницу
- `selection.ts` — не уводить по растянутой ссылке того, кто выделял текст
- `index.ts` — публичный интерфейс сегмента
