# src/shared/lib

Чистые утилиты без знания о предметной области экранов.

## Файлы

- `task-refs.ts` — разбор ссылок `TRK-42` и `TRK-42#12` в тексте и адрес, куда они ведут
- `task-refs.test.ts` — что считается ссылкой, а что остаётся текстом
- `time.ts` — относительная подпись времени и точная для подсказки
- `time.test.ts` — ступени относительного времени и разбор негодных значений
- `index.ts` — публичный интерфейс сегмента
