# src/entities/discussion

Обсуждение (решение проекта `TRK#51`): переписка человека и агентов по
одному узкому вопросу, с итогом сверху и привязанными задачами.

## Папки

- `api/` — типы обсуждения из контракта, ключи и запросы: список с отбором, карточка, лента дела
- `ui/` — чей ход отметкой и обсуждение строкой списка

## Файлы

- `index.ts` — публичный интерфейс среза
