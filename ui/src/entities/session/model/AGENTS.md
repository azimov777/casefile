# src/entities/session/model

Состояние сеанса, живущее вне React: его меняют перехватчик `401`, конфигурация
установки и соседняя вкладка.

## Файлы

- `expiry.ts` — признак «сохранённый токен больше не годится» с подпиской
- `use-session-expired.ts` — тот же признак как состояние React
- `use-session-token.ts` — действующий ключ как состояние React
- `use-token-pending.ts` — «установку про ключ ещё спрашивают»: страж ждёт, а не уводит на вход
- `use-install-key.ts` — «ключ отдала установка»: выхода при нём нет, если установка не закрыта паролем
- `use-install-locked.ts` — «установка закрыта паролем владельца»: вход паролем и выход, закрывающий сеанс
