# src/entities/direction

Направление проекта (TRK-557, `../docs/CONCEPT.md`, 3.7): часть работы проекта без конца,
со своей карточкой, атрибутами и делом. Задача входит не более чем в одно направление.

## Папки

- `api/` — типы направления из контракта, ключи и запросы карточки и списка направлений проекта
- `model/` — значение отбора «без направления» и предел описания
- `ui/` — направление ссылкой на его страницу

## Файлы

- `index.ts` — публичный интерфейс среза
