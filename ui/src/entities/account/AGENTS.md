# src/entities/account

Учётная запись человека (`TRK-113`): тип из контракта, список учётных записей установки и
представление одной из них. Пароля здесь нет ни в каком виде — сгенерированный приходит
один раз ответом на заведение или сброс (`features/manage-people`).

## Папки

- `api/` — тип учётной записи, признак отключения и список установки страницами по курсору
- `ui/` — учётная запись карточкой: почта, имя-подпись, администратор, отключена ли, кем заведена

## Файлы

- `index.ts` — публичный интерфейс среза: `accountsQueryOptions`, `accountKeys`, `isDisabled`, `ACCOUNT_PAGE_SIZE`, `AccountItem`, тип `Account`
