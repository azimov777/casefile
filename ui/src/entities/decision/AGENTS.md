# src/entities/decision

Решение проекта или области как строка списка поперёк дел (TRK-755): тип из контракта, чтение всех решений проекта и его областей или всех проектов, разбор адреса решения.

## Папки

- `api/` — строка списка решений, исход и состояние проверки, ключи и запрос `GET /api/v1/decisions` страница за страницей
- `model/` — разбор адреса решения `TRK#15` и `TRK/mcp#3` на владельца дела и номер, ссылка на запись

## Файлы

- `index.ts` — публичный интерфейс среза
