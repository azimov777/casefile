# src/entities/task/ui

Представление задачи: то, что рисуют и список, и карточка.

## Файлы

- `task-row.tsx` — строка таблицы одной высоты: поля задачи, признаки из `features`, плашка родителя в гнезде одной ширины справа в ячейке названия (UI-152); на узком месте (`@max-list:`) та же строка — карточка с переносом названия
- `task-card.tsx` — задача карточкой для доски: родитель первой строкой, ключ, приоритет, название, исполнитель, признаки
- `parent-badge.tsx` — родитель в строке таблицы плашкой «родитель KEY»; нажатие открывает панель «Родитель задачи X» с родителями ссылками
- `task-parents.tsx` — родитель задачи подписью в одну строку «ключ · название» ссылкой в него; при нескольких — первый ссылкой и «+N», все в подсказке; её ставит карточка доски
- `task-parents.test.tsx` — карточка и строка с родителем, с двумя и без: место подписи, подъём над растяжкой, куда ведёт клик, обводка строки
- `status-mark.tsx` — статус формой: кольцо, половина, пауза, залитый круг; имя из контракта рядом
- `priority-mark.tsx` — приоритет высотой столбиков; `critical` — единственная заливка в строке
- `link-kind.tsx` — знак вида связи: идентификатор моноширинным и подпись рядом; порядок групп по значимости
- `marks.test.tsx` — у каждого значения контракта своя форма, и род значения слышен диктору
- `feature-marks.tsx` — признаки знаками: замок, вопрос, флажок; блокирующий вопрос — состояние знака вопросов; `pressable` (шапка задачи) делает знак переключателем числа на фразу признака, в строке и на карточке знак остаётся подсказкой — нажатие там ведёт в задачу (UI-163)
- `feature-badges.ts` — есть ли что показывать значками; отдельным файлом ради горячей перезагрузки
- `task-nav.tsx` — липкая строка над задачей: возврат в список и переключение «Карточка — Дело» слева, действие страницы справа — переключатель на обеих страницах на одном месте (UI-144)
- `columns.ts` — порядок столбцов списка ключами словаря; отдельным файлом, чтобы не ломать горячую перезагрузку
- `tones.ts` — соответствие «статус → тон» и «приоритет → тон» для плашек
- `tones.test.ts` — полнота соответствия и различимость статусов и приоритетов
