# src/entities/task/ui

Представление задачи: то, что рисуют и список, и карточка.

## Файлы

- `task-row.tsx` — строка таблицы: поля задачи и признаки из `features`
- `task-row.module.css` — стили строки
- `task-card.tsx` — задача карточкой для доски: ключ, приоритет, название, исполнитель, признаки
- `task-card.module.css` — стили карточки
- `status-mark.tsx` — статус формой: кольцо, половина, залитый круг; имя из контракта рядом
- `priority-mark.tsx` — приоритет высотой столбиков; `critical` — единственная заливка в строке
- `marks.test.tsx` — у каждого значения контракта своя форма, и род значения слышен диктору
- `task-features.tsx` — признаки задачи значками; общие для строки списка и карточки
- `feature-badges.ts` — есть ли что показывать значками; отдельным файлом ради горячей перезагрузки
- `task-nav.tsx` — липкая строка над задачей: возврат в список и переключение «Карточка — Дело»
- `task-nav.module.css` — стили строки навигации
- `columns.ts` — заголовки столбцов; отдельным файлом, чтобы не ломать горячую перезагрузку
- `tones.ts` — соответствие «статус → тон» и «приоритет → тон» для плашек
- `tones.test.ts` — полнота соответствия и различимость статусов и приоритетов
