# src/entities/task/model

Правила над задачей, которые интерфейс применяет при чтении списка.

## Файлы

- `archive.ts` — архив (UI-97): порог в днях, условие «не в архиве» на языке запросов,
  склейка с запросом человека по «и», проверка, можно ли обернуть строку скобками, и
  возврат позиции отказа из склейки в строку человека
- `archive.test.ts` — порог и условие при заданных часах, склейка, обёртываемость строк
  (кавычки, `\`, скобки), расклейка отказа и отказы, которые не трогаются
