# src/entities/task/api

Запросы к задачам.

## Файлы

- `tasks.ts` — типы из контракта, набор запрашиваемых полей, размер страницы, ключи
  запросов, настройки запроса списка и накапливающего запроса доски; `fetchTasks` снимает
  признак `hideArchived`, считает порог архива в момент чтения и возвращает отказ склейки
  в строку человека — в ключе запроса даты нет
- `tasks.test.ts` — ключ без даты и свежий порог на каждом чтении, запрос без признака как
  есть, позиция отказа в строке человека, несклеиваемая строка уходит одна
- `task-package.ts` — пакет карточки одним запросом: задача, связи, признаки, сводка,
  вопросы, опись, переходы
