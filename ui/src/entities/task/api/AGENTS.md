# src/entities/task/api

Запросы к задачам.

## Файлы

- `tasks.ts` — типы из контракта, набор запрашиваемых полей, размер страницы, ключи
  запросов, настройки запроса списка и накапливающего запроса доски
- `task-package.ts` — пакет карточки одним запросом: задача, связи, признаки, сводка,
  вопросы, опись, переходы
