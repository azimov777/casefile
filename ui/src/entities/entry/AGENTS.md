# src/entities/entry

Запись дела — задачи или проекта: типы из контракта, чтение тел по номерам, лента дела
страницами, дело проекта, представление записи по её типу и опись с раскрытием тел.
Строки описи задачи приходят в пакете карточки (`entities/task`), строки описи проекта —
записями его дела.

## Папки

- `api/` — типы записи и запрос тел по номерам
- `model/` — заголовок записи по её типу и фактам: одно место на ленту и опись
- `ui/` — представление записи по типу, собранный заголовок и подпись автора

## Файлы

- `index.ts` — публичный интерфейс среза
