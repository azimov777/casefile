# src/entities/entry

Запись дела: типы из контракта, чтение тел по номерам, лента дела страницами
и представление записи по её типу.
Опись (заголовки) приходит в пакете карточки и живёт в `entities/task`; здесь то, что
читается отдельно.

## Папки

- `api/` — типы записи и запрос тел по номерам
- `ui/` — представление записи по типу и подпись автора

## Файлы

- `index.ts` — публичный интерфейс среза
