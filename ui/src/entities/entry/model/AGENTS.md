# src/entities/entry/model

Заголовок записи: то, чем её называют, не читая тела.

У служебных записей, у `answer` и `verdict` заголовок собирает трекер и собирает
по-английски; здесь он строится заново из типа и структурных полей — одинаково для
ленты дела (где приходит `payload`) и описи карточки (где приходят `facts`). Слова
приходят функцией перевода: подписи живут в словаре (`shared/i18n`, `ui.entry`).

## Файлы

- `headline.ts` — `entryHeadline`, приведение нагрузки записи к фактам, строка заголовка словами
- `headline.test.ts` — состав строки по каждому типу на каждом языке и то, что идентификаторы не переведены
- `section-edits.ts` — `groupSectionEdits`: правки разделов одного действия (`action_id`) одной группой; заголовок группы
- `section-edits.test.ts` — группа только из подряд идущих `section_changed` одного `action_id`, `null` и время не группируют
