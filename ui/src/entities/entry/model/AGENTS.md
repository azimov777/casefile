# src/entities/entry/model

Заголовок записи: то, чем её называют, не читая тела.

У служебных записей, у `answer` и `verdict` заголовок собирает трекер и собирает
по-английски; здесь он строится заново из типа и структурных полей — одинаково для
ленты дела (где приходит `payload`) и описи карточки (где приходят `facts`).

## Файлы

- `headline.ts` — `entryHeadline`, названия типов, приведение нагрузки записи к фактам
- `headline.test.ts` — состав строки по каждому типу и то, что идентификаторы не переведены
