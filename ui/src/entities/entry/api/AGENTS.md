# src/entities/entry/api

## Файлы

- `entries.ts` — типы записи и описи, перечисление типов и служебные типы, ключи запросов,
  чтение тела по номеру у задачи (`entries?nos=N`), у проекта и направления (`entries/{no}`),
  лента дела задачи, дело проекта и дело проекта или направления (`holderCaseQueryOptions`,
  TRK-557) страницами по курсору
- `questions.ts` — выдача вопросов поперёк задач: открытые вопросы участника и история с ответами от свежих, своя выдача, а не дело одной задачи
- `remarks.ts` — неразобранные замечания поперёк задач: отбор по автору и проекту, страницы курсором
