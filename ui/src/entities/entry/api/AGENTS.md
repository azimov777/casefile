# src/entities/entry/api

## Файлы

- `entries.ts` — типы записи и описи, перечисление типов и служебные типы, ключи запросов,
  чтение тела по номеру (`entries?nos=N`) и лента дела страницами по курсору
- `questions.ts` — открытые вопросы участника: своя выдача, а не дело одной задачи
- `remarks.ts` — неразобранные замечания поперёк задач: отбор по автору и очереди, страницы курсором
- `AGENTS.md` — эта карта
