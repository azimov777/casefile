# src/entities/entry/ui

## Файлы

- `case-filter-menu.tsx` — содержимое панели «Фильтр»: типы двумя группами (записи агента /
  служебные), подпись группы — кнопка, ставящая или снимающая её целиком; общая для задачи, проекта и области
- `case-filter-menu.test.tsx` — панель без всплывающего слоя: отбор нажатыми
  переключателями, применение по клику, подпись группы не трогает другую группу
- `case-filters.tsx` — строка инструментов («Фильтр» со счётом условий) и строка состояния
  (чипы типов, сброс) — тот же вид, что у отбора задач; один на дело задачи, проекта и области
- `case-type-notices.tsx` — слова про отбор по типу для дела проекта и области: запись из адреса спрятана отбором (со сбросом), отбор ничего не нашёл
- `copy-entry-link.tsx` — кнопка-знак «скопировать ссылку на запись»: адрес экрана владельца (карточки задачи или экрана проекта) с `?entry=N` в буфер, исход и отказ буфера на виду
- `copy-entry-link.test.tsx` — в буфер уходит адрес карточки с номером записи, отказ буфера сказан словами на виду
- `draft-mark.tsx` — `DraftMark`: «Черновик в <адрес> — не поднят» плашкой внимания или «Поднят:» со ссылками на записи адресата; в ленте и описи дела задачи
- `entry-body.tsx` — тело записи по её типу: сводка, вопрос, ответ, вердикт, служебные
- `entry-body.test.tsx` — каждый тип из контракта показан своим представлением, а не сырой нагрузкой, и без английских заготовок; правка решений задачи — ссылками на решения, пустой список словами
- `entry-card.tsx` — запись в ленте: номер, тип, автор, время, копирование ссылки `KEY#N`
- `entry-kind.tsx` — род записи знаком: свой рисунок на каждый тип контракта, идентификатор рядом; `EntryTypeIcon` — голый знак без подписи, для панели отбора записей дела
- `entry-kind.test.tsx` — у каждого типа контракта свой знак, и он назван словом рядом
- `entry-index.tsx` — опись дела задачи или проекта (`EntryOwner`): таблица, на узком месте (`@max-index:`) строками-карточками, тело записи по клику своим запросом, правки разделов одного действия одной строкой, прыжок к записи из адреса
- `decision-status.tsx` — `DecisionStatusMark`: статус решения или заметки плашкой — «действует» тоном «сделано», «заменено» тоном «снято», род («решение» или «заметка») внутри плашки; общая у решений проекта, знания области и описи «Дела»
- `entry-state-mark.tsx` — `EntryStateMark`: плашка статуса и у заменённой «→ адрес преемника» ссылкой; в описи «Дела» у действующей пометки нет
- `entry-headline.tsx` — собранный заголовок: слова по-русски, идентификаторы контракта как есть
- `author-name.tsx` — подпись автора: имя участника или метка, рядом род
