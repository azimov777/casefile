# src/entities/entry/ui

## Файлы

- `copy-entry-link.tsx` — кнопка-знак «скопировать ссылку на запись»: адрес карточки с `?entry=N` в буфер, исход и отказ буфера на виду (UI-155)
- `copy-entry-link.test.tsx` — в буфер уходит адрес карточки с номером записи, отказ буфера сказан словами на виду
- `entry-body.tsx` — тело записи по её типу: сводка, вопрос, ответ, вердикт, служебные
- `entry-body.test.tsx` — каждый тип из контракта показан своим представлением, а не сырой нагрузкой, и без английских заготовок
- `entry-card.tsx` — запись в ленте: номер, тип, автор, время, копирование ссылки `KEY#N`
- `entry-kind.tsx` — род записи знаком: свой рисунок на каждый тип контракта, идентификатор рядом; `EntryTypeIcon` — голый знак без подписи, для панели отбора записей дела (UI-137)
- `entry-kind.test.tsx` — у каждого типа контракта свой знак, и он назван словом рядом
- `entry-headline.tsx` — собранный заголовок: слова по-русски, идентификаторы контракта как есть
- `author-name.tsx` — подпись автора: имя участника или метка, рядом род
