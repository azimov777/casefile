# src/entities/setting

Настройка установки (TRK-744): тип из контракта, список семи настроек, перевод
канонического значения в человеческое (число с единицей) и карточка одной настройки.
Правки здесь нет — её даёт `features/manage-settings`.

## Папки

- `api/` — тип настройки и запрос списка
- `model/` — единицы и разбор значений, подпись значения словами
- `ui/` — настройка карточкой: название, пояснение, значение с источником, умолчание, кто и когда менял

## Файлы

- `index.ts` — публичный интерфейс среза
