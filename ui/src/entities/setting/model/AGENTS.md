# src/entities/setting/model

## Файлы

- `amount.ts` — единицы каждой настройки, разбор канонической строки в число, самая крупная единица без остатка и обратный перевод введённого в каноническую строку
- `amount.test.ts` — те же переводы: часы и дни, секунды срока, байты и мегабайты, отказ на нецелом
- `known.ts` — имена семи настроек реестра и признак «имя известно»: от них зависят ключи подписей
- `use-format-amount.ts` — подпись значения словами на языке интерфейса: `25 МБ`, `30 дн.`, «Включена»
