# src/entities

Сущности контракта: типы, запросы и представление одной сущности. Здесь живёт то,
что переиспользуют несколько экранов.

## Папки

- `session/` — текущий сеанс: первый кадр `bootstrap`, токен, признак просроченного сеанса
- `task/` — задача: типы контракта, запрос списка, строка таблицы с признаками
