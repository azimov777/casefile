# src/entities

Сущности контракта: типы, запросы и представление одной сущности. Здесь живёт то,
что переиспользуют несколько экранов.

## Папки

- `account/` — учётная запись человека: тип контракта, список учётных записей установки, карточка учётной записи
- `entry/` — запись дела: типы контракта, чтение тела по номеру, представление по типу
- `session/` — текущий сеанс: первый кадр `bootstrap`, токен, признак просроченного сеанса
- `task/` — задача: типы контракта, запрос списка и пакета карточки, строка таблицы, признаки
- `token/` — токен доступа: тип контракта, список токенов установки, строка доступа
