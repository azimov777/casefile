# src/entities/token

Доступ установки: токен из контракта с видом строки (`kind`: сеанс, ключ агента,
подключение OAuth), список токенов и представление одной строки доступа. Секрета здесь нет и быть не может — он живёт только в ответе на выпуск
(`features/manage-access`).

## Папки

- `api/` — тип токена, вид строки, признаки отзыва, жизни и принадлежности и список токенов (все или свои) страницами по курсору
- `ui/` — строка доступа: чей, какого вида, кто выдал или подключил, когда им ходили, отозван ли

## Файлы

- `index.ts` — публичный интерфейс среза
