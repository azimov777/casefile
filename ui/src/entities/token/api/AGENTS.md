# src/entities/token/api

## Файлы

- `tokens.test.ts` — принадлежность токена человеку и жизнь сеанса по сроку
- `tokens.ts` — тип токена из контракта, `isRevoked` (отзыв — это заполненный `revoked_at`), `isSession` (есть `expires_at`), `isLive` (не отозван и срок не прошёл), `belongsTo` (говорит от имени или выпущен человеком, TRK-114#12), ключи запросов и `tokensQueryOptions`: токены с отозванными страницами по курсору, `mine` сужает до своих
