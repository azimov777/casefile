# src/entities/file/model

## Файлы

- `format-bytes.ts` — ступень и число размера (`splitSize`) и `useFormatBytes`: `48 КБ`, `1,5 МБ` на языке интерфейса
- `format-bytes.test.ts` — границы ступеней
- `kind.ts` — признаки «изображение» и «живой» (не надгробие)
- `save-blob.ts` — сохранение байтов браузером под данным именем
- `use-attachments.ts` — вложения формы записи: файл грузится в проект при выборе, к записи идут id готовых, потолок десять
- `use-file-object-url.ts` — `blob:`-адрес байтов файла: чтение по требованию, адрес отзывается вместе с блоком
