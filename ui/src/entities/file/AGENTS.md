# src/entities/file

## Папки

- `api/` — тип карточки, отбор, ключи запросов, список страницами, карточка, байты файла
- `model/` — размер словами, признаки «изображение» и «живой», адрес `blob:` и сохранение байтов
- `ui/` — файл карточкой и изображение файла
