# src/entities/file/ui

## Файлы

- `file-item.tsx` — файл карточкой: имя, проект, тип, размер, кто и когда добавил, последнее открытие, число ссылок; выбор и действия приходят слотами
- `file-image.tsx` — изображение файла из установки: байты читаются по требованию, а не строкой списка
- `file-image-dialog.tsx` — «Открыть» для изображения: окно с картинкой, байты читаются при открытии окна
- `file-download-button.tsx` — «Скачать»: байты запросом с токеном, сохранение под именем файла, отказ словами
