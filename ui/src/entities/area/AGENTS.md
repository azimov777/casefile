# src/entities/area

Область проекта (TRK#57): часть работы проекта без конца, со своей карточкой, атрибутами и делом.

## Папки

- `api/` — типы области из контракта, ключи и запросы карточки и списка областей проекта
- `model/` — значение отбора «без области» и предел описания
- `ui/` — область ссылкой на её страницу

## Файлы

- `index.ts` — публичный интерфейс среза
