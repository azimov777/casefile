# src/features/manage-onboarding

Состояние знакомства своей учётной записи целиком: `status` — «Пропустить» и
«Я разобрался» на экране «Начало» (`pages/start`) — и `hints` — механизм
пояснений экрана: скрытие по одному и все разом, возврат с экрана «Начало»; проход по экранам поверх тех же пояснений по порядку.

## Папки

- `model/` — мутация `PATCH /api/v1/accounts/{id}/onboarding`, чтение учётной записи
  из `bootstrap`, перечень ключей пояснений,
  порядок шагов прохода и план прохода
- `ui/` — компонент пояснения экрана, действие «Показать пояснения снова», полоса прохода
  и кнопка «Пройти по экранам»

## Файлы

- `index.ts` — публичный интерфейс среза
