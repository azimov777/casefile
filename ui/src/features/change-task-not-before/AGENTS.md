# src/features/change-task-not-before

Момент «можно взять с …» в карточке задачи (TRK-593, TRK#47): человек ставит, меняет и
снимает его на странице задачи. Вторая правка задачи человеком после области; всё
остальное в задаче по-прежнему ведут агенты.

## Папки

- `model/` — правка поля `not_before` и перевод момента между полем `datetime-local` и контрактом
- `ui/` — строка с моментом, значок отложенной задачи, кнопки «Отложить…», «Изменить», «Снять» и окно ввода

## Файлы

- `index.ts` — публичный интерфейс среза: `TaskNotBefore`, `useChangeTaskNotBefore`, `fromLocalInput`, `toLocalInput`
