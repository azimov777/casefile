# src/features/decisions/review

Проверка решений человеком (TRK-755): подтвердить, исправить, отклонить, удалить. Одну строку решения и список берут экран проекта, страница области и Входящая (TRK-759): модуль лежит в `features`, чтобы страницы друг друга не импортировали.

## Папки

- `api/` — ручки проверки решения проекта и области и «Исправить» записью решения с `supersedes`
- `model/` — отбор вкладки из адреса и раскладка строк по отборам, мутации с перечитыванием
- `ui/` — строка решения, список с отбором, окна «Отклонить»/«Удалить» и «Исправить», строка «Не подтверждено решений»

## Файлы

- `index.ts` — публичный интерфейс среза
