# src/features/decisions/review/ui

## Файлы

- `decision-row.tsx` — `DecisionReviewRow`: строка решения (ссылка, метка, название-раскрытие, проект ссылкой (задан во Входящей), область, автор, время, задачи, «откуда»), тело по раскрытию и четыре действия у действующего решения
- `decisions-review.tsx` — `DecisionsReview`: переключатель отбора ссылками, строка состояния после проверки, список; решения одной области и найденные поиском — по параметрам
- `take-dialog.tsx` — окно «Отклонить» и «Удалить» (`alertdialog`): причина необязательна, предупреждение о прежнем решении и число задач
- `revise-dialog.tsx` — окно «Исправить»: название и текст прежнего решения, готовые к правке
- `unconfirmed-line.tsx` — `UnconfirmedLine`: «Не подтверждено решений: N» ссылкой на отбор или «Все решения подтверждены»
