# src/features/auth/ui

Формы входа: токеном и учётной записью. Куда идти после удачи, решает страница.

## Файлы

- `account-login-form.tsx` — почта и пароль учётной записи; отказ неверных данных,
  отключённой учётной записи и окна попыток — словами экрана входа, прочие — общим словарём
- `login-form.tsx` — поле токена, отправка, объяснение отказа по коду ошибки;
  раскладка утилитами, поле ввода берётся кирпичом из `shared/ui`
