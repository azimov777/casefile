# src/features/auth/ui

Формы входа: токеном и паролем владельца. Куда идти после удачи, решает страница.

## Файлы

- `login-form.tsx` — поле токена, отправка, объяснение отказа по коду ошибки;
  раскладка утилитами, поле ввода берётся кирпичом из `shared/ui`
- `password-form.tsx` — поле пароля установки, закрытой замком; отказ неверного пароля и
  окна попыток — словами экрана входа, прочие — общим словарём
