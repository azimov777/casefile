# src/features/auth/model

Что происходит при входе и выходе.

## Файлы

- `use-account-login.ts` — вход почтой и паролем: токен сеанса из ответа входа становится ключом вкладки
- `use-login.ts` — проверка токена запросом `bootstrap`; сохраняет только годный
- `use-logout.ts` — сброс токена, признака просроченного сеанса, кэша запросов; в режиме входа сначала закрывает сеанс на сервере
