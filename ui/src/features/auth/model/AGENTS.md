# src/features/auth/model

Что происходит при входе и выходе.

## Файлы

- `use-login.ts` — проверка токена запросом `bootstrap`; сохраняет только годный
- `use-logout.ts` — сброс токена, признака просроченного сеанса, кэша запросов; на установке под паролем сначала закрывает сеанс на сервере
- `use-password-login.ts` — вход паролем владельца: сеанс в куке, затем ключ от установки заново
