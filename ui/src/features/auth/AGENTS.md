# src/features/auth

Вход и выход. Токен проверяется запросом `bootstrap` и сохраняется только после удачи;
токен без участника (общий агентский) не принимается — интерфейс построен вокруг
участника. В режиме входа по учётным записям (`TRK-113`) вход — почтой и паролем: ответ
входа отдаёт токен сеанса, вкладка держит его в памяти, а кука возвращает его после
перезагрузки; выход закрывает сеанс на сервере.

## Папки

- `model/` — `use-login.ts` (проверка и сохранение токена), `use-account-login.ts` (вход почтой и паролем), `use-logout.ts` (сброс токена и кэша, закрытие сеанса)
- `ui/` — `login-form.tsx` и `account-login-form.tsx`: формы входа, оформление утилитами

## Файлы

- `index.ts` — публичный интерфейс среза: `AccountLoginForm`, `LoginForm`, `useAccountLogin`, `useLogin`, `useLogout`
