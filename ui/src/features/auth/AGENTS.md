# src/features/auth

Вход и выход. Токен проверяется запросом `bootstrap` и сохраняется только после удачи;
токен без участника (общий агентский) не принимается — интерфейс построен вокруг
участника. На установке, закрытой паролем владельца, вход — паролем: он открывает сеанс
в куке, и ключ отдаёт сама установка; выход закрывает сеанс на сервере.

## Папки

- `model/` — `use-login.ts` (проверка и сохранение токена), `use-password-login.ts` (вход паролем), `use-logout.ts` (сброс токена и кэша, закрытие сеанса)
- `ui/` — `login-form.tsx` и `password-form.tsx`: формы входа, оформление утилитами

## Файлы

- `index.ts` — публичный интерфейс среза: `LoginForm`, `PasswordForm`, `useLogin`, `usePasswordLogin`, `useLogout`
