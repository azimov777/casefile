# src/features/auth

Вход и выход. Токен проверяется запросом `bootstrap` и сохраняется только после удачи;
токен без участника (общий агентский) не принимается — интерфейс построен вокруг
участника.

## Папки

- `model/` — `use-login.ts` (проверка и сохранение токена), `use-logout.ts` (сброс токена и кэша)
- `ui/` — `login-form.tsx` и его стили

## Файлы

- `index.ts` — публичный интерфейс среза: `LoginForm`, `useLogin`, `useLogout`
