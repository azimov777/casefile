# src/features/task-filters/ui

Форма отбора и переключатель вида: то, чем человек меняет выдачу списка.

## Файлы

- `task-filters.tsx` — строка условий, флажок «показывать архив» с подсказкой, сортировка
  и сброс; в развёрнутой форме —
  статусы, приоритеты, исполнитель, теги, текст, переключатели и поле запроса с признаком
  неприменённого черновика и наложенным объяснением отказа. Очереди здесь нет: она стала
  местом в интерфейсе и живёт в боковой панели
- `view-switch.tsx` — переключатель «таблица / доска» ссылками на `tasksHref`: адрес
  строится одним правилом на все точки навигации
