# src/features/task-filters/ui

Форма отбора и переключатель вида: то, чем человек меняет выдачу списка.

## Файлы

- `field.ts` — классы поля отбора и его черновика: одни на поиск, исполнителя и запрос
- `filter-menu.tsx` — панель «Фильтр»: статус (только таблица), приоритет и признаки
  переключателями со знаками строки списка, область списком (любая, «без области»,
  области проекта с архивными), исполнитель полем; применяется сразу
- `filter-menu.test.tsx` — панель без всплывающего слоя: отбор из адреса нажат, нажатие
  применяет, исполнитель ждёт Enter, на доске статуса нет; область без проекта и с ним
- `query-problem-hint.tsx` — признак неприменённого черновика у края поля и наложенное
  объяснение отказа разбора запроса
- `task-counters.tsx` — строка чисел для шапки проекта и области: «В работе», «Открыто», «Ждут ответа», «Закрыты не целиком»; число — `meta.total` по отбору, ссылка — `tasksHref` с тем же отбором, ноль — нулём, отказ — прочерком с подсказкой
- `task-filters.test.tsx` — форма отбора: набранное поле переживает новый объект отбора с теми же
  значениями, а изменившееся мимо формы значение поле перечитывает
- `task-filters.tsx` — строка инструментов (поиск, «Фильтр», сортировка, «Запрос») и строка
  состояния (чипы условий, сброс, флажок архива с пояснением панелью по нажатию); режим запроса сменяет поиск полем языка
  бэкенда. Проекта здесь нет: он стал местом в интерфейсе и живёт в боковой панели
- `view-switch.tsx` — переключатель «таблица / доска» ссылками на `tasksHref`: адрес
  строится одним правилом на все точки навигации; ниже `fold` вид показан знаком, слово — диктору
