# src/features/task-filters/ui

Форма отбора: свёрнутая строка с условиями и раскрываемая форма под ней.

## Файлы

- `task-filters.tsx` — строка условий, сортировка и сброс; в развёрнутой форме — очередь,
  статусы, приоритеты, исполнитель, теги, текст, переключатели и поле запроса с признаком
  неприменённого черновика и наложенным объяснением отказа
- `task-filters.module.css` — стили строки, формы и наложенного объяснения отказа
