# src/features/task-filters/model

Отбор как данные: адрес, параметры запроса, разбор отказа.

## Файлы

- `filters.ts` — тип отбора, чтение и запись адреса, перевод в параметры `GET /api/v1/tasks`
- `filters.test.ts` — круг «адрес → отбор → адрес», приоритет поля запроса, отсев чужих значений
- `query-problem.ts` — позиция и допустимые значения из `details` отказа разбора
- `query-problem.test.ts` — разбор `details` и указатель на позицию
- `use-task-filters.ts` — отбор через `useSearchParams`: правка заменяет запись в истории, «ещё» добавляет
