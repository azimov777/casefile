# src/features/task-filters/model

Отбор как данные: адрес, параметры запроса, разбор отказа.

## Файлы

- `filters.ts` — тип отбора, чтение и запись адреса (включая номер страницы, свёрнутые столбцы доски и показ архива `archive=shown`), перевод в параметры `GET /api/v1/tasks` с признаком скрытого архива; порядок один на таблицу и доску
- `filters.test.ts` — круг «адрес → отбор → адрес», приоритет поля запроса, отсев чужих значений, номер страницы смещением, архив: умолчание, адрес, не условие, параметры без даты
- `href.ts` — адрес списка с изменёнными условиями: одно правило на все точки навигации, номер страницы не переносится, кроме случая, когда меняют его
- `href.test.ts` — сохранение условий при смене вида, сброс страницы, переход по страницам, отсев чужих параметров
- `query-problem.ts` — позиция и допустимые значения из `details` отказа разбора
- `query-problem.test.ts` — разбор `details` и указатель на позицию
- `summary.ts` — включённые условия словами из словаря: что показывает свёрнутый вид отбора
- `summary.test.ts` — полнота перечисления и то, что ни одно условие не свёрнуто в счётчик
- `use-task-filters.ts` — отбор через `useSearchParams`: правка заменяет запись в истории, а страницы листаются ссылками, и запись добавляет браузер; сброс оставляет место и показ архива
