# src/features/live-journal/model

## Файлы

- `stream-client.ts` — открытие SSE с заголовком авторизации и переподключением; граница, подменяемая в тестах
- `frames.ts` — кадр журнала и разбор его тела
- `invalidation.ts` — какие запросы устарели от записи этого типа и что из них ждёт просьбы человека
- `deferred.ts` — единственное место откладывания: до возврата во вкладку и до просьбы показать
- `use-deferred-list.ts` — накопленное для полосы и способ его показать
- `use-live-journal.ts` — поток на вкладку: курсор `seq`, раскладка устаревшего по срокам, статус, вопрос ко мне
- `live-journal.test.tsx` — соединение, кадры, полоса вместо перестановки, обрыв, фон, `401`, уведомление о вопросе
