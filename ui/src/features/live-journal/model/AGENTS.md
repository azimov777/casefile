# src/features/live-journal/model

## Файлы

- `stream-client.ts` — открытие SSE с заголовком авторизации и переподключением; граница, подменяемая в тестах
- `frames.ts` — кадр журнала и разбор его тела
- `invalidation.ts` — какие запросы устарели от записи этого типа и когда их перечитывать: сразу, окном склейки (доска) или по просьбе человека (таблица)
- `deferred.ts` — единственное место откладывания: до возврата во вкладку, до просьбы показать и до конца окна склейки
- `deferred.test.ts` — окно склейки: пачка кадров одним перечитыванием, новое окно после закрытия, три срока не смешиваются
- `use-deferred-list.ts` — накопленное для полосы таблицы и способ его показать
- `use-live-journal.ts` — поток на вкладку: курсор `seq`, раскладка устаревшего по трём срокам, статус, вопрос ко мне
- `live-journal.test.tsx` — соединение, кадры, полоса вместо перестановки строк таблицы, доска, обновляющаяся сама, склейка пачки, обрыв, фон, `401`, уведомление о вопросе
