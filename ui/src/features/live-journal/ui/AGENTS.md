# src/features/live-journal/ui

## Файлы

- `float-dock.tsx` — низ области содержания, общий для полосы обновлений и стопки уведомлений: вне потока вёрстки, внутри — поток, рядом, когда помещаются, и стопка строкой выше полосы, когда нет; от края панели, а не окна
- `live-status.tsx` — состояние потока словами: «подключаемся», «на связи», «нет связи»
- `question-notice.tsx` — стопка уведомлений о вопросах ко мне: стоит у правого края низа области содержания, приход и уход карточки токенами `--animate-appear` и `--animate-disappear`, её место в стопке — строками сетки
- `updates-bar.tsx` — полоса «изменилось задач: N · показать»: предложение обновить таблицу (на доске её нет — та обновляется сама), молчит, пока таблица читается; рисует её страница, а стоит она порталом в низу области содержания
