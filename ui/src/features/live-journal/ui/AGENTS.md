# src/features/live-journal/ui

## Файлы

- `live-status.tsx` — состояние потока словами: «подключаемся», «на связи», «нет связи»
- `question-notice.tsx` — стопка уведомлений о вопросах ко мне: своё место вне потока вёрстки, приход и уход карточки токенами `--animate-appear` и `--animate-disappear`, её место в стопке — строками сетки
- `updates-bar.tsx` — полоса «изменилось задач: N · показать»: предложение обновить таблицу (на доске её нет — та обновляется сама), своё место вне потока вёрстки
