# src/features/live-journal

Живой поток журнала: одно соединение на вкладку, по кадрам перечитывается то, что
человек видит (`docs/CONCEPT.md`, 5).

## Папки

- `model/` — открытие потока, разбор кадров, карта «запись → что устарело и когда», три срока откладывания (включая окно склейки), чтение таблицы, снимающее полосу, сам хук
- `ui/` — индикатор связи, уведомление о вопросе, полоса обновлений таблицы и общий низ области содержания, где эти двое стоят

## Файлы

- `index.ts` — публичный интерфейс среза: `useLiveJournal`, `useDeferredList`, `LiveStatus`, `UpdatesBar`, `QuestionNotice`, `FloatDock`, разбор кадров, `resetDeferred`
