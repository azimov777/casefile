# src/features/live-journal

Живой поток журнала: одно соединение на вкладку, по кадрам перечитывается то, что
человек видит (`docs/CONCEPT.md`, 5).

## Папки

- `model/` — открытие потока, разбор кадров, карта «запись → что устарело», сам хук
- `ui/` — индикатор связи и уведомление о вопросе в шапке

## Файлы

- `index.ts` — публичный интерфейс среза: `useLiveJournal`, `LiveStatus`, разбор кадров
