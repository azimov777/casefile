# src/features/live-journal

Живой поток журнала: одно соединение на вкладку, по кадрам перечитывается то, что
человек видит (`docs/CONCEPT.md`, 5).

## Папки

- `model/` — открытие потока, разбор кадров, карта «запись → что устарело и когда», откладывание, сам хук
- `ui/` — индикатор связи, уведомление о вопросе и полоса обновлений списка

## Файлы

- `index.ts` — публичный интерфейс среза: `useLiveJournal`, `useDeferredList`, `LiveStatus`, `UpdatesBar`, разбор кадров, `resetDeferred`
