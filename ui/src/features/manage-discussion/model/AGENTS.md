# src/features/manage-discussion/model

## Файлы

- `draft.ts` — ключи черновиков ответа на вопрос обсуждения и заметки
- `use-discussion-actions.ts` — мутации ответа, заметки, привязки, отвязки и заведения обсуждения; после каждой перечитываются карточка, списки обсуждений, значок входящей и, при привязке, задача
