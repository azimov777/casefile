# src/features/manage-discussion/ui

## Файлы

- `new-discussion.tsx` — `NewDiscussion`: кнопка и окно «Новое обсуждение» запиской с проектом, названием, текстом и задачами
- `note-form.tsx` — `NoteForm`: свободная заметка человека, заголовок выводится из первой строки
- `option-picker.tsx` — `OptionPicker`: варианты ответа радио-карточками над полем текста, «Снять выбор»
- `reply-form.tsx` — `ReplyForm`: «Ответить на #N», ответ на вопрос обсуждения; у вопроса с вариантами — выбором, текстом или тем и другим
- `task-binding.tsx` — `AttachTaskForm` и `DetachTaskButton`: привязать задачу по ключу, отвязать привязанную
