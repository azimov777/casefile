# src/features/manage-discussion

Действия человека с обсуждением (TRK-672, решение проекта `TRK#51`): ответить на вопрос,
оставить заметку, привязать и отвязать задачу, завести обсуждение запиской. Закрытия нет:
закрывает агент.

## Папки

- `model/` — ключи черновиков и мутации: ответ, заметка, привязка и отвязка, заведение
- `ui/` — формы: «Ответить на #N», «Заметка», «Привязать» и «Отвязать», окно «Новое обсуждение»

## Файлы

- `index.ts` — публичный интерфейс среза
