# src/features/switch-language

Смена языка интерфейса человеком: единственное место, откуда его выбор попадает
в `shared/i18n`. Сам механизм языка, словари и хранение выбора живут там.

## Папки

- `ui/` — `language-switch.tsx`: список языков на `Select` из `shared/ui`

## Файлы

- `index.ts` — публичный интерфейс среза: `LanguageSwitch`
