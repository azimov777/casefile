# src/features/connect-agent

Подключение агента к MCP этой установки: готовые фрагменты под клиенты. Срез общий для двух экранов —
«Подключить агента» показывает фрагменты с подстановкой вместо токена, «Доступы» — с только что выпущенным секретом.

## Папки

- `api/` — адрес MCP установки: `GET /api/v1/installation`
- `model/` — тексты фрагментов из адреса, токена или подстановки и признака метки; выбранный клиент в адресе
- `ui/` — фрагменты выбранного клиента с дорожкой клиентов и кнопками копирования

## Файлы

- `index.ts` — публичный интерфейс среза
