# src/features/manage-project/model

## Файлы

- `rights.ts` — `useProjectRights`: `manage` и `write` открыты всем, `scope` не читается (TRK-473); до первого кадра прав нет
- `use-project-actions.ts` — мутации создания, правки, атрибута, снятия, записи в дело, архива и восстановления проекта (эти две перечитывают ещё списки задач, вопросов и замечаний) и направления (правка и архив направления перечитывают его, проект, карточки и списки задач); ключ повтора окна `useOnceKey`, перечитывание префикса владельца — `['project', key]` или `['direction', адрес]` — и `bootstrap`
- `draft.ts` — ключ черновика записи: одно дело — один черновик; у проекта имя прежнее, у направления — по адресу
- `holder-tab.ts` — вкладка экрана проекта или направления из адреса (`?tab=`; без него `entry` → «Дело», `attribute` → «Атрибуты», иначе вкладка по умолчанию), адрес другой вкладки и раскрытие записи или атрибута без смены вкладки
- `holder-tab.test.ts` — правило вкладки: `tab` задан, `entry` и `attribute` без `tab`, ничего, неизвестный `tab`, вкладка, которой у направления нет; адреса вкладок и закрепление вкладки при свёртывании
- `use-holder-address.ts` — `useHolderAddress`: вкладка, раскрытая запись и атрибут из адреса, их правка `replace`, адреса вкладок и записи
- `menu-actions.ts` — пункты меню «⋯»: у проекта по архиву, у направления по правам страницы
