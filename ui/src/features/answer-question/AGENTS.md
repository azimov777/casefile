# src/features/answer-question

Ответ человека на вопрос агента в деле задачи: форма, черновик, отправка и судьба отправленного.

## Папки

- `model/` — черновик в `sessionStorage` с ключом повтора и сама отправка
- `ui/` — форма ответа с предпросмотром и замечаниями у полей

## Файлы

- `index.ts` — публичный интерфейс среза
