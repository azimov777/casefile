# src/features/answer-question

Ответ на вопрос агента — единственная запись, которую в трекере создаёт человек
(`docs/CONCEPT.md`, 1).

## Папки

- `model/` — черновик в `sessionStorage` с ключом повтора и сама отправка
- `ui/` — форма ответа с предпросмотром и замечаниями у полей

## Файлы

- `index.ts` — публичный интерфейс среза: `AnswerForm`, `useAnswerQuestion`, работа с черновиком
