# src/features/answer-question/model

## Файлы

- `draft.ts` — ключ черновика ответа; сам черновик общий (`shared/lib`)
- `use-answer-question.ts` — отправка ответа и перечитывание того, что от него устарело
- `answering.ts` — судьба вопросов, по которым отправка началась: закрепление на экране и подшитый ответ
