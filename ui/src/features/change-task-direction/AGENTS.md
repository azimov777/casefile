# src/features/change-task-direction

Направление задачи в её карточке (TRK-557, TRK#16, ч. 4): поставить направление проекта
или снять его. Единственная правка задачи, которую делает человек; всё остальное в задаче
по-прежнему ведут агенты (`docs/CONCEPT.md`, 1).

## Папки

- `model/` — правка поля `direction` и перечитывание карточки и списков
- `ui/` — кнопка «Изменить» и окно выбора направления

## Файлы

- `index.ts` — публичный интерфейс среза: `ChangeTaskDirection`, `useChangeTaskDirection`
