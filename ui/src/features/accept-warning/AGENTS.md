# src/features/accept-warning

Реакция человека на предупреждение закрытия (TRK-561): задача закрыта с проверками
`partial` или `unverifiable`, и пока её не приняли или не вернули, она ждёт его хода
(TRK#117). «Принять» — запись `acceptance` одним нажатием; «Вернуть на
доработку» — замечание, его форма живёт в `leave-remark`, и раскрывает её карточка.

## Папки

- `model/` — отправка принятия с ключом повтора и перечитыванием
- `ui/` — плашка предупреждения на карточке задачи

## Файлы

- `index.ts` — публичный интерфейс среза: `WarningPanel`, `useAcceptWarning`
