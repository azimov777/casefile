# src/features/change-task-area

Область задачи в её карточке (TRK-557, TRK#16, ч. 4): поставить область проекта
или снять её. Единственная правка задачи, которую делает человек; всё остальное в задаче
по-прежнему ведут агенты (TRK#235).

## Папки

- `model/` — правка поля `area` и перечитывание карточки и списков
- `ui/` — кнопка «Изменить» и окно выбора области

## Файлы

- `index.ts` — публичный интерфейс среза: `ChangeTaskArea`, `useChangeTaskArea`
