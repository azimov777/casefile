# src/features/manage-access

Доступы установки: завести агента-участника, выпустить ему токен, отозвать лишний.
Все три действия требуют ключа набора `main`, выпуск — ещё и учётной записи за ним, а в
выборе «за кого» человек без флага администратора не видит других людей (TRK-114#12);
решает это первый кадр `GET /api/v1/bootstrap`, а не отказ `403` (`UI-104#7`, `UI-106#18`).
Отказ, который всё же пришёл, объясняется по `details.reason`.

Секрет выпущенного токена **не проходит через кэш запросов**: выпуск идёт не мутацией
TanStack Query, а прямым вызовом, и секрет уезжает вызывающему — экран показывает его
один раз и забывает при закрытии окна. Фрагменты подключения к окну секрета подставляет
страница: срез `features` не вправе импортировать соседний срез своего слоя, а
`ConnectionSnippets` живёт в `features/connect-agent`.

## Папки

- `api/` — запросы реестра и токенов: участники, выпуск, отзыв
- `model/` — состояние трёх действий с ключом повтора из `shared/lib`; причина отказа в праве
- `ui/` — окна: заведение агента, выпуск, секрет один раз, подтверждение отзыва

## Файлы

- `index.ts` — публичный интерфейс среза: `AgentDialog`, `IssueDialog`, `SecretDialog`, `RevokeDialog`, `participantsQueryOptions`, `participantKeys`, типы `IssuedToken`, `Participant`, `IssueInput`, `AgentInput`, `TokenScope`
