# src/features/manage-access

Доступы установки: завести агента-участника, выпустить ему ключ, отозвать лишний доступ или отключить
подключение OAuth; отказ, который всё же пришёл, объясняется по `details.reason`. Секрет выпущенного ключа уезжает
вызывающему мимо кэша запросов и показывается один раз; фрагменты подключения к окну секрета подставляет страница.

## Папки

- `api/` — запросы реестра и токенов: участники, выпуск, отзыв
- `model/` — состояние трёх действий с ключом повтора из `shared/lib`; причина отказа в праве
- `ui/` — окна: заведение агента, выпуск, секрет один раз, подтверждение отзыва

## Файлы

- `index.ts` — публичный интерфейс среза
