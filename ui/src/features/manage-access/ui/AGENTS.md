# src/features/manage-access/ui

## Файлы

- `agent-dialog.tsx` — окно «Завести агента»: имя и описание, объяснение отказа, переход к выпуску токена заведённому участнику
- `issue-dialog.tsx` — окно «Выпустить токен»: кому (участник или общий), набор с объяснением каждого (умолчание `task`), имя токена
- `secret-dialog.tsx` — окно секрета: сказано, что показ один, блок копирования и фрагменты подключения детьми
- `revoke-dialog.tsx` — подтверждение отзыва `role="alertdialog"`: последствия словами, у ключа этого сеанса — отдельное предупреждение
