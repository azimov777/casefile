# src/features/manage-access/ui

## Файлы

- `agent-dialog.tsx` — окно «Завести агента»: имя и описание, объяснение отказа, переход к выпуску токена заведённому участнику
- `issue-dialog.tsx` — окно «Выпустить ключ»: кому (свой агент, агент без хозяина, у администратора все с именем хозяина, или общий ключ; людей нет), имя ключа; выбора набора нет
- `secret-dialog.tsx` — окно секрета: сказано, что показ один, блок копирования и фрагменты подключения детьми
- `revoke-dialog.tsx` — подтверждение отзыва `role="alertdialog"`: последствия словами, у ключа этого сеанса — отдельное предупреждение; у подключения OAuth то же действие зовётся «Отключить»
