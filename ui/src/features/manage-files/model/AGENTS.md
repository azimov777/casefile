# src/features/manage-files/model

## Файлы

- `use-file-actions.ts` — мутации загрузки (с ключом повтора), замены, удаления одного и нескольких; после каждой перечитываются списки файлов
- `use-all-matching.ts` — все файлы под отбор: дочитывает страницы до конца, чтобы назвать число для подтверждения удаления по отбору
