# src/features/manage-files

Изменения файлов установки (TRK-739): загрузить в проект, заменить содержимое под той же ссылкой, удалить один файл,
выбранные или все под отбор — с подтверждением числом. Читают файлы `entities/file`; экран собирает `pages/files`.

## Папки

- `api/` — запросы изменения: загрузка и замена (`multipart/form-data`), удаление одного, нескольких, по отбору
- `model/` — мутации с перечиткой списков, ключ повтора загрузки, обход всех страниц под отбор для подсчёта
- `ui/` — окна загрузки, замены, удаления одного и нескольких

## Файлы

- `index.ts` — публичный интерфейс среза
