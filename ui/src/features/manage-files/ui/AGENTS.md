# src/features/manage-files/ui

## Файлы

- `upload-dialog.tsx` — кнопка и окно «Загрузить файл»: проект (не архивный), файл, необязательное имя
- `replace-dialog.tsx` — кнопка и окно «Заменить»: новые байты под той же ссылкой
- `delete-dialog.tsx` — кнопка и окно удаления одного файла: сколько записей и задач ссылаются
- `delete-many-dialog.tsx` — окно удаления выбранных и всех отобранных: число, имена, сумма ссылок, отметка «удаляю ровно N» для отбора
- `file-field.tsx` — выбор файла и необязательное имя: общая часть загрузки и замены
