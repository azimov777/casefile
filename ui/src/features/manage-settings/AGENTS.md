# src/features/manage-settings

Правка настроек установки, только администратору: задать значение числом с единицей или выбором
«включена / выключена», вернуть настройку окружению. Отказ сервера показывается рядом с полем, черновик
остаётся.

## Папки

- `api/` — `PATCH` одной настройки: значение или `null` («брать из окружения»)
- `model/` — мутация правки: ответ ложится в кэш списка, список перечитывается
- `ui/` — форма правки одной настройки

## Файлы

- `index.ts` — публичный интерфейс среза
