# src/features/manage-people

Люди установки, только администратору: завести товарищу учётную запись, сбросить пароль, отключить и
включить обратно. Сгенерированный пароль уезжает вызывающему мимо кэша запросов — экран показывает его
один раз.

## Папки

- `api/` — заведение учётной записи, сброс пароля, отключение и включение
- `model/` — состояние действий с паролем в ответе мимо кэша и мутация отключения
- `ui/` — окна: заведение, пароль один раз, сброс, отключение и включение; выбор пароля

## Файлы

- `index.ts` — публичный интерфейс среза
