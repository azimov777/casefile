# src/features/manage-people/ui

## Файлы

- `create-dialog.tsx` — окно «Завести человека»: почта, имя-подпись с правилом, флаг администратора, пароль; отказ у своего поля
- `password-choice.tsx` — выбор пароля: сгенерировать (умолчание) или вписать; поле появляется только для вписанного
- `password-dialog.tsx` — окно пароля один раз: предупреждение над ним, почта и пароль блоками копирования
- `reset-dialog.tsx` — сброс пароля `role="alertdialog"`: последствия словами, выбор пароля
- `disable-dialog.tsx` — отключение `role="alertdialog"` с последствиями (вход закрыт, токены отозваны) и включение обратно тем же окном
