# src/app

Верхний слой: всё, что собирает приложение в целое. Экранов здесь нет — они в `pages`; оболочка живёт
в `layouts/`, страж входа — рядом с маршрутами в `routes/`.

## Папки

- `config/` — настройки серверного состояния (`query-client.ts`)
- `layouts/` — оболочка приложения и шапка с участником, счётчиком вопросов и выходом
  (выход показан только там, где человек входил сам)
- `providers/` — общая обвязка: провайдер запросов и присмотр за просроченным сеансом
- `routes/` — список маршрутов, страж входа, страница «не найдено»

## Файлы

- `app.tsx` — обвязка плюс маршрутизатор браузера
- `explanations.test.tsx` — страничный тест пояснений экранов: тексты `en`/`ru` дословно, скрытие, список и доска порознь, словари против перечня ключей
- `index.ts` — публичный интерфейс слоя
- `walk.test.tsx` — страничный тест прохода по экранам: шаги и их адреса, архивный проект пропущен, «Назад»/«Далее»/«Закончить», ни одного `PATCH`, нет кнопки без учётной записи
