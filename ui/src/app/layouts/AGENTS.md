# src/app/layouts

Оболочка вокруг любого экрана: то, что человек видит на всех страницах сразу.
Сегмента `ui` у слоя `app` быть не должно, поэтому оболочка живёт здесь.

## Файлы

- `app-shell.tsx` — рамка приложения: сетка из боковой панели и содержимого, шторка панели на узком экране
- `app-side.tsx` — содержимое панели: очереди, входящая со счётчиком, участник, состояние потока, выход
- `app-side.test.tsx` — подсветка места, счётчик числом с подписью, отсутствие действий кроме выхода, отказ `bootstrap`
- `app-topbar.tsx` — верхняя полоса: где человек находится, переключатель вида, кнопка панели на узком экране
- `place.ts` — где человек находится по адресу: раздел, очередь, ключ задачи
