# src/app/routes

Адреса приложения и то, что решает, пускать ли по ним.

## Файлы

- `routes.tsx` — список маршрутов (страница области — `projects/:key/areas/:area`); тот же список поднимают страничные тесты
- `home-redirect.tsx` — `/`: пока состояние знакомства учётной записи `pending`, ведёт на «Начало», иначе на список задач
- `home-redirect.test.tsx` — `pending` → `/start`, `completed`/`skipped`/`null` → `/tasks`, ожидание первого кадра `bootstrap`
- `require-auth.tsx` — страж: ждёт ответа установки про ключ, а без ключа уводит на вход
- `require-auth.test.tsx` — оба источника ключа на экране: ключ установки, его отсутствие,
  старшинство над сохранённым, `401` с перечитыванием конфигурации
- `require-sign-in-mode.tsx` — страж экранов режима входа (`/account`, `/people`): на своей машине их адрес — «страница не найдена»
- `not-found.tsx` — экран несуществующего адреса
