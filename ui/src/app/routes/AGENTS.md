# src/app/routes

Адреса приложения и то, что решает, пускать ли по ним.

## Файлы

- `routes.tsx` — список маршрутов; тот же список поднимают страничные тесты
- `require-auth.tsx` — страж: ждёт ответа установки про ключ, а без ключа уводит на вход
- `require-auth.test.tsx` — оба источника ключа на экране: ключ установки, его отсутствие,
  старшинство над сохранённым, `401` с перечитыванием конфигурации
- `not-found.tsx` — экран несуществующего адреса
