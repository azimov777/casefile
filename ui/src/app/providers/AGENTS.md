# src/app/providers

Обвязка, которая должна действовать одинаково в браузере и в страничных тестах.

## Файлы

- `app-providers.tsx` — единственная сборка обвязки; её же поднимает `testing/render.tsx`
- `session-watcher.tsx` — реакция на `401`: снять кэш, поднять признак просроченного сеанса
- `session-watcher.test.tsx` — проверка, что просроченный токен уводит на вход с пояснением
