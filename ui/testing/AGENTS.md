# testing

Обвязка модульных и страничных тестов. Лежит вне `src`, чтобы не быть слоем FSD
и не попадать в сборку. Подключается псевдонимом `@testing/*`.

## Папки

- `msw/` — подмена API: сервер без общих обработчиков и ответы в оболочке контракта

## Файлы

- `setup.ts` — сопоставители, жизненный цикл подмены, уборка токена и хранилищ между тестами
- `render.tsx` — подъём приложения на маршрутах в памяти с настоящей обвязкой
- `live-journal.ts` — подмена открытия живого потока: в jsdom настоящий SSE не работает
