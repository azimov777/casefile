# testing/msw

Подмена API для страничных тестов.

## Файлы

- `server.ts` — сервер MSW; общих обработчиков нет намеренно, их задаёт каждый тест
- `responses.ts` — адреса источника и конфигурации установки, ответы в оболочке контракта
  и фикстуры: `bootstrap`, строка списка,
  страница списка задач с общим числом выдачи, пакет карточки, записи дела (сводка, вопрос,
  вердикт), опись
