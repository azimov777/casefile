# testing/msw

Подмена API для страничных тестов.

## Файлы

- `server.ts` — сервер MSW; общих обработчиков нет намеренно, их задаёт каждый тест; исключение — запасной ответ плашки выпуска «обновления нет» (`TRK-416`)
- `responses.ts` — адреса источника и конфигурации установки, ответы в оболочке контракта
  и фикстуры: `bootstrap`, строка списка (родителей по умолчанию нет — `[]`), страница списка задач с общим числом выдачи,
  выдача по параметрам самого запроса (`taskListing`: отбор по статусу, размер страницы,
  курсор), пакет карточки, записи дела (сводка, вопрос, вердикт), опись, доступ установки
  (`accessToken`), версия и последний выпуск (`release`, без обновления), участник реестра (`participant`) и карточка проекта (`projectDetail`,
  активная по умолчанию)
