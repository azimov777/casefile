# testing/msw

Подмена API для страничных тестов.

## Файлы

- `server.ts` — сервер MSW без общих обработчиков: их задаёт каждый тест; запасные ответы — только плашке выпуска
  («обновления нет») и списку обсуждений (пусто)
- `responses.ts` — адреса источника и конфигурации установки, ответы в оболочке контракта и фикстуры сущностей:
  `bootstrap`, строка и страница списка задач, выдача по параметрам запроса (`taskListing`), пакет карточки с блоком
  `state`, записи дела и опись, доступ, выпуск, участник, проект, область, обсуждение и его записи
