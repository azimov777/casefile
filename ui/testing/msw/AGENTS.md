# testing/msw

Подмена API для страничных тестов.

## Файлы

- `server.ts` — сервер MSW; общих обработчиков нет намеренно, их задаёт каждый тест; исключения — запасной ответ плашки выпуска «обновления нет» (`TRK-416`) и пустой список обсуждений (TRK-672)
- `responses.ts` — адреса источника и конфигурации установки, ответы в оболочке контракта
  и фикстуры: `bootstrap`, строка списка (родителей по умолчанию нет — `[]`), страница списка задач с общим числом выдачи,
  выдача по параметрам самого запроса (`taskListing`: отбор по статусу, размер страницы,
  курсор), пакет карточки и его блок `state` (`taskState`, TRK-579), записи дела (сводка, вопрос, вердикт), опись, доступ установки
  (`accessToken`), версия и последний выпуск (`release`, без обновления), участник реестра (`participant`), карточка проекта (`projectDetail`,
  активная по умолчанию) и область проекта (`areaCard`, `areaDetail`, TRK-557), обсуждение (`discussion`, `discussionDetail`) и записи его дела: вопрос, ответ, заметка, итог (TRK-672)
