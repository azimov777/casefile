# docs

Проектная документация интерфейса: что строим и по каким правилам.
Точка входа для нового агента — `CONCEPT.md`, затем `CONVENTIONS.md`, затем своя задача
в проекте `TRK` трекера — общем на весь репозиторий.

## Папки
- `notes/` — находки и грабли от предыдущих агентов; читается до начала работы, только пополняется

## Файлы
- `CONCEPT.md` — роль человека, экраны, потоки данных, принципы интерфейса, чего не строим
- `CONVENTIONS.md` — обязательные правила: стек, структура, клиент API, состояние, тесты, коммиты,
  протокол выполнения задачи
- `FRONTEND.md` — карта контракта бэкенда: экраны и их запросы, оболочка и ошибки, признаки,
  строка описи, замечания, живой поток; пути и коды сверяются с выгрузками бэкенда тестом
