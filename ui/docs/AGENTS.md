# docs

Проектная документация интерфейса: что строим, по каким правилам и в каком порядке.
Точка входа для нового агента — `CONCEPT.md`, затем `CONVENTIONS.md`, затем свой файл задачи.

## Папки
- `notes/` — находки и грабли от предыдущих агентов; читается до начала работы, только пополняется
- `tasks/` — задания для агентов-исполнителей, по одному файлу на задачу; выполненные удаляются

## Файлы
- `CONCEPT.md` — роль человека, экраны, потоки данных, принципы интерфейса, чего не строим
- `CONVENTIONS.md` — обязательные правила: стек, структура, клиент API, состояние, тесты, коммиты,
  формат задания, протокол выполнения задачи
- `ROADMAP.md` — порядок запуска задач 01–08, зависимости, точки наблюдения
