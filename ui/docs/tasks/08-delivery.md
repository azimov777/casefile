# 08. Поставка: сквозные тесты, доступность, README

## Цель

Довести интерфейс до состояния, в котором его можно отдать человеку: сквозные сценарии
всех экранов против демо, проверка доступности, сборка в образ, README с запуском
с нуля.

## Контекст

- Все экраны из задач 01–07; `CONVENTIONS.md`, разделы «Запуск», «Интерфейс», «Тесты».
- Бэкенд с демо в `../tracker`; сквозные тесты идут в Docker через `docker-compose.yml`
  этого репозитория.

## Ограничения

- Сквозные тесты используют только демо-данные и то, что создают сами через API
  бэкенда; порядок тестов не важен.
- `axe` без нарушений уровня serious и critical на каждой странице в обеих темах.
- Производственная сборка отдаётся nginx из образа; адрес бэкенда задаётся переменной
  окружения при запуске, а не при сборке.

## Выход

- Набор Playwright: вход, список с фильтрами, доска, карточка с подгрузкой записи,
  лента дела, ответ на вопрос, живое обновление; отчёт со снимками при падении.
- `axe` в каждом сквозном тесте; найденные нарушения исправлены.
- Образ и `docker-compose.prod.yml` для запуска интерфейса рядом с прод-контуром бэкенда;
  README: запуск с нуля, переменные, команды проверки, как подключить к своему бэкенду.
- `AGENTS.md` всех папок актуальны; заметки дописаны.

## Обзорные проверки

1. На чистой машине с Docker по README: поднять бэкенд с демо, поднять интерфейс, открыть в браузере, войти токеном из `init`, увидеть очередь `DEMO`.
2. `pnpm e2e` проходит весь набор; при намеренном падении одного теста в отчёте есть снимок экрана и трассировка.
3. `axe` не находит нарушений serious и critical ни на одной странице ни в одной теме.
4. Производственный образ запускается с другим адресом бэкенда через переменную окружения без пересборки.
5. `pnpm check` зелёный; всё запущенное погашено.
