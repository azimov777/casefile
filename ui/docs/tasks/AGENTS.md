# docs/tasks

Задания для агентов-исполнителей: один файл — одна задача, выполняемая за один заход.
Порядок и зависимости в `docs/ROADMAP.md`, правила и формат задания в `docs/CONVENTIONS.md`.
Выполненная задача удаляется вместе со своей строкой в этом списке.

## Файлы

- `03-board.md` — режим доски: шесть столбцов статусов одной очереди
- `05-case-timeline.md` — лента дела со всеми типами записей и ссылками `TRK-42#12`
- `06-questions.md` — входящая открытых вопросов и форма ответа с идемпотентностью
- `07-live.md` — живой поток журнала, инвалидация по кадрам, индикатор соединения
- `08-delivery.md` — сквозные тесты, доступность, образ, README
