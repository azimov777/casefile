# docs/notes

Заметки интерфейса, ещё не перенесённые в трекер: находки, грабли и неочевидные решения
предыдущих агентов, файл на область. Формат записи и снос — решения TRK#230 и TRK#231; указатели
«Где:» и имена из текста сверяет `testing/notes.test.ts`.

## Файлы

- `tooling.md` — pnpm, версии Node, контур Docker, откуда берётся токен для сквозных тестов, режим nginx, который пишет шаг старта
- `testing.md` — грабли jsdom, MSW и react-router; из чего собрана обвязка тестов; пересборка образа; второй режим интерфейса в сквозном контуре
- `api.md` — пределы структурных фильтров списка и форма отказа разбора запроса
- `connect.md` — чужие клиенты MCP под фрагменты подключения: порядок флагов Claude Code, токен Codex из окружения, формы JSON `mcpServers`
- `ui.md` — поведение TanStack Query на отказе, перечисление значений контракта, вёрстка и ссылки
- `live.md` — живой поток: подмена в тестах, когда перечитывать, как воспроизвести обрыв, что снимает полосу таблицы
