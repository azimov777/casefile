# docs/notes

Накопленное знание по проекту: находки, грабли и неочевидные решения, оставленные агентами
для тех, кто придёт следующим. Один файл на область. Заметки только копятся. Формат записи
в `docs/CONVENTIONS.md`, раздел «Заметки».

## Файлы

- `tooling.md` — pnpm, версии Node, контур Docker, откуда берётся токен для сквозных тестов
- `testing.md` — грабли jsdom, MSW и react-router; из чего собрана обвязка тестов; пересборка образа
- `api.md` — пределы структурных фильтров списка и форма отказа разбора запроса
- `connect.md` — чужие клиенты MCP под фрагменты подключения: порядок флагов Claude Code, токен Codex из окружения, формы JSON `mcpServers`
- `ui.md` — поведение TanStack Query на отказе, перечисление значений контракта, вёрстка и ссылки
- `live.md` — живой поток: подмена в тестах, когда перечитывать, как воспроизвести обрыв, что снимает полосу таблицы
